## ◎ 最優先で検討すべき

---

### 1. 根本昌夫（朝日カルチャーセンター 新宿 / オンライン受講可）

> 島田雅彦・小川洋子・角田光代を発見した伝説の文芸編集者。「文学として読む眼」を鍛える講座。

| 項目 | 内容 |
|---|---|
| 形式 | オンライン受講可（現地不要） |
| 頻度 | 月1〜2回 / 受講生全員の作品に添削 |
| 純文学適性 | ◎ |
| 料金 | カルチャーセンター相場（月数千円〜） |
| 申込 | [朝日カルチャーセンター](https://www.asahiculture.com/asahiculture/asp-webapp/web/WWebKozaShosaiNyuryoku.do?kozaId=8546385) |

**なぜ推すか:** Constrainのような内省的・心理的な純文学を「文学として読める」数少ない指導者。定員制で満席になることが多いため早めに確認推奨。

---

### 2. アッチシア（ココナラ 純文学添削）

> 純文学新人賞最終選考経験あり。Wordのコメント機能で原稿に直接指摘＋1,000字以上の総評。添削実績70作品超。

| 項目 | 内容 |
|---|---|
| 形式 | 非同期添削（場所・時間を選ばない） |
| 頻度 | 自分のペースで提出 |
| 純文学適性 | ◎ |
| 料金 | 0〜1万字の基本料金（ページ参照） |
| 申込 | [ココナラ](https://coconala.com/services/2177510) |

**なぜ推すか:** スクールに縛られず「単発で使える」。まず1作品試して相性を確認できるのが初心者に向いている。「必ず直すべき点」と「解釈が分かれる点」を分けてくれる指摘スタイルが具体的。

---

### 3. 薄井ゆうじ（小説塾 / 完全個人運営）

> 作家本人が全件対応する通信添削。料金体系が明瞭。

| 項目 | 内容 |
|---|---|
| 形式 | 通信添削（メール） |
| 頻度 | 自分のペースで提出 |
| 純文学適性 | ○（ジャンル不問・文学的視点） |
| 料金 | 100枚まで2万円、全6回コース36,000円 |
| 申込 | [小説塾](https://www.syousetujuku.com/) |

**なぜ推すか:** 担当者ガチャなしで作家本人が読む。「丁寧で細かな指摘」という評判。料金が明瞭で試しやすい。

### 6. 心斎橋大学（大阪 / オンライン対応）

> 半年20回、毎回課題提出→個別講評のサイクルが回る。通える場所にある唯一の継続型スクール。

| 項目 | 内容 |
|---|---|
| 形式 | 通学 or オンライン（選択制） |
| 頻度 | 月2〜3回 |
| 純文学適性 | ○ |
| 料金 | 入学金29,700円 ＋ 受講料約116,600円（半年） |
| 申込 | [心斎橋大学](https://www.shinsaibashi-daigaku.jp/course/writing) |

**備考:** 「サイクルが回る外圧が欲しい」という要件には最もマッチ。ただし担当講師との相性確認が必要。見学（火曜）で先生の雰囲気を見てから判断推奨。

## × 今回は見送り

| 候補 | 理由 |
|---|---|
| 大阪文学学校 | 提出頻度が低い・合評中心で要件と合致度低 |
| 榎本メソッド | エンタメ・LN特化 |
| ヒューマンアカデミー通信 | ラノベ特化 |
| ストアカ各種 | 純文学適性が不明・質のばらつきあり |
| 京都芸術大学 通信 | 費用・期間が大きすぎる（今のフェーズには合わない） |

## 推奨アクション

1. **まず試す（低コスト・単発）**: アッチシア（ココナラ）で1作品添削してもらい「プロの目に何が見えるか」を体験する
2. **並行して確認**: 根本昌夫の朝日カルチャー講座の残席を確認（オンライン可）
3. **継続の場が欲しくなったら**: 心斎橋大学の見学（火曜）へ。担当講師名を事前に確認してから行く
4. **大阪文学学校**: 明日の見学は「比較データ取得」目的で行くなら価値あり。気乗りしないならキャンセルでも可
