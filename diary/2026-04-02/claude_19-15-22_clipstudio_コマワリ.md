# CLIP STUDIO PAINT コマワリが縦長になる問題と対策

## なぜ縦長になるか

「コマ枠フォルダー分割」で分割していくと、均等分割の繰り返しになりがち。特に縦に割る→さらに縦に割る、を繰り返すと全体が縦長コマだらけになる。

---

## 基本の対策

### 1. 分割の方向を意識的に交互にする
- **横線で割る（段を作る）→ その段の中を縦線で割る** が基本
- まず2〜3段に横分割してから、各段を縦に割ると自然なレイアウトになる

### 2. コマ枠ツールの「分割」ではなく「枠線の移動」を使う
- 分割した後、**オブジェクト操作ツール**でコマ枠の辺をドラッグして比率を変える
- 見せゴマ（大きく見せたいコマ）は大きく、つなぎのコマは小さくする
- **全部同じサイズにしない**のがコツ

### 3. コマのサイズにメリハリをつける
- 1ページ内で **大・中・小** を混ぜる
- 目安：
  - **大コマ**（1/3〜1/2ページ）：見せ場・感情のピーク → 1ページに1つ
  - **中コマ**（1/4ページ程度）：会話・動作 → 2〜3個
  - **小コマ**（1/6以下）：リアクション・効果音・間 → 1〜2個

### 4. 横長コマを意識的に入れる
- 風景・距離感・静寂・時間経過 → **横長コマ**が効果的
- 縦長ばかりだと画面が窮屈になるので、横長を1つ入れるだけで空気感が出る

---

## 具体的な手順（CLIP STUDIO）

### おすすめワークフロー

1. **コマ枠フォルダーを作成**（レイヤー → 新規レイヤー → コマ枠フォルダー）
2. **まず横線で2〜3段に分割**（コマ枠ツール → コマフォルダー分割 → 横方向にドラッグ）
3. **各段を必要に応じて縦に分割**
4. **オブジェクト操作ツール**に切り替えて、枠線をドラッグしてサイズ調整
5. 特定のコマを目立たせたい場合は **枠線を削除してぶち抜きコマ**にする

### 枠線の間隔設定
- `ツールプロパティ` → `左右の間隔` / `上下の間隔` を設定
- 上下の間隔 > 左右の間隔 にすると **段の区切りが明確**になって読みやすい
  - 例：左右 5.0mm / 上下 8.0mm

## よくあるNGパターンと修正

| NGパターン | 原因 | 修正 |
|-----------|------|------|
| 全コマ同じサイズ | 均等分割のまま | オブジェクト操作でサイズ変更 |
| 縦長コマばかり | 縦分割の繰り返し | まず横分割で段を作る |
| コマが多すぎ | 1ページ6コマ超え | 1ページ4〜6コマ目安 |
| 全部四角形 | 分割ツールのみ使用 | 斜め線・ぶち抜き・断ち切りを混ぜる |

## 参考テンプレート（4〜5コマの基本配置）

```
┌──────────────────┐
│    大コマ（横長）    │   ← 見せ場
├────────┬─────────┤
│  中コマ  │  中コマ   │   ← 展開
├──┬─────┴─────────┤
│小│   中〜大コマ      │   ← 締め
└──┴───────────────┘
```

この構成だと視線が Z字に流れて読みやすくなる。

---

## まとめ

- **まず横で段を割る → その中を縦で割る**
- **全コマ同サイズにしない**（大中小のメリハリ）
- **横長コマを意識的に1つ入れる**
- 上下の間隔を左右より広くして段を明確に
