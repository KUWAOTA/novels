# 小説・創作の個人指導講師・講座 調査レポート

> 調査日: 2026-03-23
> 目的: 純文学・心理ドラマに対応できる個人指導講師・講座の発掘

---

## 凡例

- **純文学対応度**: ◎強い / ○対応可 / △不明
- **指導形式**: 添削（非同期）/ オンライン面談 / 通信（郵送・メール）/ 講義+添削
- **個別度**: 完全1対1 / 少人数+個別添削 / グループ講義メイン

## A. 個人作家・元編集者による指導（最注目）

---

### 1. 根本昌夫（ねもとまさお）— 朝日カルチャーセンター新宿

| 項目 | 内容 |
|------|------|
| **プロフィール** | 元「海燕」「野性時代」編集長。島田雅彦・吉本ばなな・小川洋子・角田光代・佐伯一麦らを発見・育成した伝説的編集者。著書『実践小説教室』(PHP) |
| **純文学対応度** | ◎（純文学の発掘現場にいた人物） |
| **指導形式** | 講義（対面/オンライン）+ 全員の作品への添削講評 |
| **個別度** | 少人数グループ＋個別添削 |
| **開講場所** | 朝日カルチャーセンター新宿（オンライン聴講も可） |
| **料金感** | 月1〜2回、6回コースで数万円程度（カルチャーセンター相場） |
| **申込URL** | https://www.asahiculture.com/asahiculture/asp-webapp/web/WWebKozaShosaiNyuryoku.do?kozaId=8546385 |
| **特徴・評判** | 純文学新人賞受賞者を多数輩出。エンタメではなく文学として小説を読む眼を鍛える。受講生作品を全員で読み合わせ、編集者視点で徹底的に講評する形式 |

**おすすめ度: ★★★★★**（純文学・心理ドラマ志望ならここが最有力）

### 2. 島田雅彦 監修「純文学講座」— 公募スクール

| 項目 | 内容 |
|------|------|
| **プロフィール** | 芥川賞選考委員、現役純文学作家。著書多数。法政大学教授 |
| **純文学対応度** | ◎（「純文学」と明示） |
| **指導形式** | 通信（課題提出→講師添削）全9回。島田氏の著書『小説作法ABC』をテキストに使用 |
| **個別度** | 完全通信・個別添削 |
| **料金感** | 通信コース一括申込。再提出1回6,600円（追加オプション） |
| **申込URL** | https://school.koubo.co.jp/course/shimada-masahiko-pure-literature/ |
| **特徴・評判** | 島田雅彦本人が監修した課題設計。添削は講師担当だが、純文学の文脈を前提とした講座設計が他と一線を画す |

**おすすめ度: ★★★★☆**（純文学への意識が明確な数少ない講座）

### 3. 薄井ゆうじ（うすいゆうじ）— 『小説塾』（完全個人運営）

| 項目 | 内容 |
|------|------|
| **プロフィール** | 小説家。都筑道夫門下。『樹の上の草魚』等著書多数。長年個人で通信講座を運営 |
| **純文学対応度** | ○（ジャンル不問・文学的視点での指導） |
| **指導形式** | 通信添削（メールまたは郵送）。作品提出→塾長本人が詳細講評を返す |
| **個別度** | 完全1対1 |
| **料金感** | 1作品1回完結コース：100枚まで2万円、上限1000枚9万円。全6回課題コース：36,000円 |
| **申込URL** | https://www.syousetujuku.com/ |
| **特徴・評判** | 作家本人がすべて対応。受講者評価「丁寧で細かな指摘」「目からウロコのアドバイス」。純文学・文芸志望に適している |

**おすすめ度: ★★★★☆**（完全個人対応・料金明瞭・文学的指導）

## 総合比較・おすすめ選択肢

### 純文学・心理ドラマを書きたい場合の優先順位

| 優先 | 講師/サービス | 理由 |
|------|--------------|------|
| 1位 | **根本昌夫（朝日カルチャーセンター）** | 純文学の本場で育てた編集者。文学として読む眼を鍛える |
| 2位 | **アッチシア（ココナラ）** | 純文学専門・添削実績70作品超・非同期で使いやすい |
| 3位 | **薄井ゆうじ（小説塾）** | 作家本人の完全個別対応・料金明瞭 |
| 4位 | **島田雅彦監修（公募スクール）** | 純文学の文脈が明確・通信で全国対応 |
| 5位 | **壽倉雅（ストアカ）** | マンツーマン面談形式・スケジュール柔軟 |

### 指導形式別

| 形式 | おすすめ |
|------|---------|
| **リアルタイム対話** | 壽倉雅（ストアカ）、根本昌夫（オンライン受講） |
| **じっくり非同期添削** | アッチシア（ココナラ）、薄井ゆうじ（小説塾） |
| **通信講座（体系的）** | 島田雅彦監修（公募スクール）、朝日カルチャーセンター通信 |

## 注意・補足

- ココナラ出品者は随時変動するため、URLの有効性は要確認
- 根本昌夫の朝日カルチャー講座は定員制・残席少の場合あり（2025/1月時点でほぼ満席という情報あり）
- 「純文学・心理ドラマ」への適性は、問い合わせ段階で「内省的・心理的な文学を書きたい」と明示して相性を確認することを推奨
