# 地の文 vs ト書き — constrain/main 執筆フォーマット分析

## 前提の整理

現在の `constrain/main/` シーンファイルには以下が揃っている：
- YAMLメタデータ（価値変化・時空間・POV）
- ビート候補（箇条書き）
- 象徴・台詞候補

**問いは「## 本文」を埋めるとき、最初から地の文（完成原稿の文体）で書くか、ト書き（脚本的な動作指示＋台詞）で書くかどちらが効率的か。**

---

## 選択肢の定義

### A. 地の文（散文・完成原稿）

```
放課後のピロティに残っているのは樹だけだった。
コンクリートの柱が等間隔に並ぶその場所は、教室にも校庭にも属さない。
樹はそこが好きだった。どこにも属さないという点で、自分に似ていたから。
```

### B. ト書き（脚本的記法）

```
【ピロティ・放課後】
樹、ひとりで柱のそばに座っている。ランドセルを柱に立てかけ、図鑑を開く。
校庭から歓声。樹は一瞬顔を上げるが、すぐ図鑑に戻る。

秀斗（走りながら）「おーい、サッカーやろうぜ！」
　→ 樹のほうは見ていない。別の子に声をかけている。

樹（M）なんで走ってるときにそんなに笑えるんだろう。
```

---

## 分析

### 1. 現在のプロジェクト状態との相性

| 観点 | 地の文 | ト書き |
|------|--------|--------|
| 既存ビート候補との連続性 | ギャップが大きい（箇条書き→いきなり完成文） | 自然な延長線上（箇条書き→動作・台詞の具体化） |
| YAMLメタデータの活用 | 書くときに参照するだけ | POV・空間をそのまま柱書きに使える |
| 1シーン≒1000字の規約 | 最初から文字数を意識する必要がある | 分量を気にせず構造を固められる |

**→ 現状のファイル構造からは、ト書きのほうが自然な次のステップ。**

### 2. 作品の性質との相性

| 観点 | 地の文 | ト書き |
|------|--------|--------|
| 心理描写の深さ | ◎ ASD的認知の内面を直接書ける | △ 内面はト書きでは「M（モノローグ）」に頼る |
| 身体感覚・知覚の描写 | ◎ 「Constrainらしさ」の核 | △ 動作指示では質感が出にくい |
| 複数POVの切り替え | △ 地の文だと視点混乱しやすい | ◎ 柱書きで明示的にPOVを切れる |
| 対比構造（樹vs秀斗の家庭） | △ 交互に書くと文体が揺れる | ◎ クロスカットが構造的に書ける |

**→ この小説は内面描写が命なので、最終形は地の文。しかしS2（秀斗のクロスカット）のような構造的に複雑なシーンはト書きで構造を先に固めたほうが安全。**

### 3. 執筆効率

| 観点 | 地の文 | ト書き |
|------|--------|--------|
| 書き直しコスト | 高い（文体・リズムも作り込むため捨てにくい） | 低い（構造メモなので捨てやすい） |
| 1シーンの執筆速度 | 遅い（推敲込み） | 速い（動作と台詞だけ） |
| AI協業のしやすさ | 低い（文体の統一が難しい） | 高い（構造は共有しやすく、文体は人間が後で載せる） |
| 「書けない」の壁 | 高い（白紙→完成文のプレッシャー） | 低い（「何が起きるか」だけ書けばいい） |

**→ 5ACT分を書き切るには、ト書き先行のほうが圧倒的にスループットが高い。**

### 4. リスク

| リスク | 地の文先行 | ト書き先行 |
|--------|-----------|-----------|
| プロットと齟齬が出たとき | 書き直しが痛い | ト書きを直すだけ |
| 文体が固まらないまま進む | ありえない（文体で書くから） | **ありえる（後回しにし続ける危険）** |
| 構造の穴に気づかない | **ありえる（文章の美しさに目が行く）** | 気づきやすい（骨だけ見えるから） |

## 推奨：ハイブリッド方式

**「ト書き→地の文」の2パス方式を推奨する。ただし、最初の1シーンだけは地の文で書く。**

### 具体的な手順

```
Phase 1: S1だけ地の文で書く
  → 文体・トーン・1シーンの粒度を確定する「基準シーン」にする
  → ここで「スマホ閲覧用改行」「≒1000字」のリズムも掴む

Phase 2: 残りのシーンはト書きで一気に書く
  → ビート候補を具体的な動作・台詞・内面メモに展開
  → 構造的な穴・矛盾をこの段階で潰す
  → ACT単位でプロットとの整合性を確認

Phase 3: ト書きを地の文に変換していく
  → S1の文体を基準にする
  → 1シーンずつ、ト書きを見ながら散文化
```

### なぜS1から地の文か

- S1「ASD傾向で孤立」は構造的にシンプル（POVは樹のみ、時間軸は線形）
- この作品の「声」を最初に確定しないと、ト書きの書き方自体がブレる
- 読者が最初に触れるシーンなので、ここの質がすべてを決める
- ビート候補（シュモクバエ、ピロティ）が具体的で、すぐ書ける状態にある

### S2以降をト書き先行にする理由

- S2はクロスカット構造で、地の文でいきなり書くと視点管理が破綻しやすい
- ACT2以降は未確定要素（🔶）が多く、構造が変わる可能性がある
- ト書きなら「この台詞はいる／いらない」の判断が速い

## ファイル運用案

現在の `## 本文` セクションをそのまま使う：

```markdown
## 本文

### ト書き
【ピロティ・放課後】
樹、ひとりで柱のそばに…（ト書きフェーズで記入）

### 完成稿
放課後のピロティに残っているのは…（地の文フェーズで記入）
```

こうすれば、ト書きと完成稿が同じファイル内で対照でき、変換作業がしやすい。

## まとめ

| 判定 | 内容 |
|------|------|
| **結論** | ト書き先行（ただしS1のみ地の文スタート） |
| **理由** | 構造の穴を早期発見でき、書き直しコストが低く、5ACT完走の確率が最も高い |
| **最大のリスク** | ト書きで止まって地の文に進まないこと → S1を先に完成させることで基準を作り、このリスクを潰す |
