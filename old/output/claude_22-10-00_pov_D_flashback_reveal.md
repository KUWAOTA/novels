# 案D：樹メイン＋謎解きフラッシュバック方式

## 構造

```
原則：全編を樹の一人称（僕）で描ききる。
例外：物語の転換点で「謎が明かされる」タイミングに、
      秀斗 or あんずの一人称による回想シーンを挿入する。
```

読者は樹と同じ情報量で物語を追体験する。
樹が知り得ない事実は、**構造上の必然があるタイミング**で
秀斗・あんずの回想として「割り込む」。

### ⚠️ W001 `12_exposition` — あんず回想の挿入タイミング

```
あんずの回想（性的虐待→死の経路）をACT2-S4直後に配置する場合：
  importance_score: 0.95 の情報が物語の40%地点で露出
  → premature_high_importance_dump の可能性

ただし：
  ・直前に「死の報せ」があり、curiosity_level は最大
  ・読者は「なぜ死んだのか」を今すぐ知りたい状態
  ・13_scene-transition の backstory_revelation 条件を全て満たす：
    active_conflict_present: true（樹の誤信念が今確立された）
    curiosity_level: 1.0（死の理由）
    value_axis_linked: true（理解⇔誤解の軸に直結）
  → 正当化可能。warning は残るが最も自然なタイミング

代替案：あんず回想をACT5に遅らせる
  → ペーシングは改善するが、ACT3〜4でドラマティックアイロニーが使えなくなる
  → トレードオフ
```

### ℹ️ I001 `16_choice-and-expression` — 樹の認知フィルターの一貫性が最高

```
案Aの長所をそのまま維持：
  ・全編を樹のASD的認知フィルターで体験する
  ・読者は樹の「見えなさ」に没入し、同じ盲点を共有する
  ・フラッシュバックが入った瞬間、「樹には見えなかったもの」が爆発する
  → contrast（対比）が「同一シーン内」ではなく「時間軸」で発生する
```

### ℹ️ I002 `13_scene-transition` — フラッシュバックが全て構造的必然を持つ

```
4つの回想が全て flashback_usage_rules を満たす：

① 秀斗の羨望（ACT1-S3直後）：
  redefines_current_action_meaning: true
  （「いじめ」の意味が「嫉妬」に再定義される）

② あんずの最後の夜（ACT2-S4直後）：
  alters_audience_interpretation: true
  （読者のあんず像が「かわいそうな子」→「あの夜を生きた人」に変わる）
  shifts_value_state: true
  （樹の誤信念の「誤り」が読者に確定する）

③ 秀斗の崩壊の内側（ACT4-S2直後）：
  redefines_current_action_meaning: true
  （「正しい指導」が「虐待の再現」に再定義される）

④ 秀斗の教育虐待（ACT4-S3前）：
  shifts_value_state: true
  （鏡像認識の準備。秀斗の家庭を読者が知ることで共鳴が最大化）

→ 4つ全て「必然のタイミング」に配置される。装飾的な回想がゼロ
```

### ℹ️ I003 `20_interpretation-layer` — ドラマティックアイロニーが段階的に蓄積

```
情報格差の推移：

ACT1: 読者 = 樹（同じ情報量）
  → S3直後の秀斗回想で：読者 > 樹（秀斗の動機を知る）

ACT2: 読者 > 樹（秀斗の動機だけ知っている）
  → S4直後のあんず回想で：読者 >> 樹（あんずの真実を知る）

ACT3: 読者 >> 樹
  樹が「厳密な言語で救えた」と確信する度に読者は苦しくなる

ACT4: 読者 >> 樹
  → 秀斗回想が2つ入り、読者の情報量がさらに増える
  → 樹の「正しさ」の暴力が読者には見えている

ACT5: 樹が追いつく
  → 読者が先に知っていた真実に樹がようやく到達する
  → カタルシス

→ 「段階的な情報格差の蓄積 → ACT5での解消」は
  12_exposition の importance_curve_monotonicity と完全に一致
```

### ℹ️ I004 `23_character_components` — 回想が実像露呈装置として機能

```
通常シーン：樹の characterization（表面）が見える
フラッシュバック：秀斗・あんずの true_character（実像）が見える

しかも、秀斗・あんずの回想を読んだ後に
樹の通常シーンに戻ると、樹の characterization の裏に
true_character が透けて見えるようになる

→ 回想が「別キャラの実像露呈」と「樹の再解釈」を同時に行う
```

### ℹ️ I005 `19_scene-mastery` — 通常→回想→通常の before/after 対比

```
例：ACT2
  S3（デート・樹視点）: 楽しい時間。正の価値
  → あんず回想: 同じ夜。死。最大の負
  → ACT3-S1（灘・樹視点）: 樹は何も知らず使命に燃える
  
  回想の前後で、樹の通常シーンの意味が変わる
  → scene_mastery の before/after 対比が「シーン間」で発生
```

## 案A（あんず視点なし）との違い

案Aの `compile_error` だった E001（性描写の情報到達不可能）を
**フラッシュバックで解決する**のがこの案の本質。

```
案A: あんず視点なし → 性描写不可能 → compile_error
案D: あんず視点をフラッシュバックとして挿入 → 性描写可能 → error解消
```

案Aの長所（樹の認知フィルター一貫性）を維持しつつ、
案B/Cの長所（あんず・秀斗の実像露呈）もフラッシュバックで確保する。

## 最大のリスクと対策

**リスク：フラッシュバックが4つあると物語の推進力が削がれる**

```
13_scene-transition: excessive_flashback_density の可能性
```

**対策：**
- フラッシュバックは全て**短い**（1000字以内）
- 通常シーンの直後に置く＝推進力が一度止まった直後に入れる
- フラッシュバック直後に次のACT/SEQが始まる＝再加速の起点にする
- 4つのうち③④（秀斗の2つ）は1つに統合する選択肢もある
  → 3回なら density は許容範囲
