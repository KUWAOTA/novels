# 黒田コンサルへの需要 — 観点スキャン用

> **使い方**: 各項目を見て「要る / 要らない / 保留」を判断する。抜けている観点があれば追記する。
> 記号例: ◎ 絶対欲しい / ○ あると嬉しい / △ 保留 / × 不要

---

## 1. FBの中身（何を指摘してもらうか）

- [ ] **文章レベル** — 文体・リズム・語彙選択・比喩・描写の密度
- [ ] **構造レベル** — プロット構成・シーン設計・テンポ・伏線の張り方
- [ ] **キャラクター** — 人物造形の深さ・動機の説得力・対話の自然さ
- [ ] **内面描写** — 心理の運動・意識の流れの書き方（純文学の核）
- [ ] **テーマの浮かび上がり方** — 主題が読者にどう届くか・象徴の効果
- [ ] **読者体験** — 退屈な箇所・引き込まれる箇所・ページをめくる力
- [ ] **視点・語り** — 視点人物の選択・語りの距離感・一人称/三人称の効果
- [ ] **シーンの機能** — そのシーンが物語全体で何を果たしているか
- [ ] **削るべき箇所** — 冗長・重複・機能していない部分の指摘
> このあたりはどんな技術観点だろうと必要なので、すべて含めてください。あくまで例なので、例の観点として置いておくのはありかも

- [ ] **「なぜダメか」の言語化** — 感想でなく、機能不全の理由を説明してもらえるか
> これは絶対に必要

> 後可能なら、悩みに対するおすすめの書籍を提示してきてそれを勉強する型がいいかもしれない。

## 2. FBの形式（どうやって返してもらうか）

- [ ] **原稿への直接コメント** — Word/Docs等で該当箇所に赤入れ
- [ ] **総評** — 全体の印象・方向性を文章でまとめたもの
- [ ] **口頭ディスカッション** — 通話や対面でやりとり
- [ ] **「直せ」型 vs 「選択肢提示」型** — 正解を示すか、複数の道を見せるか
- [ ] **一読目の率直な感想** も欲しいか — 分析の前に「読者としてどう感じたか」
- [ ] **優先順位付き** — 全部指摘するのでなく「まずここを直せ」の優先度

> これは黒田氏が賭けてくれる工数に依存する。理想を言えば一文一文原稿に直接コメントほしいが膨大になる。
> 基本的な方向性としては、現状の課題があって、それを持っていってそれであればこのレビューの形がいいでしょう。と毎回決めておく方がいい。
> どの観点で切ればいいかに関するディスカッション・コンサルもお願いしたい。
> おそらく、最初から小説を書いて全部見せることは少なくて、プロットだったりサンプルsceneだったりする。

## 3. FBの粒度・単位（何を出して何が返ってくるか）

- [ ] **シーン単位** で出して細かくFBもらう
- [ ] **章単位** でまとめて出す
- [ ] **作品全体** を通しで読んでもらう
- [ ] **プロット・構成段階** でもFBもらえるか（書く前の相談）
- [ ] **書きかけ・未完成** でも出せるか
- [ ] **書き直し後の再FB** — 修正が効いたか確認するサイクル

> 前述のとおり、目的や進め方毎に毎回相談してFB方法は決めたいです。

## 4. ペース・サイクル（どれくらいの頻度で回すか）

- [ ] **提出頻度** — 週1 / 隔週 / 月1 / 月2 / 不定期
- [ ] **FB返却の目安日数** — 何日で返ってくるか
- [ ] **締切は誰が決めるか** — 黒田が決める / 自分で宣言 / 相談して決める
- [ ] **締切を破った時** — せっつく / 放置 / リスケ相談
- [ ] **提出→FB→修正→再提出のサイクル** が明確に回ること
- [ ] **最低限のペース保証** — 月に最低N回は出す、等の約束事

> 週1くらいでやれたら理想。相談で締め切りを決めたい。
> 締め切りを破れるのは突発的な用事や体調不良の時が基本で、それ以外でn回落とすと金が発生するとかパニッシュメント型でいい

## 5. 伴走・メンタル面（技術以外のサポート）

- [ ] **進捗確認** — 定期的に「どこまで書いた？」と聞いてくれる
> ありがたいけど、工数かけることにならないか？　それは負担であろう
- [ ] **書けない時の相談** — 詰まった時に壁打ちできるか
> したい
- [ ] **モチベーション管理** — やる気が落ちた時のサポートは範囲内か
> 外、相談に含むでもいい
- [ ] **せっつき・外圧** — 「まだ？」と言ってくれること自体に価値がある
> 特になし
- [ ] **純粋に技術指導のみ** — メンタル面は自分で管理、FBだけもらう
- [ ] **心理的安全性** — 傷つけるより前進させるスタンス
> 大事
- [ ] **褒める/認めるのバランス** — できている部分も言語化してほしいか
> それはしてほしい

## 6. 指導のスタンス（どういう関わり方を求めるか）

- [ ] **ティーチング寄り** — 「こう書くべき」「この技法を使え」と教える
- [ ] **コーチング寄り** — 「あなたはどう書きたい？」から引き出す
- [ ] **編集者的な読み** — 商業的な完成度の目で見る
- [ ] **作家仲間的な読み** — 同じ書き手として意見を言う
- [ ] **作品の方向性にも口を出す** — 「このプロットはこう変えた方がいい」
- [ ] **技術面のみ** — 方向性は自分で決める、実装の質だけ見てほしい
- [ ] **厳しさの度合い** — 遠慮なく言ってほしい / ある程度クッション欲しい

> 現状だと、〇〇であり、もしあなたが△△を望むなら、□□が足りない　よって、あなたが△△に持っていきたい場合は～～が必要で、そのためには＊＊のスキルがいる
> というように強制指導というよりは論理的なほうがいい。

## 7. コミュニケーション手段・頻度

- [ ] **FB返却の手段** — テキスト（LINE/メール）/ 通話 / 対面 / ドキュメント共有
> 場合によってもいい、通話対面が理想だが
- [ ] **質問・相談** — FBに対して質問できるか、一方通行か
> できたほうがいい
- [ ] **FB以外の雑談・相談** — 読書の話、他の作品の話など
> なくていい
- [ ] **レスポンス速度の期待値** — 即日？数日？
> 自由でいい
- [ ] **定期ミーティング** — 月1で通話して振り返る等
> 締め切りごとにで十分では？

## 8. 対象範囲（何をコンサルの範囲とするか）

- [ ] **完成原稿のFB** — メインの想定
- [ ] **プロット・構成の相談** — 書く前の段階
- [ ] **アイデア出し・ブレスト** — 「こんな展開どう思う？」
- [ ] **読書案内** — 「この課題ならこれを読め」という処方
- [ ] **技法の解説** — 特定の技術について教えてもらう
- [ ] **他作品の分析** — 「この小説のここはなぜ効いているか」を一緒に考える
- [ ] **公募・投稿先の相談** — 今は不要だが将来的に？
- [ ] **執筆プロセス自体の相談** — 書き方・習慣・ツールなど

> ここは全般だが、毎回の相談で何を強化して何は自分で進めることができるかを相談したい。

## 9. Constrain固有の事情

- [ ] **長編であること** — 全体を把握した上でのFBが必要
> これはいきなり書かないから大丈夫
- [ ] **ACT1-2は完成、3-5は未執筆** — 既存部分のFBと未執筆部分の構成相談
> AIが書いたやつは未執筆扱いでいいです
- [ ] **純文学・心理ドラマ** — エンタメ的な盛り上がりより内面の運動が軸
> これは黒田もそうなので気にしなくてよい
- [ ] **McKee理論ベースの構造** — 理論は自分で入れている、その適用が正しいかの確認
> これはしたい
- [ ] **Claude/AGとの併用** — AI支援と人間のFBの役割分担
> これも相談はしたい、というかAIに任せられる汎用知識の部分は自走したいっすね。それで、人間の観測が必要なところを詰めていきたい。せっかくのリソースなので

## 10. 成長の実感（どう上達を測るか）

- [ ] **定期的な振り返り** — 月1で「前月と比べてどう変わったか」
- [ ] **前の原稿との比較** — 以前の原稿を引き合いに成長を見せてもらう
- [ ] **具体的なスキル項目のチェック** — 「描写力は上がった、構成はまだ」等
- [ ] **特に測定しない** — FBの質で自然に実感できればいい

> 取り入れたほうがいいかもしれないが、力点になくてもいい

## 11. 期間・料金・契約

- [ ] **期間の目安** — 3ヶ月 / 半年 / 1年 / 決めない
- [ ] **料金体系** — 月額 / 回数制 / 作品単位 / 時間制
- [ ] **ムラマサ基準（55,000円/10回添削+1回長文）** との比較感
- [ ] **途中で合わなかった場合** — 解約・休止の取り決め
- [ ] **成果の定義** — 何をもって「コンサルが機能した」とするか

> 料金は月2万台までなら全然出す
