# 小説通信講座 徹底比較調査
調査日：2026-03-23

## 1. 薄井ゆうじ 小説塾

### 講師プロフィール

- **薄井ゆうじ**（1949年生、茨城県出身）
- 1988年「残像少年」で第51回小説現代新人賞受賞
- 1994年「樹の上の草魚」で第15回吉川英治文学新人賞受賞
- 約50冊の小説を上梓、発表作品は1000作近く
- 代表作：『くじらの降る森』『樹の上の草魚』『星の感触』『狩人たち』
- 映画化作品あり（『樹の上の草魚』→映画『あ、春』のモデル的存在）
- 2015年に「小説塾」を立ち上げ塾長に就任
- **作風**：大衆文学寄り（吉川英治文学新人賞）。ファンタジー・SFよりのユニークな作品群も多い。純文学というよりエンタメ系文芸の実力者

### コース・料金

#### 1作品完結講座（自由原稿添削）
| 枚数（400字詰換算） | 料金 |
|---|---|
| ～100枚 | 20,000円 |
| 101〜200枚 | 30,000円 |
| 201〜300枚 | 40,000円 |
| 801〜1000枚 | 90,000円（最大9段階） |

- 受講者が自由に書いた作品を提出 → 添削・講評・アドバイス返却
- 返却期間：**10日〜2週間**
- 最大1000枚（長編対応）

#### 全6回・課題コース
- 料金：**36,000円**
- 6回分のテキストと課題に沿って書いて提出する形式
- 受講期間：1年間（最初の作品提出から）

### 受講の流れ

1. コース選択・入金
2. 1作品完結：作品をメール等で提出
3. 10〜14日で添削・講評・アドバイスが返却
4. 全6回コース：テキストに沿って課題を順次提出・添削

### 添削の内容・具体性

添削は**塾長・薄井ゆうじ本人が担当**（講師陣への外注ではない）。

内容：
- 誤字脱字・言葉の使用法の指摘（原稿に丸囲み数字でマーク、別紙解説）
- 導入部・中盤・後半それぞれの構成アドバイス
- 展開の順序・人物描写・設定のつじつまへの指摘
- 登場人物の名前・性格付け・舞台設定への提案
- 題名への提案も含む

実際の口コミから判明した具体的アドバイス例：
- 実験的な作品に対して「多くの作家がすでに書き尽くした形式」という率直な評価
- 「現実感のある世界をしっかり書けばそれなりに世間から認められるのではないか」というリアリズムへの転換提案
- 「この作品を読んだ読者にどんな感動を与え、どんな読後感を持ってもらいたいのか」という本質的な問いかけ
- 「書き直しの重要性」への言及が複数の受講者から報告されている

編集者のアドバイスに近いスタイル（構成・読者体験重視）。

### 口コミ・評判

**ポジティブ**
- 「丁寧で細かな指摘と講評に感謝。『こうしてみては』という大胆なアドバイスで目からウロコ」（10年以上受講者）
- 「筆力があると言ってもらえた」「プロからのフィードバックが実践的」
- 長編対応（最大1000枚）で返却が早い点を高く評価する声
- 添削が塾長本人から来る安心感

**ネガティブ・留意点**
- 公式サイト（syousetujuku.com）が403エラーで一般アクセスを制限しており、最新情報の確認が困難
- 口コミの総数が少なく、SNS・口コミサイトでの露出が限定的
- 作風がエンタメ文芸寄りのため、**純文学・心理ドラマへの指導が主軸ではない可能性**がある
- 「実験小説はすでに書き尽くされた」発言のように、前衛・実験的な文体への評価は厳しめ

### 純文学・心理ドラマへの適性

**中程度**。薄井ゆうじ自身は受賞歴からすると大衆文学的な立ち位置。ただし添削は作品の読者体験・構成力の指摘が中心で、心理描写の技法よりも物語構造・読みやすさ重視と思われる。純文学的な実験性・内面性を極めたい場合は合わない可能性がある。

## 2. 島田雅彦監修 純文学講座（公募スクール）

### 講師・監修者プロフィール

**島田雅彦**（1961年生、東京都）
- 東京外国語大学ロシア語学科卒業、法政大学国際文化学部教授
- 1983年「優しいサヨクのための嬉遊曲」でデビュー（大学在学中）
- 受賞歴：野間文芸新人賞、泉鏡花文学賞、伊藤整文学賞、芸術選奨文部科学大臣賞、毎日出版文化賞、読売文学賞
- 代表作：『夢遊王国のための音楽』『彼岸先生』『退廃姉妹』『虚人の星』『君が異端だった頃』
- **芥川賞選考委員**
- 著書『小説作法ABC』（新潮選書）が本講座のテキスト
- **作風**：高度に文学的・哲学的・前衛的。純文学の王道かつ実験性も高い

**添削担当**：「公募スクール講師陣」（具体的な名前は非公開）

### コース・料金

| 受講方法 | 料金 |
|---|---|
| 通常（郵送） | 68,400円 |
| オンライン | 59,400円 |
| オンライン10%OFF | 約53,460円 |
| 郵送10%OFF | 約61,560円 |

- **全9課程、9回添削**
- **受講期間：1年6ヶ月**
- テキスト：『小説作法ABC』（郵送）

### カリキュラム（9課程）

1. ジャンル論（小説のジャンル意識の養成）
2. 構成法（起承転結の理解）
3. 内容決定（キャラクター設定・シーン構成）
4. 人称と視点（視点表現の技法）
5. 対話構成（会話シーンの技術）
6. 描写技法（比喩・表現力向上）
7. トポロジー（場所描写の工夫）
8. 時間軸表現（回想・意識の流れ）
9. 修了課題（5つの条件を満たす短編10枚完成）

### 受講の流れ

1. 申込・入金
2. 受講セット一式が届く（テキスト郵送、ガイド等はメール）
3. 各課程のテキストを読み、課題を作成して提出
4. 公募スクール講師陣が添削・採点して返却
5. 平均4点以上取得 → 島田雅彦の特別講義動画を視聴できる特典

### 添削の内容・具体性

- **添削は公募スクール講師陣が担当**（島田雅彦本人ではない）
- 各課題に採点（点数評価）あり
- 具体的な添削スタイルは非公開で、口コミも極めて少ない
- 「島田雅彦の特別講義動画」は課題平均4点以上で解放される仕組み

### 口コミ・評判

**データの現状**：独立した受講者の口コミ・ブログ記事がほぼ見当たらない。SNS・noteでの言及も非常に限定的。

**構造的な懸念点**：
- 島田雅彦本人は「監修者」であり、日常的な添削には一切関与しない
- 添削担当の「公募スクール講師陣」の名前・経歴が一切非公開
- 採点制（点数評価）が入るため、純文学の実験的表現との相性が不明
- 受講期間が1年6ヶ月と長い

**ポジティブ（公式情報から）**：
- 島田雅彦の理論体系（『小説作法ABC』）が体系的に学べる
- カリキュラムが「ジャンル論→構成→視点→描写→時間軸」と純文学の文法を網羅
- 純文学と明示した講座が少ない中、「純文学」を前面に出した希少な講座

### 純文学・心理ドラマへの適性

**高い（理論面）、不明（実践面）**。テキスト・カリキュラムは純文学に特化。島田雅彦の理論は意識の流れ・視点・時間軸表現など心理ドラマに必要な技法をカバーしている。ただし添削者の素性が不明な点が最大のリスク。

## 3. ムラマサ小説道場（通信）

### 講師プロフィール

**村上政彦**（1958年生、三重県出身）
- 1987年「純愛」で海燕新人文学賞受賞（吉本ばなな と同時受賞）
- **芥川賞5回候補**（1990〜1993年）：『ドライヴしない？』『ナイスボール』『青空』『量子のベルカント』『分界線』
- 映画化：『ナイスボール』→相米慎二監督『あ、春』（1998年）
- 大学で文芸創作の授業を担当した経験あり
- 現在も現役で執筆中（「生きる派」という概念で活動）
- **作風**：純文学・日常的リアリズム。心理描写・人物の内面に根ざした作風

### コース・料金

| コース | 料金 | 内容 |
|---|---|---|
| 基礎コース | 30,000円（税別） | 全10回・月1回添削、受講期間1年 |
| 添削コース | 30,000円（税別） | 添削3回・推敲3回、300枚以内、1年 |
| 基礎＋添削コース | 50,000円（税別） | 基礎修了後に実作添削、受講期間3年 |
| フリープラン | 5,000円/月（税別） | 月1回原稿やりとり＋電話相談30分 |

- 支払い：銀行振込のみ
- 添削コースは「原稿水準が著しく低い場合は受講お断り」あり（基礎コース修了レベルが前提）

### カリキュラム（基礎コース・全10回）

1. 主題
2. 物語
3. 文体
4. 人称・表題・書き出し
5. 場面
6. 描写
7. 語り
8. 会話
9. プロット
10. 人物造形

テキスト：村上政彦著『小説を書いてみよう』の編集版
目標：「『アンナ・カレーニナ』『ボヴァリー夫人』から学ぶ近代小説の文法」

### 受講の流れ

1. 申込・銀行振込
2. テキスト・課題が月1回届く（基礎コース）
3. 課題を書いて提出 → 村上政彦本人が添削して返却
4. 基礎修了後、添削コースで実作添削へ

### 添削の内容・具体性

- **村上政彦本人がマンツーマンで添削**
- 添削コースでは「講師が編集者の役割を担い、アイデア発想→プロット設計→執筆→推敲（最低3回）」まで伴走
- 「どこよりも柔軟な指導が可能」と自称
- 電話相談付き（フリープラン：月30分）
- 特典：道場で書いた作品を電子書籍としてAmazonへ出品可能（別途20,000円・表紙デザイン・校正込）

### 口コミ・評判

**データの現状**：独立した口コミ・ブログが非常に少ない。知名度がやや低く、SNSでの言及も限定的。

**ポジティブ（公式・検索情報から）**：
- 講師本人（芥川賞5回候補の実力者）が直接添削してくれる
- 初心者から明示的に歓迎
- フリープランで電話相談が可能（他2講座にない）
- 近代純文学（トルストイ、フローベール）を軸にした本格的な文学理論

**留意点**：
- 添削コースは「基礎コース修了レベル」が前提で、完全初心者は基礎コースから
- 銀行振込のみ・個人運営感があるため安定性への不安
- 電子書籍出品の特典は別途2万円必要で、純粋な執筆指導の文脈では不要な可能性
- フリープランは月5,000円で続けると年6万円になる点に注意

### 純文学・心理ドラマへの適性

**最も高い**。村上政彦自身が芥川賞候補作家で、日常・内面・人物の心理を扱うリアリズム純文学の実践者。基礎コースのテキストが「アンナ・カレーニナ」「ボヴァリー夫人」であることからも、心理ドラマへの感度が高い。

## 各講座の向き・不向きまとめ

### 薄井ゆうじ 小説塾 — こんな人向き
- 長編・中編を書いていて、一作品丸ごと見てほしい
- 比較的早めに添削を返してほしい（2週間以内）
- 物語構造・読者体験の観点から具体的なフィードバックがほしい
- 自由なペースで不定期に添削を受けたい

**注意**：純文学的な実験性・前衛性を伸ばすよりも、「読まれる小説」の文脈で指導が来る可能性が高い。

### 島田雅彦純文学講座 — こんな人向き
- 島田雅彦の理論（『小説作法ABC』）を体系的に学びたい
- 純文学の文法（視点・時間軸・トポロジー等）を順番に習得したい
- 「島田雅彦監修」のブランド価値を重視する
- 費用を出せる（6万円弱〜）

**注意**：島田雅彦本人から添削を受けられるわけではない。添削者の実力が不明である点はリスク。口コミがほぼないため、実際の添削品質は賭けになる。

### ムラマサ小説道場 — こんな人向き
- 純文学・心理ドラマを徹底的に学びたい
- 芥川賞候補クラスの作家に直接見てもらいたい
- 初心者から基礎体系を積み上げたい
- 近代リアリズム小説（トルストイ、フローベール的）の文法を学びたい
- 電話で相談しながら進めたい（フリープランなら）

**注意**：口コミが少ないため、実際の指導の相性確認が難しい。添削コースは事実上「基礎コース修了後」が前提。

## 調査上の限界と補足

- **薄井ゆうじ小説塾**の公式サイトは403エラーで直接アクセス不可。情報はWebSearch経由の断片から構成
- **島田雅彦純文学講座**と**ムラマサ小説道場**ともに、独立した受講者口コミがほぼ存在しない（SNS・note・ブログで実名レビューがほぼ見つからない）
- 3講座すべてにおいて、添削品質の「実態」を第三者が検証した情報は極めて限られている
- 試しに1作品だけ送れる薄井ゆうじ塾の「1作品完結講座」（2万円〜）で試してみてから判断するのが現実的な選択肢のひとつ
