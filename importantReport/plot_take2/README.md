# plot_take2 — 黒田フィードバック反映版

## 目的

plot_take1 の骨子はしっかりしている。  
しかし黒田の指摘通り、**具体的なシーン・会話・象徴的な場面**が不足しているため、いざ書き出そうとしたときに「一文字目が書けない」状態になっている。

## take2 でやること

各エピソードの穴埋めマークダウンに、以下を書き込んでいく：

1. **象徴的な会話（1〜2往復でOK）** — その章の空気を決定づける台詞
2. **盛り上がりシーンの仮執筆** — 各章で一番書きたい瞬間を、粗くていいから書いてしまう
3. **五感の断片** — 場所・天気・匂い・音など、頭に浮かんだ映像メモ
4. **キャラの身体性** — そのシーンでキャラが何をしているか（手の動き、目線、姿勢）

## 参考：黒田「いちどめの人間」のプロットとの比較

黒田のプロットには各章ごとに：
- **場所**が明確（太呂さんの店、糸原文具店、美容室）
- **会話の断片**がメモされている（「苗字？ 名前？」「どちらでも」）
- **形式**（場面/語り）が指定されている
- **具体的な小道具**がある（スクラッチ、コピック、障害者手帳、試し書きノート）

→ Constrainのプロットにも同じ粒度の情報を足していく。
