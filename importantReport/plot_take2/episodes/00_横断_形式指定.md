# 横断ワークシート：形式（場面 / 語り）

黒田プロットでは各章に「場面」「語り」「場面＋語り」を明記している。  
これがあると書き出すときに「地の文で始める？ 台詞で始める？」で迷わない。

- **場面**：登場人物が動き、会話する。リアルタイム描写。映画のシーンのように書く。
- **語り**：内面描写、回想、時間経過の圧縮。
