# PROLOGUE2.md レビュー — ストーリーコンパイラ準拠

## 総評

「魔法」メタファーによるASD体験の言語化が非常に鮮烈。プロローグとして声（ボイス）の確立に成功している。ただし、構造設計との乖離と、最終行の問題が大きい。

---

## ストーリーコンパイラ検証

### Module 12（情報提示・好奇心駆動）

```
⚠️ warning [W001] 12_exposition: 最終行がテーマの帰結を直接提示している
```

> そんなだった僕が、魔法だらけのニンゲン社会を愛せるようになった話を今から書いていこうと思う。

この一文で読者は「ああ、最終的に受け入れるんだな」と結末を知ってしまう。McKeeの好奇心駆動原則では、**プロローグは問いを開く場所であって、答えを予告する場所ではない**。

v4設定の構造メモでも「なぜ今読んでいるのかは書かない」とあった。この最終行は真逆の方向に踏み込んでいる。

**提案:** 最終行を削除するか、問いのまま閉じる。例えば「友達のいなかった小学生の昼休み、図鑑を眺めながらずっとそんなことを考えていた。」で終わる方が余韻と好奇心が残る。あるいは、大人の樹がこの日記/記憶に触れている「気配」だけを残す（一行の時制変化など）。

### Module 17（象徴・中核イメージ）

```
✅ info [I001] 17_symbolism: シュモクバエが1ページ目に登場 — 配置OK
```

シュモクバエの登場自体は設計通り。ただし現状では「図鑑の表紙に載っていた虫」としてのみ機能しており、**樹自身との重ね合わせがやや弱い**。

v4テーマ設定では「恣意的なルールで生きている小さな虫 ＝ 人間も同じ」が核心。現テキストの「何とも滑稽でアホくさい話だと思った」は良いが、その次の「僕の方がよっぽどアホくさい存在」への接続がやや急。

**提案:** シュモクバエの「目が離れているほどモテる」→ 人間の「空気が読めるほど愛される」という対比をもう一拍置いて描くと、中核イメージの定着が強くなる。

### Module 20（解釈生成レイヤ）

```
⚠️ warning [W002] 20_interpretation: テーマの直接記述
```

「『魔法で通じ合うか、言葉で通じ合うか』それだけの違いをずっと気にしているのだから」— この行はテーマを読者に説明してしまっている。Insight直接記述禁止の原則に抵触。

**提案:** 体験描写で代替する。例えば、休み時間に周りが「魔法」で通じ合っているのを見ている具体的な場面（笑い声、目配せ、自分だけ取り残される感覚）を数行挟むと、読者が自分でテーマを組み立てられる。

### Module 24（鑑識眼・陳腐さ検出）

```
✅ pass [I002] 24_discernment: 「魔法使い」メタファーは新鮮
```

「ニンゲンは魔法を使うようだ」から始まる冒頭は、ASD当事者の認知をファンタジー的な比喩で捉えており、**既存の発達障害文学にはないアプローチ**。カタカナの「ニンゲン」表記も異化効果がある。これは明確な強み。

ただし「落ちこぼれの魔法使い」は既存のファンタジー語彙に近いため、やや陳腐化リスクあり。

## v4設定との整合チェック

### 形式の変更について

設計では「幼少期の日記を大人の樹が読み返す」二重構造だったが、現テキストは「普通にプロローグにしてみた」と一人称直接語りに変更。

**構造的な影響:**

| 観点 | 日記形式（元設計） | 直接語り（現行） |
|------|-------------------|-----------------|
| エピローグとの対句 | 強い（日記 vs 実体験） | やや弱い |
| 「なぜ今読んでいるか」の謎 | 自然に発生 | 発生しない |
| 声の確立 | 二重（幼少期＋大人） | 一重（幼少期のみ） |
| 読みやすさ | やや複雑 | シンプルで入りやすい |

直接語りにした利点（シンプルさ、冒頭の入りやすさ）は確かにある。ただしエピローグとの構造的対応を意識するなら、**大人の樹の存在を最小限（一行程度）示唆する**だけでも対句が復活する。

### 「枠を選びなおせば」の直感

v4設定にあった「枠を選びなおせば何の問題もないのでは、という原初の直感」が現テキストに不在。これはACT5の「第三の選択」（厳密さを捨てるのでも諦めるのでもなく、理解できなくても関わり続ける）の種として重要な伏線。

**提案:** 「ニンゲンという枠から解き放たれれば、どれだけ楽だっただろう」の近くに、うっすらとこの直感を忍ばせる。

## 良い点まとめ

1. **「魔法」メタファーの独創性** — 冒頭一行で世界の見え方が確立する
2. **カタカナ「ニンゲン」の異化効果** — 樹の認知的距離感が文字面で伝わる
3. **シュモクバエへの接続が自然** — 「魔法が使えない→昆虫の方が楽しい→図鑑→シュモクバエ」の流れに無理がない
4. **「中途半端な存在でいるくらいなら」の切実さ** — ただしあんずの自死との共鳴に注意（下記）

## 注意点

- 「ニンゲンを辞めてしまいたかった」は、あんずが実際に死を選ぶ物語で、冒頭から自殺的な響きを持つリスクがある。樹の場合は「種を変えたい」（人間→昆虫になりたい）という文脈なので、そのニュアンスをより明確にすると安全。
- 「はしごを与えてくれないニンゲン社会」— 「はしご」比喩がやや唐突。「言葉というはしご」の導入が一文前にあるが、「はしごを与えてくれない」だと社会が言葉を与えないように読める。樹の問題は「言葉以外の通信手段（魔法）を持たない」ことなので、比喩の方向がずれている可能性。

## 改善案の方向性（3パターン）

### A案: 最終行カット（最小修正）
最終行を削除し、「図鑑を眺めながらずっとそんなことを考えていた。」で閉じる。好奇心を開いたまま本編へ。

### B案: 日記フレーム復活（設計準拠）
冒頭に「古い日記が出てきた。」程度の一文を置き、最後に「…と、書いてある。」で大人の樹の存在を一瞬だけ見せる。エピローグとの対句が復活。

### C案: 「枠」の直感を追加（テーマ伏線強化）
シュモクバエの描写の後に、「枠が違えば、アホくさいのは向こうかもしれない」程度の一文を追加。ACT5の第三の選択への遠い伏線になる。

**個人的推奨: A案 + C案の組み合わせ。** 最終行を切り、「枠」の直感を静かに置く。シンプルかつテーマの種が撒かれる。
