## 案A：樹主軸型

```
樹: 15シーン / 秀斗: 5シーン / あんず: 0シーン
```

**設計思想:** 樹の一人称がデフォルト。秀斗は家庭内の場面（樹が知り得ない場面）だけ視点を渡す。あんずには視点を渡さない。

**メリット:**
- 樹の認知フィルター（ASD的な知覚順序、感情の遅延）を一貫して体験できる
- あんずの内面を隠すことで、「読者も樹と同じ情報量」→ 後から真実を知る衝撃が最大化
- 「デートの夜、あんずの側で何が起きたか」を読者に見せないことで、ACT5のフラッシュバック時に初めて補完される構造

**デメリット:**
- あんずの自殺シーン（S4）を樹視点で書くと「報せを聞く」だけになり、あんず側の経路が描けない
- 「善意が人を殺す」構造の①を体感させにくい

**あんずの自殺の処理:**
- 樹が翌日/数日後に知らされる → 情報の断片だけ。真実はACT5で回想として明かす
- あるいはエピローグ的に短い三人称挿入（一人称の例外）

## 案B：均等3視点型

```
樹: 11シーン / 秀斗: 6シーン / あんず: 3シーン
```

**設計思想:** 3人の「僕」「俺」「わたし」が交互に語る。あんずにも視点を渡し、デートと死を彼女の目で描く。

**メリット:**
- あんずの内面（性的虐待→樹の手→死への経路）を直接描ける → 読者の情動が最大
- 「善意が人を殺す」三重構造を3人の視点から立体的に見せられる
- デートシーンがあんず視点になることで、樹の無自覚な優しさが外側から見える

**デメリット:**
- あんずの一人称をどう書くか（知的障害の描写＋一人称の語彙制約）が技術的に難しい
- 読者があんずの情報を持つ → 樹より先に真実を知る → 「樹が気づけなかった」ことへの苛立ちorドラマティックアイロニー
- 視点が3つあると読者の感情移入先が分散するリスク

**あんず視点の書き方候補:**
- 語彙を限定（短文、感覚的、抽象語を避ける）
- 「手」のイメージだけで内面を描く
- 思考よりも身体感覚を主体にする

## 案C：対比重視型

```
樹: 12シーン / 秀斗: 5シーン / あんず: 3シーン
```

**設計思想:** 「同じ出来事を別の目で見る」対比を最大化する配置。あんず視点はACT2の出会い〜死に集中。いじめの過激化は樹視点に戻し、「��斗の暴力を樹がどう処理するか」を見せる。

**メリット:**
- ACT2の核心部分（出会い→デート→死）をあんず視点で一気に描ける → 読者があんずの側に入る
- ACT1-S3（いじめの開始）を樹視点にすることで、「なぜ樹は秀斗の攻撃を分析対象として見るか」が内側から見える
- ACT5-S1（自殺未遂）を樹視点に固定 → 「今度こそ間に合う」の切迫感

**デメリット:**
- あんず視点がACT2に集中するので、あんずの出番が「ブロック」になる → 視点切り替えのリズムが偏る可能性

**特徴的なポイント:**
- ACT2-S1をあんず視点にする → 「あんず係」という仕組みを、あんず側から見せる。樹が来たときの安堵を描ける
- ACT2-SUB「いじめの過激化」を樹視点にする → 秀斗の暴力を樹がノートに記録する冷徹さを内側から見せる

## 判断のポイント

| 問い | 案A寄り | 案B/C寄り |
|------|---------|-----------|
| あんずの死の経路を**直接描きたいか** | 描かない（ACT5回想で明かす） | 描く（S4であんず視点） |
| 読者に**ドラマティックアイロニー**を与えたいか | 与えない（樹と同じ情報量） | 与える（読者はあんずの真実を知る） |
| あんずの一人称の**技術的チャレンジ**を引き受けるか | 回避 | 挑戦 |
| 樹の**認知フィルター**の一貫性を重視するか | 重視 | 部分的に手放す |
