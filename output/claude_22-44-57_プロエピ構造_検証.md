# プロローグ/エピローグ構造のストーリーコンパイラ検証 + 執筆順序の検討

---

## 1. 検証対象の構造（確定版）

```
プロローグ ： 幼少期の樹の日記を大人の樹が読み返す。
            シュモクバエと自分についての内的独白。
ACT1〜ACT5 ： 本編（時系列）
エピローグ ： カカメガの森（ケニア）でシュモクバエを見つけて笑い合う。
```

---

## 2. ストーリーコンパイラによる検証

### 2-1. `12_exposition.yaml` — 好奇心駆動の原則

> 情報は「読者が知りたい」状態で提示すべき。答えを先に出し、問いを後にするのは逆。

**判定: ◎ 好奇心駆動に完全に合致**

プロローグで幼少期の日記（シュモクバエへの独白）を見せると、読者は：
- 「シュモクバエって何？ なぜこの子はこんなことを考えている？」
- 「この日記を読み返している大人は、今どんな状態なのか？」
- 「なぜ今このタイミングで読み返しているのか？」

という**問い**を抱えて本編を読み始める。ACT1でシュモクバエが図鑑に出てきた瞬間、「プロローグの日記はこの頃のものか」と**接続**する。ACT5で航空券を買う瞬間、「あの日記の独白がここに繋がるのか」と全てが繋がる。

さらに、「日記を読み返す大人の樹」の存在が、読者に**物語全体を俯瞰する視点**を与える。「この子は大人になったのだ」という安心感と、「どうやって大人になったのか」という好奇心が同時に生まれる。

### 2-2. `17_symbolism-and-image.yaml` — 中核イメージの配置

> 中核イメージは物語の最終的な価値状態の結晶。構造の収束から自然に生まれなければならない。

**判定: ◎ 構造的収束がある**

エピローグの「カカメガの森で笑い合う二人」は、ACT1〜5の全ての苦しみを経た後の到達点。プロローグの日記（幼少期の孤独な独白）と対になることで、物語が「一人の内的独白」から「二人で笑い合う」へ移行したことが構造として浮き彫りになる。

スコア:
- `value_finality_alignment`: 高。笑いは最終価値状態（受容）の体現
- `controlling_idea_embodiment`: 高。テーマが**説明ではなく行動（笑い）**で体現
- `structural_convergence`: 高。プロローグの日記 → ACT1の図鑑 → ACT5の航空券 → エピローグのケニア
- `emotional_compression`: 高。過去の苦しみが「笑い」一点に圧縮される

**プロローグ＝日記にしたことの追加効果**:

シュモクバエの象徴が物語の**最初の1ページ目**から配置される。読者は物語を読み終えた後、プロローグを読み返したくなる。「あの日記の言葉は、こういう意味だったのか」——この再読衝動は中核イメージが正しく機能している証拠。

### 2-3. `03_climax-rules.yaml` — クライマックスとの関係

> クライマックスの価値変化は不可逆でなければならない

**判定: ◎ 問題なし（旧構造の懸念も解消）**

旧構造（プロローグ＝ケニア）では「秀斗が生きていることがバレる」懸念があった。日記構造ではこの問題が**完全に消失**する。

- プロローグには秀斗が登場しない → ACT5の自殺未遂の緊張感が100%維持される
- 「日記を読み返す大人の樹」が何を思っているかは描かれない → クライマックスの衝撃を先取りしない
- エピローグのケニアは**クライマックスの後**に来るので、ネタバレリスクゼロ

### 2-4. `18_tension-dynamics.yaml` — テンションの設計

> 物語のリズムは緊張と弛緩の交互配置で成り立つ

**判定: ◎ テンション設計として優秀**

```
プロローグ（静・内省）→ ACT1-4（上昇）→ ACT5（最大緊張）→ エピローグ（弛緩・開放・笑い）
```

プロローグが「静かな内省」であることで、ACT1の孤立やACT2のあんずの死との間に**トーンの連続性**が生まれる。旧構造（ケニアの森＝陽気）ではACT1との落差が大きすぎる懸念があったが、日記の静けさなら本編への移行が自然。

そしてエピローグが「ケニアでの笑い」であることで、物語全体が**暗い夜から明るい朝へ向かう弧**を描く。読者は最後に深呼吸して本を閉じることができる。

### 2-5. `13_scene-transition.yaml` — 時間構造の整合

> フラッシュフォワード/フラッシュバックは読者の好奇心を生むが、ネタバレリスクがある

**判定: ◎ 問題なし**

日記構造はフラッシュフォワードではなく**フレーム（額縁）構造**。

- 「大人の樹が日記を読み返す」＝現在時点のフレーム
- ACT1〜5＝本編
- エピローグ＝フレームの閉じ（本編の後の時間軸）

この構造は純文学で広く使われる伝統的手法であり、時間的混乱は生じない。読者は「この人物の過去を追体験している」と自然に理解する。

旧構造にあった「秀斗生存バレ」の問題は完全に解消。時間構造に関する懸念はゼロ。

### 2-6. `05_controlling-concept.yaml` — 統制概念との整合

> 統制概念は物語の冒頭と結末の間で体現される弧である

**判定: ◎ 完全に整合。むしろ旧構造より強い**

プロローグとエピローグが**対句構造**になる：

| | プロローグ | エピローグ |
|---|---|---|
| 時間 | 幼少期（回想） | 物語の後（未来） |
| 場所 | 日本のどこか（内面世界） | カカメガの森（外の世界） |
| 人数 | 樹一人 | 樹＋秀斗 |
| 行為 | 内的独白（考える） | 笑い合う（感じる） |
| シュモクバエ | 図鑑の中の知識 | 目の前にいる実物 |
| テーマ | 「枠を選びなおせば…」（仮説） | 「あほやな」（受容） |

この対句がそのまま統制概念の弧を体現している：
- プロローグ：「理解すれば救える」の萌芽（論理で世界を切る少年）
- エピローグ：「理解できなくても笑える」の到達（論理を手放した大人）

**エピローグの注意点**:

エピローグは「笑い」で終わるのが最も強い。内的独白は入れないほうがいい（それはプロローグの仕事）。エピローグは**行動と感覚だけ**で書く：湿度、虫の音、笑い声、シュモクバエの小ささ。

## 4. プロローグ/エピローグを最初に書くのはアンチパターンか？

### 答え: **アンチパターンではない。むしろ推奨される手法**

#### 根拠1: 黒田レビューとの整合

plot.drawioの「執筆アドバイスまとめ」にこうある：

> アドバイス③ 書くとしたらクライマックスかエピローグを先に。読後感の設計→逆算。
> 黒田レビュー(2026-04-12)：イメージがついているところから書けるところから始める。まずパーツを作ってみる。剪定は後から。

プロローグ（日記）やエピローグ（ケニア）を最初に書くことは、黒田アドバイスの「読後感の設計→逆算」に**完全に合致**する。

#### 根拠2: McKee理論的にも正しい

McKeeは「クライマックスから逆算して設計する」ことを推奨している（`03_climax-rules.yaml`）。エピローグはクライマックスの直後であり、「この余韻にたどり着くためにACT1〜5で何を積み上げるべきか」を逆算する基点になる。

#### 根拠3: この構造の場合の特殊な利点

- **プロローグ（日記）を書くことで、幼少期の樹の「声」が決まる** → 一人称の文体・語彙・リズムが確立する → ACT1の基準ができる
- **エピローグ（ケニア）を書くことで、「ゴール地点の絵」が手元にある状態で本編を書ける** → 書きながら迷わない
- **プロローグの日記のトーンが、この小説全体のトーンを決める** → 「重すぎる」のか「軽やかさもある」のかの判断基準
- **日記という形式は短い** → 着手のハードルが低い。書き始めの摩擦が最小

#### 根拠4: 歴史的前例

多くの文学作品がエピローグやラストシーンから書かれている：
- 村上春樹は「最後の一文」を先に決めてから書き始めることがある
- フィッツジェラルドは『グレート・ギャツビー』のラスト（「我々はこうして舟を漕ぎ続ける」）を早い段階で書いた
- 映画脚本では「ラストシーンから逆算」は標準的な手法

#### 注意点

- 先に書いたプロローグ/エピローグに**縛られすぎない**こと
- ACT1〜5を書く過程でトーンが変わる可能性は大いにある → 「剪定は後から」（黒田）
- 最初に書いたものは「方角を示す灯台」であり、「到着地点」ではない

#### 執筆順序の提案

```
① プロローグ（幼少期の日記）→ 樹の声とトーンの確立。最も短く書きやすい
② エピローグ（ケニアの場面）→ ゴールの絵。笑いのトーンを掴む
③ ACT5のクライマックス（航空券＋「辛かったやろ」）→ 最大の山場
④ ACT2のあんずの死（引き金）→ インパクトのある場面
⑤ 以降は書けるところから
```

**これは完全に黒田アドバイス「1シーケンス/1weekで進めていく」と両立する。**
