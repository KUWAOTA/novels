# デートシーン（ACT2-S3）視点構成案

## 前提

「同じシーンを1視点で書く」に縛る必要はない。
McKee `23_character_components` の multi_viewpoint_processing は
「同一の出来事を複数の視点から解釈し、その解釈の癖がキャラクターを形成する」と規定している。
デートシーンはこの原理が最も効く場所。

---

## 案① あんず単独視点（現行C案）

```
S3: あんず視点のみ
```

- あんずの sensation で石切公園を描く
- 樹は「あんずの目に映る樹」としてだけ存在
- **利点:** シンプル。あんずの内面に没入。「手」の象徴が最大化
- **欠点:** 樹がこの時間をどう過ごしたかが見えない。デートの「温度差」（あんず＝人生最高 / 樹＝楽しいけど恋愛ではない）が片面だけ

---

## 案② 樹→あんず（前半後半分割）

```
S3a: 樹視点（デートの行き〜石切公園）
S3b: あんず視点（石切公園〜帰路）
```

- 前半は樹の分析的な語りで始まる。「あんずが珍しく僕を誘った。なぜだろう」
- 石切公園の夜景を樹が見る → 光の美しさを「データ」として処理
- 後半であんず視点に切り替わる → 同じ夜景がsensationとして立ち上がる
- あんずが手に触れようとして止める → 帰路の sensation
- **利点:** 同じ風景の見え方の違いが対比として機能。樹の「見えなさ」が構造的に証明される
- **欠点:** シーン内の視点切り替えは McKee 的には原則NG（連続する時空間＝1視点）。ただしシーンを分割（S3a / S3b）すれば回避可能

### コンパイラ評価

```
19_scene-mastery:
  before/after 対比が「視点の切り替え」自体で発生する（高品質）
  同じ夜景の二重描写 → symbolic_density_growth が上昇

23_character_components:
  multi_viewpoint_processing の直接的実装
  樹の「解釈の癖」とあんずの「解釈の癖」が同一事象で対比
  → キャラクターの立体化が最大

12_exposition:
  あんずの内面情報がデートの後半で自然に露出
  contextualization_score: 高い（行動の中で出る）
```

## 案③ あんず→樹（前半後半分割）

```
S3a: あんず視点（デートの準備〜石切公園の到着）
S3b: 樹視点（石切公園〜帰路の分岐点）
```

- あんず視点で「出かける」ことの重さを描く（家を出る恐怖、期待、服を選ぶ sensation）
- 石切公園に着いたら樹視点に切り替わる
- 樹の目にはあんずが「いつもより少し違う」程度にしか映っていない
- 帰路、あんずが「帰りたくない」と小さく言う → 樹は「遅くなるし帰ろう」と返す
- **利点:** あんずの「準備」の切迫感が描ける。帰路の分岐点で樹が「帰りたくない」を聞き流す瞬間が、「言葉の限界」を体現する
- **欠点:** クライマックス（手に触れようとするシーン）が樹視点になるので、sensation の密度が落ちる

### コンパイラ評価

```
05_controlling-concept:
  「帰りたくない」を樹が聞き流す
  → 統制概念の核心：「厳密な言語」の外にある訴えを受け取れない
  → 非常に高い整合性

14_causal-chain:
  あんずの「帰りたくない」→ 樹が流す → あんずが死ぬ
  → 因果鎖が樹の視点内で成立（樹自身はACT5まで気づかない）
  → ドラマティックアイロニーの種

24_discernment:
  「帰りたくない」が中学生の何気ない言葉に見える
  → 読者もこの重さに気づけるか？
  → S1（あんず視点）で虐待の示唆を読んだ読者だけが気づく構造
```

## 案④ 交互カット（短いビート単位で視点交替）

```
S3: あんず→樹→あんず→樹→あんず（ビート単位で交互）
```

- 同じ瞬間を2人の目で交互に描く。映画的クロスカット
- 例：
  - [あんず] 手に触れようとする → 止める
  - [樹] あんずの手が動いた気がした → 気のせいだろう
  - [あんず] 夜景がきれい。この人と一緒にいられる
  - [樹] 「きれいだね」と言うべきか。言語化する必要性を計算する
- **利点:** 二人のズレがリアルタイムで浮き上がる。最も映画的で緊張感が高い
- **欠点:** 一人称で交互カットは技術的に非常に難しい。読者が混乱するリスク。「僕」「わたし」が交互に来る構造の読みにくさ

### コンパイラ評価

```
19_scene-mastery:
  variety_score: 最高（視点が常に動く）
  ただし rhythm_and_tempo が不安定になるリスク

23_character_components:
  multi_viewpoint_processing の最大実装
  ただし「解釈の癖の一貫性」が短いビートでは確立しにくい

16_choice-and-expression:
  テキスト表現の難易度が最も高い
  読者の認知負荷が高い → 没入を妨げる可能性
```

## 案⑤ あんず単独 + 樹の回想（ACT3 or ACT5で）

```
S3: あんず視点のみ（現行）
ACT3 or ACT5 に「樹の回想としてのデート」を別シーンとして配置
```

- デートをリアルタイムではあんず視点だけで描く
- ACT3（使命の確信）or ACT5（秀斗の自殺未遂後）で樹がデートを回想する
- 同じ出来事が時間差で二重に描かれる → 回想時に「あの時あんずが手を伸ばしたのは…」と樹が初めて意味を与える
- **利点:** 情報ペーシングが最良。ACT2では感覚体験、ACT5で意味が再構成される。`13_scene-transition` のフラッシュバック制約を完全に満たす（現在の行動の意味を再定義する）
- **欠点:** デートシーンの「樹側」がかなり遅れて来る。リアルタイムの対比は失われる

### コンパイラ評価

```
13_scene-transition:
  flashback_usage_rules を完全に満たす：
    redefines_present_meaning: true（デートの意味が変わる）
    shifts_value_state: true（樹の認識が変わる）
    alters_audience_interpretation: true（読者のデートの記憶が書き換わる）
  → 最も構造的に強いフラッシュバック

12_exposition:
  information_pacing: 最良
  ACT2で sensation（低importance表現）
  ACT5で 意味の再構成（高importance）
  → importance_curve_monotonicity が完璧に上昇

20_interpretation-layer:
  読者はACT2でデートをあんずの目で体験
  → ACT5で樹の目で「同じシーン」を見直す
  → 読者の中で意味が再構成される（insight_engine の理想形）
```

## 案⑥ あんず→樹（S3→S3'、同一時間帯を2シーンとして）

```
S3:  あんず視点（デート全体）
S3': 樹視点（同じデートを樹の目で）
```

- 完全に同じ出来事を2回、別の視点で書く。「羅生門」方式
- S3であんずの sensation を体験した直後に、S3'で樹の分析的語りを読む
- **利点:** 対比が最大限に効く。読者は「同じ出来事がこんなに違って見えるのか」を体験する。統制概念の直接的証明
- **欠点:** 同じ出来事を2回読む冗長感。物語の推進力が止まる。McKee 的にはシーンは前進しなければならない（value_change が2回同じ方向に動く？）

### コンパイラ評価

```
01_core-structure:
  2つのシーンが同じ value_change を持つのは scale_violation の可能性
  → ただし value_axis が異なればOK：
    S3 (あんず): 愛⇔孤独 が動く
    S3'(樹):    理解⇔誤解 が動く（「楽しかったけどよくわからない」）
  → 軸を分ければ構造的に正当化可能

05_controlling-concept:
  統制概念の最も直接的な体現
  「言葉の人」と「言葉を持たない人」が同じ出来事をどう処理するか
  → これが物語の全テーマ
```

# 推奨

**書きやすさ・構造的品質・統制概念の三点で、案⑤が最もバランスが良い。**

- ACT2ではあんず視点で没入する（sensation 体験）
- ACT5で樹が同じデートを回想する（意味の再構成）
- 「同じ出来事が時間差で二重に描かれる」構造は、
  13_scene-transition / 20_interpretation-layer の要件を完璧に満たす

**ただし、対比の強さを最優先するなら案② or ③。**
特に案③の「帰りたくない」を樹が聞き流す構造は、統制概念の核心を1シーンで体現する。

**案⑤ + 案③の「帰りたくない」だけ借りる混合案:**
- S3a: あんず視点（デートの準備〜石切公園〜手に触れようとする）
- S3b: 樹視点（帰路の分岐点。あんずが「帰りたくない」→ 樹が流す）
- ACT5: 樹の回想でデートの意味が再構成される

これなら sensation の没入と「聞き流し」の両方が入る。
