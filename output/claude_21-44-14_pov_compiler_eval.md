### ❌ E001 `12_exposition` — あんずの性的虐待の情報到達が構造的に不可能

あんず視点がゼロのため、性的虐待の事実を読者に提示する手段が構造的に欠如する。

```
現状の情報到達経路：
  樹視点 → 樹はあんずの虐待を知らない → 読者も知らない
  秀斗視点 → 秀斗もあんずの虐待を知らない → 提示不可

必要な情報:
  ・あんずが性的虐待を受けていること（importance_score: 0.95）
  ・デート後に「これは優しさじゃない」と初認識すること
  ・「手」の対比（樹 vs おじさん）
  ・自殺に至る内的経路

→ これらを「説明」で処理すると 12_exposition の
  contextualization_score が壊滅的に低くなる（< 0.3）
→ ACT5回想で処理する場合、13_scene-transition の
  flashback_usage_rules は満たせるが、
  ACT2時点での読者の情動体験がゼロになる
```

**ユーザー所感と一致:** あんずの一人称描写がないと性描写が難しい。
**構造的にも同結論:** 第三者の語りや説明で性的虐待を処理すると、
`24_discernment` の `authorial_dishonesty`（作者の不誠実）に抵触する。
被害の当事者を通さず加害の事実だけ提示するのは、構造的な嘘。

**修正指針:** あんず視点を最低1〜2シーン入れるか、案Aを断念する。

### ⚠️ W001 `23_character_components` — あんずの一人称の語彙制約と `characterization` 技法

```
あんずは知的障害を持つキャラクター。
一人称で語らせる場合、characterization の5分類：
  physical / mannerism / social / personality / intellect
のうち intellect に強い制約がかかる。

技法的リスク：
  ・語彙を限定しすぎると「記号的な障害者」になる
    → 24_discernment の lifeless_character 検出
  ・語彙を広くすると設定と矛盾する
    → 06_protagonist の credibility_rule 違反

推奨アプローチ：
  身体感覚（sensation）を主体にする。
  23_character_components の emotion_vs_sensation 区分：
    sensation: 急性・局所的・身体に紐づく（手の温度、匂い、光）
    emotion: 慢性・全身的・名前がつく（悲しみ、怒り、愛）
  → あんずは sensation で語り、emotion の名前を与えない
  → 読者が sensation から emotion を再構成する
  → 20_interpretation-layer の「読者による再構成」と整合
```

# 結論

**案Aは `compile_error` が出る。** あんずの性的虐待をあんず視点なしで処理するのは、
`12_exposition`（情報到達の構造的不可能）と `24_discernment`（不誠実な回避）の両面で破綻する。
ユーザーの直感（「あんずの１人称描写がないとさすがに性描写難しいのでは」）はコンパイラ的にも正しい。

**案Bと案Cの差は小さい。** 主な違いは：
- ACT2-S1（あんず係）を誰で書くか（案B: 樹 / 案C: あんず）
- ACT2-SUB（いじめの過激化）を誰で書くか（案B: 秀斗 / 案C: 樹）
- ACT5-S1（自殺未遂）を誰で書くか（案B: 秀斗 / 案C: 樹）

**案Cが warning 最少かつ統制概念との整合が最も高い。**
ただし案BのACT5-S1を秀斗視点にする選択も、秀斗の実像露呈として有効。
→ 案Cベースで、ACT5-S1の視点だけ検討の余地あり。
