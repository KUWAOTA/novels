# S4 v2 プリント散乱シーンへの接続案

対象:
`diopsidae/本文/ACT1/SEQ2_父との絆と喪失/S4_父から仮説を学ぶ/v2/本文.txt`

## 現在の末尾

```text
シーツのしわが、孝則の指の下で少し戻った。
傾いていた体が、ゆっくりベッドへ沈んだ。
孝則は、まだ樹を見ていた。
樹は肩紐を戻そうとして、肘を動かした。
```

ここからプリントへつなぐなら、**樹が肩紐を戻そうとする動作で、ランドセルの口が開いていることに気づく**のが自然です。

父が先にプリントを見つけるより、樹の身体動作から「こぼれている」へ移るほうが、今の視点と文体に合います。

## 接続の基本順

おすすめの順番はこれです。

```text
肩紐を戻そうとする
→ ランドセルが肘に引っかかる
→ ふた、または留め具が外れている
→ 教科書・筆箱などがずれる
→ 紙が一枚出る
→ それが一枚ではなく、ばらばらのプリントだとわかる
→ 孝則の視線がそちらへ移る
→ でも孝則はすぐに聞かない
```

大事なのは、プリントをいきなり「問題の紙」として出さないことです。  
最初はただの散らかった荷物として出して、樹が拾おうとしたときに、破れ方や赤い跡などで意味が立ち上がるほうがよいです。

## 採用候補

今の末尾にそのまま続けるなら、これが一番使いやすいと思います。

```text
樹は肩紐を戻そうとして、肘を動かした。

ランドセルが、背中でかたむいた。
金具の外れたふたが、肘の下でぱたんと開いた。

教科書の角が床に当たった。
筆箱がその上をすべって、赤い下敷きが半分だけ出た。

その下から、紙が一枚、遅れて落ちた。
一枚だと思った。

けれど床に当たると、紙は二つに分かれた。
もう一つ、折れた端がランドセルの口から出てきた。

樹はそれを見た。
拾わなければ、と思った。
```

この形の利点は、プリントが「ばらばらだった」と説明せず、床に落ちた瞬間に分かれることで見せられる点です。  
また、父の視線をまだ入れていないので、まず樹の反応を優先できます。

## 孝則の視線まで入れる版

父とのシーンとして機能させるなら、上のあとにこう続けるとよいです。

```text
孝則の目も、床へ下りた。

教科書でも、筆箱でもなく、二つに分かれた紙のところで止まった。
それでも孝則は、手を伸ばさなかった。
名前も、理由も、すぐには聞かなかった。

樹は先に、破れた端を重ねようとした。
```

ここで孝則が「それどうしたんや」とすぐ聞くと、追及に見えます。  
まず「見ているが、奪わない」「気づいているが、急かさない」にすると、さっきの安堵の描写と同じ父の態度でつながります。

## もっと短い版

テンポを優先するなら、ここまで削れます。

```text
樹は肩紐を戻そうとして、肘を動かした。

ランドセルのふたが、背中でぱたんと開いた。
教科書と筆箱が床にすべり、赤い下敷きがその横で止まった。

最後に、紙が落ちた。
床に当たって、二つに分かれた。

孝則の視線が、そこへ下りた。
樹はあわてて手を伸ばした。
```

これはかなり扱いやすいです。  
散乱の映像だけを置いて、プリントの事情は次の会話へ送れます。

## 樹の恥ずかしさを強める版

プリントが裕子との出来事につながるなら、樹の「見られたくない」を少しだけ入れるのもありです。

```text
樹は肩紐を戻そうとして、肘を動かした。

ランドセルのふたが開いた。
中に押しこんでいたものが、順番をなくして床へ出た。

教科書。
筆箱。
赤い下敷き。

それから、破れたプリント。

樹は反射的に手を伸ばした。
けれど、指が触れる前に、もう片方の紙片がランドセルの口からすべり落ちた。

孝則の目が、そこへ下りた。
```

「順番をなくして床へ出た」は、少しだけ情緒があります。  
荷物の散乱と、樹の中の整理できなさが重なります。

## おすすめ

おすすめは「もっと短い版」です。

理由は、今の本文がかなり乾いた動作描写で進んでいるからです。  
ここでプリントの意味を説明しすぎるより、

```text
ランドセルが開く
物が落ちる
紙が二つに分かれる
孝則が見る
樹が手を伸ばす
```

だけ置いたほうが、次の会話が生きます。

## その後の会話への入り方

孝則の第一声は、問い詰めではなく、紙の状態をそのまま見る言葉がよいです。

候補:

```text
「破れたんか」
```

または、

```text
「それ、直すんか」
```

「どうしたんや」は少し尋問に寄ります。  
父らしさを出すなら、事情ではなく、まず樹が今しようとしていることを見るほうが合います。

たとえば続きはこうです。

```text
樹はあわてて手を伸ばした。
二つに分かれた紙を、もとの形に戻そうとした。

「それ、直すんか」

孝則は、紙ではなく、樹の手を見て言った。
```

これなら、孝則はプリントを事件として扱わず、樹の行為を受け止める父として出せます。
