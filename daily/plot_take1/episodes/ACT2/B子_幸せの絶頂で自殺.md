# ACT2 — B子：★ デート後の自殺【設定更新済】

**プロット要素:** B子は家庭内で日常的に性的虐待を受けていた。知的障害のため「これが普通」と受容していた。主人公とのデートで初めて「本当の優しさ」を体験し、帰宅後の虐待との対比が生じ、「もう帰りたくない」という単純な拒絶として死を選ぶ。
**役割:** 主人公の善意（デート）自体が引き金になった構造。主人公はこの真実を知らず「苦しみの末に死んだ」と誤解し、「厳密な言語があれば救えた」という誤信念を確立する。

## エピソードメモ

- B子は家庭内で日常的に性的虐待を受けていた（虐待者は要設定：父親 or 母親の交際相手 等）
- 知的障害のため、虐待を「異常」と認識できず耐え続けていた
- 主人公とのデートで初めて「本当の優しさ」「本当の好き」を体験
- 帰宅後、虐待が始まる → 今までと違い「嫌だ」「違う」と感じてしまう
- しかし知的障害のため、助けを求める言葉を持たない。逃げ方もわからない
- → 「もう帰りたくない」という単純な感情から死を選ぶ
- 死は哲学的判断ではなく、本能的な拒絶

### 構造的な意味

- **善意が人を殺す構造**：デートがなければ、B子は虐待を「普通」のまま受け入れ続けていたかもしれない
- **ACT4との並行**：主人公がA男に「教育」という善意で加害するのと同じ構造
- **主人公の誤解が二重に的外れ**：
  - B子を殺したのは「社会の無理解」ではなく家庭内の性的暴力
  - 「厳密な言語」があっても、この問題は解決しない
  - 主人公が立てた全人生の前提が根本から的外れ

### B子の家庭環境（確定）

- **母親**：知的障害気味（望まぬ出産）。自分に似て馬鹿な娘がなんとなく嫌い、お荷物扱い
- **母親の交際相手**：B子に対して性的に利用するために「優しいふり」をして洗脳。恋人になる気はない。B子にとって唯一「優しくしてくれる人」
- → B子は「優しさ＝性的な関係」と刷り込まれている

### 「偽の優しさ」と「本当の優しさ」の対比（核心）

1. **交際相手の偽の優しさ**：性的搾取のための手段。B子はこれを「愛」と思い込んでいる
2. **主人公の本当の優しさ**：デートでの体験。厳密でキツい言い方だが、搾取がない
3. **B子が主人公を性的に誘う描写**：「優しさ＝こういうこと」という刷り込みから、主人公にも同じことをしようとする
4. **主人公の反応**：照れ隠しから「大切な人とするのは付き合ってからだよ」と断る
5. → B子は初めて「優しさの中に性的なものがない関係」を知る
6. → 交際相手がしてきたことは「優しさ」ではなかったと気づく
7. → 帰宅して交際相手の「いつもの優しさ」が始まる → 「もう嫌だ」

### 未設定事項へのアイデア

**虐待の事実が明かされるタイミング：**
ACT2でB子視点の章を挟み、読者にだけ見せるのがベスト。主人公には最後まで明かさない（or ACT5で初めて知る）。主人公がACT5で真実を知った時、「全人生の前提が間違っていた」が二重に刺さる。

**B子が主人公を誘う描写のトーン：**
暗示的がいい。B子が主人公の手を自分の体に導こうとする。主人公が手を引っ込める。B子がキョトンとする。「……しなくていいの？」「大切な人とするのは付き合ってからだよ」。——この **「しなくていいの？」** に全てが詰まっている。読者はこの一言で家庭の状況を察する。

**台詞の洗練：**
「せのくんのものでいたい、帰りたくない、よごされたくない」——知的障害の子の言語で書くなら、もっとシンプルに。「せのくんのところにいたい。おうちいやだ。」くらいの方がリアルで刺さる。

脂ぎった手と細い白い手の交差→嘔吐。これは映像として強い。B子の内面描写としてデート帰りの電車内で使えば、飛び込みへの導線になる。
