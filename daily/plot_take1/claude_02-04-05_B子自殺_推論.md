# B子の自殺の「筋が通る設定」— 推論

## メモから抽出した制約条件

1. **知的障害のB子にできること**（「頭がいい発想」ではない）
2. **性的描写が絡む**
3. **B子は自分の意志で死ぬ**
4. **学校以外のB子の側面**にスポットライト
5. **デート直後に死ぬこととマッチ**
6. **かなり胸糞悪い**
7. **つじつまが合う**

---

## 推論：家庭内での性的虐待

**B子は家庭内で日常的に性的虐待を受けていた。**

### なぜこの設定がすべての制約を満たすか

#### 「頭のいい発想ではない」→ ✓
「今が最高点だから死ぬ」は哲学的な判断で、知的障害の子には不自然。だが **「もう嫌だ」「もう帰りたくない」** という単純な拒絶感情なら、知的障害があっても自然に生じる。高度な論理は不要。ただ「もう耐えられない」だけでいい。

#### 性的描写が絡む → ✓
そのまま。家庭内での性的虐待（父親、あるいは母親の交際相手など）。

#### 自分の意志で死ぬ → ✓
誰かに追い詰められて死ぬのではなく、「あの家に帰るくらいなら」という自発的な選択。

#### 学校以外の側面 → ✓
学校では「いじめられている子」「保健室にいる子」としてしか見えないB子の、**家庭での地獄**にスポットライトが当たる。

#### デート直後とマッチ → ✓ （ここが核心）
主人公とのデートで、B子は**生まれて初めて「本当の好き」「本当の優しさ」を体験した**。その幸福が、帰宅後に待っている性的虐待との**対比**を生じさせた。

今までは「これが普通」だと思えていた（あるいは言語化できなかった）ものが、デートの体験を通じて初めて **「違う」「嫌だ」** と認識できてしまった。でも知的障害があるから、誰かに助けを求める言葉を持たない。逃げ方もわからない。できることは一つだけ。

#### 胸糞悪い → ✓
言うまでもなく。

#### つじつまが合う → ✓
以下の全体構造と完全に噛み合う。

---

## 物語全体との整合性

### 1. 主人公の誤解がより深く、より悲劇的になる

主人公は「B子は社会の無理解（いじめ）で苦しんで死んだ」と思い込む。だから「厳密な言語があれば救えた」という誤信念を持つ。

**しかし実際には：**
- B子を殺したのは「社会の無理解」ではなく、**家庭内の性的暴力**
- 「厳密な言語」があっても、この問題は解決しない
- 主人公が立てた全人生の前提が、根本から的外れ

### 2. 主人公自身が「引き金」になった構造

最も胸糞悪いポイント：**主人公の善意（デート・優しさ）そのものが、B子の死の引き金になった**。

- デートがなければ、B子は虐待を「普通」のまま受け入れ続けていたかもしれない
- 主人公が幸福を与えたからこそ、B子は虐待の異常さに気づいてしまった
- 主人公は「言語が足りなかったから救えなかった」と思っているが、実は「幸福を与えたこと自体」が引き金

これはACT4で主人公がA男に「教育」という善意で加害する構造と**完全に並行**する。

### 3. B子の知的障害の設定が活きる

知的障害があるからこそ：
- 虐待を「異常」と認識するのが遅れた
- 助けを求める言語を持たなかった
- 認識した瞬間の反応が「逃げる」「相談する」ではなく、もっと直接的な行動になった

### 4. 「鏡像」構造の深化

主人公とB子は「空気が読めない」という共通点で鏡像だが、この設定では**もう一つの鏡**が生まれる：

- B子 → 家庭内で性的に搾取される（弱者への暴力）
- 主人公 → 学校でいじめられる（異質者への暴力）
- **どちらも「言語化できない暴力」の被害者**

主人公は自分のいじめは論理でかわせたが、B子の暴力は論理ではかわせない種類のものだった。この非対称性が「厳密さ＝救済」の限界を最初から暗示している。

---

## 補足：別の可能性も検討

### 変種A：同級生による性的搾取
父親ではなく、A男グループや他の同級生が知的障害につけ込んで性的ないじめをしていた。学校外（通学路、公園など）で。ただしこれだと「学校以外の側面」という指摘とやや合いにくい。

### 変種B：性的搾取＋妊娠
性的虐待の結果として妊娠していた。知的障害のため状況を理解できず、デート後に帰宅して虐待者から妊娠を知らされる（あるいは暴力を受ける）。より胸糞悪いが、中学生の設定でどこまで描くかという問題がある。

---

## 結論

**最も筋が通る設定は「家庭内性的虐待」。** 主人公とのデートが「幸福と虐待の対比」を生じさせ、それが死の引き金になった。主人公は真実を知らず、的外れな教訓（「厳密さがあれば救えた」）を引き出して全人生を誤った方向に進む。

この設定が「胸糞悪い」のは、虐待そのものだけでなく、**善意が人を殺す**という構造にある。
