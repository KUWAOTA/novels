# 書き出し候補比較 — diopsidae v5

今回は、第一場面の文章の良し悪しではなく、読者に何をどの順で経験させるかを比較する。配属場面に欲求や行動がまだ書かれていないことは、補筆可能な不足であり、その開始位置の構造的不適切さを意味しない。前の回答はこの二つを混同していた。

参照：[人物設定](../../diopsidae/設定資料/v5/characters.drawio)、[プロット](../../diopsidae/設定資料/v5/plot.drawio)、[テーマ](../../diopsidae/設定資料/v5/theme.drawio)。以下の具体的な開始案は提案であり、設定の確定変更ではない。関連資料：[書き出しの選定要件](書き出し選定要件.md)。

## 比較の前提

v5の中心は、樹の「厳密な言葉が人を救う」という信念、その成立に関わる父・あんず・学業上の成功、秀斗への善意の指導と崩壊、最後の「理解できなくても関わる」という選択である。

開始位置によって変わるのは、この出来事の順番そのものより、読者が樹をどの理解で追うかである。樹の善意を先に知れば悲劇の予感になり、加害の結果を先に知れば人物を見直す物語になる。

比較表は、原則として「その場面が作品の最初にある場合」を扱う。現行の日記プロローグを先に置く場合の違いは後述する。

## 各候補を物語全体へつなぐ案

### A：配属から始める

組織図に二人の名前が並ぶ。樹は新しい仕事として受け取り、秀斗は違う意味で受け取る。この認識の差を最初の疑問にする。

提示順の候補：配属・再会 → 二人が一度仕事をする → 中学での出会い → 現在の指導が進む → あんず・父に関する過去。

この位置の強みは、現在と過去で二人の立場がどう変わったかを読む楽しみである。秀斗の家庭事情や樹の贖罪を全部明かす必要はない。最初の回想では「旧知」の意味を一段変えるだけでよい。

契機事件としては、配属によって樹が継続的に秀斗へ関わる責任を負い、その後の行動を生むなら成立しうる。単なる予告的な再会なら、契機事件は後に置ける。樹の決意そのものを契機事件と呼ぶ必要はない。

向く狙い：成人した二人を見せてから、中学の二人との落差を読ませたい。

### B：成功している樹から始める

曖昧な説明で止まっていた仕事を、樹が整理して前進させる。人から感謝され、彼のやり方が社会で役立っていることが分かる。具体的な仕事は新規に選ぶ。

提示順の候補：成功 → 秀斗への配属・担当 → 同じ方法の不調 → 過去にその方法を獲得した場面 → 指導の悪化。

「厳密さは有害」という単純な主張にしないために有利。v5の学業成功の機能の一部を成人の現在で示すこともできる。ただし、この機能を移すなら灘・東大の回想が重複しないか確認する。

向く狙い：読者が樹の世界観に一度納得してから、その限界を体験する。

### C：善意と反作用が同居する指導から始める

樹は秀斗の説明を助けているつもりで問いを重ねる。仕事の論点は明瞭になるが、秀斗は発言しなくなる。理由や過去はまだ提示しない。

提示順の候補：指導の食い違い → 成人の日常・責任 → 中学の似たやり取り → 現在でさらに手を尽くす → あんずの記憶。

読者には害の兆しを樹より早く見せ、深い原因では樹と同じく分からない状態を作れる。配属の説明は短く後置できる。契機事件をすでに過去の配属に置くか、冒頭後の重大な失敗に置くかは選べる。

向く狙い：二人の関係の両義性そのものを最初から読ませたい。

### D：指導の結果を告げられるところから始める

上司が秀斗の不調と指導の関連を問う。樹は自分の説明の内容を確認しようとするが、問われているのは正誤だけではない。

提示順の候補：告知 → 現在で秀斗との関係へ働きかける → 過去の指導を再構成 → さらに古い経験 → 修復の失敗と新しい選択。

ここは単なるAの短縮版ではない。主筋が「善意の指導が破局へ進む」から「破局を突きつけられた人物が、自分を問い直す」へ寄る。現在の行動が過去を調べるだけにならない設計が必要で、v5からの変更量は大きめ。

向く狙い：樹の自己像の崩壊と再形成を中心にする。

### E・F・G：過去から始める三つの違い

Eは社会との摩擦、Fは方法と愛の継承、Gは言葉にならない親しさを、読者の第一印象にする。過去始まりでも、次の章で成人へ飛べる。中学時代の全経歴を完走する義務はない。

Eから成人へ飛ぶと、関係の逆転が驚きになる。Fから成人の指導へ飛ぶと、父の方法との違いを読む構造になる。Gから成人へ飛ぶと、あんずの不在と樹の変化が問いになる。

いずれも樹への感情的な接続を先に作りやすい一方、現在の職場を本筋と認識させる切り替えが必要になる。

### H・I：重大事件を先に見せる

Hは樹の誤信の起源を先に置く案、Iはその誤信の末路を先に置く案。強烈さは共通しているが、作る問いは異なる。

Hではあんずとの日常を後から描いて、失われた人物の存在感を増やせる。ただし「樹の言葉が死を起こした」という本人の解釈を、語りが真実として保証しないことが重要。

Iでは救命場面の途中で過去へ長く戻ると、現在の危機を人質にして説明を読ませる印象になりやすい。採るなら短い予告にするか、過去と現在の往復自体を作品の形式として引き受ける。

### J：現行プロローグを含めて決める

日記プロローグを残すなら、A〜Iは厳密には「第二の入口」である。すでに読者は樹の孤立感・声・自己分析への執着を知っているため、本編最初の場面で同じ説明を繰り返さなくてよい。

| 組み合わせ | 得られる読み方 | 負担・調整点 |
|---|---|---|
| J → A | 孤立を語っていた人物が社会的上位にいる。その変化と旧友の敵意を追う | 日記を開いた直後に職場へ移る理由を、時点表示などで明瞭にする |
| J → C | 自己理解を求める人物の、理解の失敗をすぐ見せる | 内面説明と指導場面が同じ主張を繰り返さないようにする |
| J → E | 日記から過去へ自然に入る | 成人の現在軸へ移るのが遅くなりやすい |
| AまたはC → 過去、Jは後で検討 | 現在軸を一度で立ち上げられる | 昆虫と自己探究の声を別のところで育てる必要がある |

現行プロローグの帰還後の樹は、「何が起きたか」より「彼がどう変わったか」を読む入口になっている。これを残すかは、本編の第一場面とセットで比較したい。

## 今回の目的に対する絞り方

「完成した成人の樹を先に見せ、謎を作って中学の出会いへ戻る」という狙いに対して、まず比較する価値が高いのはA・B・C。Aは二人の過去、Bは樹の方法への信頼、Cは善意と害の食い違いを最優先する。どれも場面内の不足を補えば成立可能で、現段階でAを落とす根拠はない。

Dは、現在の主筋そのものを自己検証と修復へ寄せたい場合の強い別案。E〜Jは読者の最初の理解を変える対照候補として並べた。

次の試作は全文ではなく、候補ごとに「最初の出来事／読者が分かること／分からないこと／次に見せる過去／現在へ戻ったときの意味」を各一文ずつ書けば比較できる。見せ場の派手さではなく、二つ目・三つ目の場面まで読みたくなる問いが続くかを見る。
