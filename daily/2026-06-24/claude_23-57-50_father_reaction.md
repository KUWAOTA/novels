# S4 v2 末尾括弧の実現案

対象:
`diopsidae/本文/ACT1/SEQ2_父との絆と喪失/S4_父から仮説を学ぶ/v2/本文.txt`

## 方針

ここは、孝則が「心配していない」のではなく、「自分の不安を樹に押しつけない」父であることを見せる場面にするとよいです。

ポイントは、孝則に大きな声を出させないことです。  
ただし完全に無反応だと冷たく見えるので、身体だけは一瞬動く。目は樹を見る。危険がないとわかってから、樹が自分で起きる余白を残す。

おすすめは、転倒直後に以下の順で描くことです。

```text
孝則の手が少し動く
→ 樹の頭・手・膝を見る
→ 大丈夫そうだと判断する
→ 声を重ねない
→ 樹が自分で起きる
→ 床に散ったものへ視線が移る
```

## 採用候補

そのまま本文末尾に続けるなら、まずはこの形が一番使いやすいと思います。

```text
どん、と音がした。

孝則の手が、シーツの上で少し浮いた。
起き上がろうとしたのか、ベッドの柵に指がかかった。
けれど、その手はすぐには伸びてこなかった。

樹は床に尻もちをついたまま、何が起きたのかわからずに瞬きをした。
ランドセルの重みが、まだ背中を横へ引っぱっていた。

孝則は樹の顔を見て、それから手を見て、膝を見た。
どこかを打った音を探すような目だった。

「痛いか」

声は小さかった。
樹が首を横に振ると、孝則はそれ以上、何も言わなかった。
樹が床に手をついて起き上がるまで、ベッドの柵にかけた指だけが残っていた。
```

## より静かな版

今の本文の静けさを保つなら、こちらでもよいです。孝則の台詞を最小限にして、見守り感を強めます。

```text
どん、と音がした。

孝則の指が、シーツを押した。
ベッドの上の体が、ほんの少しだけこちらへ傾いた。

樹は床に尻もちをついた。
ランドセルが背中でずれて、肩紐が片方だけ肘のところまで落ちていた。

孝則はすぐには何も言わなかった。
樹の顔を見て、手を見て、膝を見た。
その目が一度止まって、それから戻ってきた。

「立てるか」

樹は床に手をついた。
孝則は、まだベッドの柵に指をかけたまま、樹が立ち上がるのを待っていた。
```

## 裕子との差を少し強める版

裕子なら「大丈夫なの」「何してるの」「だから言ったでしょ」と言いそうなところを、孝則は一回だけ聞く、という差を出す版です。

```text
どん、と音がして、椅子だけがまだ半分回った。

孝則の肩が動いた。
シーツの上に置かれていた手が、ベッドの柵まで出た。

樹は床に尻もちをつき、椅子の脚が止まるのを見ていた。
叱られる、と思った。

けれど孝則は、声を上げなかった。
樹の頭の位置を見て、手のひらを見て、曲がった膝を見た。

「打ってへんか」

それだけだった。

樹がうなずくと、孝則は小さく息を吐いた。
そして、樹が自分で起きるまで、次の言葉を待っていた。
```

## 私のおすすめ

一番よいのは「採用候補」です。

理由は、孝則の心配がちゃんと見える一方で、それが樹への圧になっていないからです。  
特に、

```text
孝則は樹の顔を見て、それから手を見て、膝を見た。
どこかを打った音を探すような目だった。
```

このあたりで、父が冷静に危険確認をしていることを show できます。

さらに、

```text
声は小さかった。
樹が首を横に振ると、孝則はそれ以上、何も言わなかった。
```

ここで「不安を押しつけない」が出ます。  
裕子との差も、直接裕子を出さずに立ちます。

## 次にプリントへつなぐなら

このあと床にこぼれたものへ入るなら、続きはこうできます。

```text
ランドセルの口が開いていた。
教科書の角が床に当たり、赤い下敷きがその横で斜めになっていた。
その下から、折れたプリントの端が出ていた。

孝則の視線が、そこで止まった。
けれど、指は差さなかった。

樹はあわてて手を伸ばした。
```

孝則がすぐ問い詰めないことで、プリントを「事件の証拠」ではなく「樹の世界からこぼれたもの」として扱えます。
