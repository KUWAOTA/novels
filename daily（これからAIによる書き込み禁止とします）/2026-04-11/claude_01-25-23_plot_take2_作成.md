# plot_take2 穴埋めマークダウン作成完了

## やったこと

`daily/plot_take2/` に、黒田フィードバックを反映した穴埋めマークダウンを作成した。

## 構成

- **README.md** — take2の目的と方針
- **episodes/index.md** — 全ファイルの一覧・不足カテゴリの横断整理
- **ACT1/** — 5ファイル（主人公3 + A男2）
- **ACT2/** — 7ファイル（主人公3 + A男2 + B子2）
- **ACT3/** — 3ファイル（主人公2 + A男1）
- **ACT4/** — 6ファイル（主人公3 + A男3）
- **ACT5/** — 4ファイル（主人公2 + A男1 + B子1）

**合計：25ファイル**

## 各ファイルの構造

1. **take1にあるもの（骨子）** — 既存の設計をそのまま記載
2. **足りないもの** — 黒田フィードバックに基づくTODO
3. **穴埋めスペース** — 以下の4カテゴリで空欄を用意
   - 象徴的な会話（1〜2往復）
   - 盛り上がりシーンの仮執筆（3〜5行）
   - 五感の断片（場所・天気・匂い・音）
   - キャラの身体性（手の動き・目線・姿勢）

## 横断的に足りないもの（全ACT共通）

| 不足カテゴリ | 黒田プロットにはあるがConstrainにないもの |
|------------|--------------------------------------|
| 場所 | 固有名詞レベルの舞台設定 |
| 時間 | 月単位・季節・時間帯 |
| 会話 | 各章の象徴的な台詞の断片 |
| 小道具 | 印象に残る具体的な物（分析ノート以外） |
| 身体性 | キャラの外見・姿勢・手の動き |
| 形式 | 「場面」か「語り」かの指定 |

## 使い方

- `【TODO】` マークの箇所を、思いついた順に埋めていく
- `【仮執筆スペース】` は粗くてOK。黒田の言う「自分に見えた映像を直観的に」
- 全部埋まったらtake1のプロットに肉付けしてフィードバックする流れ
