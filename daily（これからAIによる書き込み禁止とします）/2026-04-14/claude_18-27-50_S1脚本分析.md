# ACT5-SEQ1-S1「秀斗の自殺未遂 → 樹が走る」脚本分析と改善提案

## 現状の診断

### たたき台の構造的問題（ストーリーコンパイラ視点）

#### ❌ compile_error: シーン設計とvalue_changeの不整合

master.mdの定義:
```yaml
value_change:
  axis: 理性⇔本能
  from: 鏡像認識後の立ちすくみ（思考の中）
  to: 論理より先に体が動く（初めて）
  cause: 秀斗の自殺未遂の報せ + あんずの記憶
```

**問題:** 現在の脚本では、秀斗が樹の家に来て包丁を振るう展開になっている。「報せを聞いて走り出す」という設計が消えている。樹が「走る」＝論理より先に体が動く、という価値変化の核心が脚本に存在しない。

さらに、S2（クライマックス）で「シュモクバエ」「ケニア航空券」「辛かったやろ」が全て起きる設計になっている。S1の脚本がS2の要素を先食いしてしまっている。

#### ⚠️ warning: S1とS2の役割分担が曖昧

S1の役割 = **「理性で考える前に体が動いた」初体験**
S2の役割 = **「理解できなくてもいい」という選択**

現在のたたき台はS1の中でケニアの台詞から和解まで全部やろうとしている。これだとS2が不要になるか、重複する。

#### ⚠️ warning: 鑑識眼チェック — 陳腐さの検出

- 「包丁を振りかざす → 手が震えて動かなくなる → 涙」→ **紋切り型**
- 「死ぬくらいなら○○しよう！」で自殺を止める → **テレビドラマの文法**
- 「殺すつもりで来たが、実は殺せない」→ 読者に予測され、驚きがない
- 樹が焦って変なことを言う → 秀斗が笑い出す → **ご都合主義的な解消**

#### ⚠️ warning: 樹の葛藤（ジレンマ）が不在

ユーザー自身が指摘している通り。現在の脚本で樹は「なんとか止めなきゃ」→「変なこと言っちゃった」→ 結果オーライ、になっている。これは**選択**ではなく**偶然**。

McKeeの選択の真正性（module 16）に照らすと:
- 樹が選べる選択肢が複数ない
- どちらを選んでも何かを失う構造がない
- 観測者によって評価が割れるジレンマがない

まずS1とS2を分けることが重要。S2の脚本は既にかなり固まっているので、そこから逆算してS1の役割を明確にする。

### S2で起きること（確定済み）
- スマホでナイロビ行きを検索
- 「シュモクバエ、見に行かん？」「俺もわからん」
- ケニア行き航空券を買う

- 秀斗がハグ → 「仕返しだと思ってた」→「え？何で？」

### S1で起きるべきこと（再設計）
S1の仕事は**S2への橋を架けること**。具体的には:

1. **樹が「報せを聞いて走り出す」**— 理性より先に体が動く初体験
2. **秀斗と対峙する** — 止めたが、秀斗の呪詛を浴びる
3. **樹の葛藤が露呈する** — 「正しい言葉」を探すが見つからない
4. **S2への引き** — 何も言えない樹 / 秀斗の「お前が俺を壊したんだ」

S1は**解決しないまま終わる**のが正しい。解決はS2の仕事。

## 改善案: S1脚本の再構築

### 構造設計

```
Before状態: 樹は日常の中にいる（ACT4の鏡像認識後、何もできず立ちすくんでいる）
転換点: 秀斗の自殺企図の報せ
After状態: 走り出す → 対峙 → 呪詛を浴びる → 言葉が出ない
```

### 提案する脚本（ビートシート）

#### Phase 1: 報せ（理性→本能の転換）

```
〇樹の自室（夜、一人）
　ACT4で秀斗を追い詰めたことに気づいた後。
　何日か経っている。何をすればいいかわからないまま過ごしている。
　スマホが鳴る。
　会社の誰かから。秀斗が橋の上にいるらしい、と。
```

**ここでの演出ポイント:**
- 電話の内容を全部聞く前に、樹はもう走り出している
- あんずの時は「報せを聞いた時にはもう遅かった」— 今度は「まだ間に合うかもしれない」
- **走る理由を樹自身が理解していない** ← これがvalue_changeの核心
- 「なぜ走っているのか」を考える余裕がない。体が先に動いた。これが樹にとって初めての体験

#### Phase 2: 対峙（秀斗の呪詛 + 樹の言葉の無力）

```
〇橋の上（深夜）
　秀斗が欄干の外側にいる。
　樹が到着する。息が切れている。
```

**ここでの葛藤設計:**

秀斗は樹を見て**逆上**する。「お前が来るのかよ」

秀斗の呪詛は3層で設計する（秀斗の12設定から引き出す）:

**第1層: 怒り**
- 「お前のレビューは父親の採点と同じだった」（設定006, 009）
- 「正しいから反論できない。正しさの中にいると死ぬ」（設定011）

**第2層: 嫉妬の暴露**
- 「お前の親父は『百点じゃなくてもいい』って笑ってたよな。俺の家にはその法律がなかった」（設定005）
- 「お前は恵まれてたくせに、俺をあの家と同じ目に遭わせた」

**第3層: 質問（これが樹を追い詰める）**
- 「お前、俺のこと人間だと思ってたか？ それとも直すべきバグだと思ってたか？」

**樹の反応（葛藤の核心）:**
- 樹は答えを探す。論理的に正確な答えを。
- だが**正直に振り返ると、「バグだと思っていた」に近い**ことに気づく。
- 嘘をつくか、正直に言うか。どちらも秀斗を傷つける。
  - 嘘（「そんなことない」）→ 秀斗にはわかる。精密な樹の嘘は、余計に残酷
  - 正直（「……わからない」）→ 秀斗の怒りを確認してしまう
- **これが真のジレンマ。どちらを選んでも傷つける。**

#### Phase 3: 沈黙と引き

```
　樹は答えられない。
　秀斗「……やっぱりな」
　秀斗が欄干から身を乗り出す。
　樹が秀斗の腕を掴む。
　秀斗「離せよ」
　樹「（言葉が出ない。ただ掴んでいる）」
　秀斗「お前に止める権利があると思ってんのか」
```

**S1はここで切る。**

樹は秀斗を物理的に止めたが、**言葉では何も止められていない**。
正しい言葉を探し続けてきた樹が、「正しい言葉がない」状況に初めて放り込まれる。

→ これがS2への完璧なセットアップになる。
S2で樹は「正しい言葉」を諦めて「シュモクバエ、見に行かん？」という**論理を捨てた言葉**を発する。

## 葛藤設計のまとめ

### 樹のジレンマ（S1で提示、S2で「解決」）

| 選択肢 | 樹にとって | 秀斗にとって |
|---------|-----------|-------------|
| A: 論理的に正しいことを言う | 自分のアイデンティティを守れる | 「また採点された」= 死の確認 |
| B: 感情的な言葉で止める | 自分が何を言っているか理解できない（恐怖） | 止まるかもしれないが、上から目線に聞こえるリスク |
| C: 何も言わない（体で止める） | 言葉の敗北を認めることになる | 「力で抑えただけ」= 何も解決しない |

S1では**Cを選ばざるを得ない**（AもBも間に合わない／出てこない）。
S2では**Bの変形**（「シュモクバエ」）が出てくるが、それは計算された感情表現ではなく、**本当に意味がわからないまま出た言葉**。

### 秀斗の矛盾（次元の証明）

秀斗は樹を殺したいほど恨んでいるが、同時に「この人に認められたい」と思っている（設定007）。
橋の上に来たのは死ぬためだが、**連絡が会社経由で樹に届くルートを無意識に残している**のは、止めてほしいからかもしれない。
秀斗自身がその矛盾に気づいていない。

## 場所の問題: 「樹の家の前」vs「橋」

たたき台では「樹の家の前に秀斗が来る」設計だが、以下の理由で**橋（または高所）**を提案する:

1. **あんずの電車飛び込みとの構造的エコー**を活かすなら、「高所」「落下」のイメージが有効
2. **「走る」という価値変化**を描くには、物理的距離が必要。家の前に来られたら走れない
3. 秀斗の設定012「橋の前夜」が既にある。ここでの橋はACT5用に設計されたもの
4. **「靴だけ揃えて出てきた」秀斗**の描写が、橋の上で使える（設定012）
