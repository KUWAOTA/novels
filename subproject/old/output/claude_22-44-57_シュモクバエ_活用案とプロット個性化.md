# シュモクバエの活用案 + プロットの「個性のなさ」を打破するアイデア集

---

## Part 1: シュモクバエをクライマックスの象徴として使う方法

前回の検討で「ケニア渡航をそのまま採用するのは構造的に困難」と判定した。しかしユーザーの新しい提案は、**そのまま行くのではなくチケットを買って止める**、あるいは**エピローグでケニアに行く**など、柔軟な使い方を模索している。

以下、具体的な案を列挙する。

---

### 案1: 「ケニア行きのチケット」で自殺を止める

**概要**: 秀斗の自殺企図の現場で、樹が論理でも言葉でもなく、突拍子もない行動で止める。「シュモクバエを見に行こう」とスマホでケニア行きの航空券を実際に買う。

**シーンイメージ**:

```
秀斗がGoogle屋上（or 駅ホーム）に立っている。
樹が駆けつける。

何を言えばいいかわからない。
「厳密な言葉」が何も出てこない。

沈黙。

樹、スマホを取り出す。
秀斗が振り向く。

樹「……ナイロビ行き、2席あった」

秀斗「は？」

樹「シュモクバエ。カカメガの森にしかおらんやつ。
　　目が離れてるほどモテるハエ。
　　……あほみたいやろ」

秀斗「何言ってんだお前」

樹「俺もわからん。でも買った」
（画面を見せる。決済完了画面）

秀斗、力が抜ける。
「……お前、頭おかしいんか」

樹「たぶん」
```

**この案の構造的意味**:
- 樹が**論理で説明できない行動を初めてとる** → 統制概念「理解できなくても動く」の体現
- 「シュモクバエを見に行こう」は**合理的に見れば全く意味がない** → だからこそ樹のキャラが立つ。ASD的な「字義通り」の極端さが、ここでは救いになる
- 秀斗の「お前、頭おかしいんか」→ 物語で初めて**秀斗が樹を「人間として」見る**瞬間
- **航空券という物質**が「小道具リレー」の到達点になる（横断ワークシートの穴を埋める）

**懸念と対処**:
- 「買っちゃった」が軽く見えるリスク → **樹自身が震えている/泣いている**描写で重さを担保
- 「何故シュモクバエ？」の説明が必要 → **説明しない**のがベスト。読者はACT1の図鑑エピソードを覚えている。樹が説明しないことが、樹の変容そのもの（かつての樹なら必ず説明した）
- 「辛かったやろ」との共存 → チケットを見せた後、沈黙があり、その後で「辛かったやろ」が出る。順序：**チケット（不合理な行動）→ 沈黙 → 「辛かったやろ」（感情の言葉）**

**評価: ◎ 強力。キャラが立つ。既存設計との両立も可能。**

### 案2: エピローグでケニアに実際に行く

**概要**: ACT5のクライマックスは病室（既存設計を維持）。エピローグで「数ヶ月後、本当にケニアに行った」を描く。

**シーンイメージ**:

```
エピローグ

カカメガの森。湿度が高い。虫の音がうるさい。

ガイドの研究員が「この辺にいる」と指差す。
秀斗が葉の裏を覗き込む。

「……これ？」

1センチもない。茶色い。目が離れている。

秀斗「こんなんのために」
樹「こんなんのために」

秀斗「Google辞めて」
樹「辞めたのは俺だけやろ。お前は休職」

秀斗「でもケニアまで来た」
樹「来た」

（間）

秀斗「……あほやな、俺ら」

笑い声が森に響く。
シュモクバエは気にせず、目を離したまま飛んでいる。
```

**この案の構造的意味**:
- クライマックスの**後**なので、統制概念の体現には干渉しない
- 「笑い合う」は**テンションの解放**。重い物語の最後に読者が深呼吸できる
- 「シュモクバエは気にせず飛んでいる」→ 中核イメージとして、「どんなルールで生きていても、それぞれが勝手に飛んでいる」という統制概念の余韻
- Google退職（樹）と休職（秀斗）→ 社会的に不可逆な変化の残響
- **タイトル回収**: 「シュモクバエのこと、笑ってやろうぜ」が最終シーンで体現される

**懸念と対処**:
- エピローグが蛇足に感じるリスク → **短く書く**。400字以内。情景描写＋会話3往復＋最終行で完結
- 「結局行くんかい」のコメディ感 → この作品に必要なのは**まさにこの軽さ**（後述の「個性のなさ」問題への回答）

**評価: ◎ クライマックスを壊さず、タイトルを回収し、読後感を保証する。**

### 案3: ロードムービー構造（ACT5自体をケニア旅に）

**概要**: 秀斗の自殺を止めた後、樹が「とにかくここから出よう」と秀斗を連れ出し、ケニアまで行く。その道中で過去のエピソードが回想として挿入される。

**構造イメージ**:

```
ACT5-① 自殺企図を止める（日本・既存設計ベース）
ACT5-② 成田空港→ナイロビ（機内で回想：あんずのこと）
ACT5-③ ナイロビ→カカメガ（高速バスで回想：父のこと、秀斗との子供時代）
ACT5-④ カカメガの森（シュモクバエを見つける→笑う→抱き合う）
```

**この案の構造的利点**:
- ACT3（灘〜東大）の外的イベント不足問題を**回避**できる。ACT3の内容を回想として挿入するため、独立した幕として成立させる必要がない
- 移動という物理的距離が、心理的距離の変化を体現する
- 日本→ケニアの地理的跳躍が「枠を選びなおす」（ACT1の樹の原初の直感）の文字通りの実現

**この案の構造的問題**:
- **純文学からロードムービーへのジャンル転換**が最大の問題。ACT1〜4が心理劇なのにACT5だけ冒険譚になる
- 「道中の回想」構造は**映画的**であり、小説として書くと冗長になるリスク
- 樹の変容ポイント（「体が先に動く」）がケニア行きの計画性と矛盾する
- 秀斗が自殺未遂直後にパスポートを持って飛行機に乗れるかというリアリズムの問題

**対処（もし採用するなら）**:
- 全体構造を**最初からロードムービーとして設計しなおす**必要がある。ACT5だけロードムービーは無理
- あるいは、**全編を「ケニア行きの飛行機の中」から始める**枠構造にする：

```
プロローグ：ナイロビ行きの機内。隣に眠っている秀斗。
　→ なぜこんなことになったのか……
ACT1〜4：回想として語られる
ACT5：カカメガの森
```

この枠構造なら純文学として成立しうるが、**別の小説になる**。

**評価: △ 面白いが、現行設計の大幅な作り直しが必要。「別の小説」として検討する価値はある。**

### 案4: シュモクバエを「小道具」として使う（ケニアには行かない）

**概要**: シュモクバエの図鑑（or 写真/標本）が物語を貫く小道具になる。

```
ACT1: 樹が図書室でシュモクバエの図鑑を見つける。
      「馬鹿みたいだ」→「安心した」
      この図鑑ページに付箋を貼る。

ACT2: あんずが保健室で樹のカバンから図鑑を見つける。
      「これ、なに？」
      樹「シュモクバエ。目が離れてるほどモテるハエ」
      あんず「……へんなの」（笑う）
      → あんずが笑った。樹にとって「あんずが笑った」記憶。

ACT4: 樹のGoogle社のデスクに、あの図鑑がまだある。
      付箋が古びている。秀斗がそれを見て「なんすかこれ」
      樹「シュモクバエ。目の位置でモテるか決まるハエ」
      秀斗「……くだらな」
      → あんずと同じリアクション。樹は気づかない。読者だけが気づく。

ACT5: 病室。樹が何も言えずにいる。
      カバンから図鑑が落ちる（or 樹が無意識に持ってきている）。
      秀斗「……まだ持ってんのかよ、それ」
      
      長い沈黙。

      樹「……辛かったやろ」
```

**この案の構造的意味**:
- 図鑑が**ACTを跨ぐ小道具リレー**（横断ワークシートの穴を完全に埋める）
- あんずと秀斗の「くだらな/へんなの」のエコー → 二人の接続
- 最終シーンで図鑑が落ちる → 樹が「分析・分類する道具」を手放す象徴
- **説明しない**: 樹は「僕もシュモクバエだ」とは言わない。図鑑があるだけ

**評価: ○ 地味だが構造的に堅実。他の案と組み合わせ可能。**

### 案5: 案1+案2+案4の合体（推奨案）

最も有効と思われる組み合わせ：

```
【ACT1】図鑑でシュモクバエを知る。付箋を貼る。「馬鹿みたいだ」→「安心した」

【ACT2】あんずが図鑑を見て「……へんなの」と笑う。
        あんずの死後、樹はこの図鑑を手放せなくなる（理由を自分でも言語化できない）

【ACT4】デスクに図鑑。秀斗「なんすかこれ」→「くだらな」
        （あんずのエコー。読者だけが気づく）

【ACT5-①】秀斗の自殺企図。樹が駆けつける。
          何を言えばいいかわからない。
          
          スマホを取り出す。震える手でナイロビ行きを検索する。
          「……シュモクバエ、見に行かん？」
          秀斗「は？」
          樹「目の位置で人生決まるハエ。カカメガの森にしかおらん」
          秀斗「お前……何言って……」
          樹「俺もわからん」（←これが核心。初めて「わからない」と言う）

【ACT5-②】秀斗の力が抜ける。
          病院（or その場で座り込む）。沈黙。
          「辛かったやろ」

【エピローグ】カカメガの森。シュモクバエを見つけて笑う。
            「こんなんのためにGoogleクビになったぞ」
            「あほやな」
            シュモクバエは気にせず飛んでいる。
```

**この構造が達成すること**:
1. シュモクバエが全幕を貫く中核イメージ ← `17_symbolism`の`recurrence_with_variation`
2. 図鑑が小道具リレー ← 横断ワークシートの穴を埋める
3. 「俺もわからん」が樹の変容の核心 ← 統制概念の体現（説明ではなく行動）
4. 「辛かったやろ」は健在 ← 父の①の回収
5. エピローグで笑い ← 読後感の設計＋タイトル回収
6. 「あんずが笑った」→「秀斗と笑う」のエコー
7. **Googleクビの不可逆性** ← クライマックスの価値変化が不可逆

## Part 2: 「個性のなさ」「論理的に詰めたら想像つく展開」を打破するアイデア

ユーザーが感じている問題を構造的に言い換えると：

> 全てのプロットビートが「テーマの論証」として配置されており、キャラクターが「テーマを証明するための関数」になっている。
> 結果として、キャラクターが生きた人間ではなく「構造の駒」に見える。

これはMcKee理論を忠実に適用した場合の**典型的な副作用**。構造が正しいほどキャラが死ぬ、というパラドックス。

以下、この問題を打破するアイデアを出す。

---

### 問題A: 樹が「ASD的な論理人間」以外の個性を持っていない

**現状**: 樹のキャラクターは「論理→誤信念→崩壊→気づき」という機能で完全に説明できてしまう。読者が「この人のこういうところが好き」と思える余地がない。

**打破アイデア**:

#### A-1: 樹に「論理と矛盾する好き」を与える

McKee `21_character-dimension`が要求する「矛盾」。樹の中に、論理では説明できない偏愛があるべき。

**シュモクバエへの執着がまさにこれ**。

しかしシュモクバエ以外にも：
- **特定の音楽を繰り返し聴く癖**（例：同じ曲を200回リピート。曲自体は論理的でないもの——例えばスピッツとか、あいみょんとか）。秀斗に「お前それ200回目やろ」と言われても「うるさい」としか返せない。なぜ好きか説明できない。
- **食に異常にこだわる**（ASD的なこだわりだが、それが面白い方向に出る。例：カレーの具材の切り方に30分かけるが、味付けは適当）
- **虫を見ると歩くのをやめる**。大人になっても。Google出勤中にアリの行列を15分見ていて遅刻する。秀斗「またですか」。→ これがACT1のシュモクバエ体験の残響として自然

**最も効果的なのは「虫を見ると止まる」癖**。これは：
- ACT1（ピロティでシュモクバエの図鑑）の延長として自然
- ACT4（Google出勤中に虫を見て遅刻）で秀斗との関係描写に使える
- ACT5（病室の窓の外に虫が飛んでいる）で中核イメージに収束する
- 読者が「この人、面白いな」と思える具体性がある

#### A-2: 樹の「ピュアさ」をもっと前面に出す

characters.drawioに「ピュアだからわけもわからず止めようとする」とある。この「ピュア」が現行プロットで十分に描写されていない。

**具体案**:
- ACT1で、樹がいじめられている**別の子を論理で助けようとする**（そして失敗する）。つまり自分が孤立しているのに他人を助けようとする。→ 動機は正義感ではなく「困っている人がいると気持ち悪い」（ASD的な秩序欲求＋善良さの混合）
- ACT2で、あんずに対して**無自覚にデリカシーのないことを言う**が、あんずはそれを「裏表がない＝安全」と感じる。例：「今日臭い」「知ってる」「洗濯機の使い方教えようか」→ あんず「（笑う）」。普通なら怒るが、あんずにとっては「この人は嘘をつかない＝性的な下心もない」の証拠
- ACT4で、秀斗に**良かれと思って弁当を作ってくる**（自炊スキルが妙にある）。秀斗は「こいつ俺を潰しておいて弁当持ってくるのか」と混乱する。→ 樹は自分が秀斗を追い詰めていることに全く気づいていないからこその行動

#### A-3: 樹に身体的な「変な癖」を

characters.drawioの身体性ワークシートがほぼ空白。これを埋めると一気にキャラが立つ。

- **考え事をするとき指でリズムを刻む**（机をコツコツ。秀斗はこの音が嫌い。ACT4でSlack返信しながらコツコツやっている描写→秀斗の視点で「あの音がまた聞こえる」）
- **人と話すとき相手の右肩あたりを見る**（目を合わせない）。あんずだけ例外的に目を合わせられた→あんずの死後、誰とも目を合わせなくなった→ACT5で秀斗と初めて目を合わせる
- **走るのが異様に遅い**（運動音痴）。ACT5で秀斗のもとに走るシーンが、この遅さのせいで逆にリアルになる。息切れがひどい。膝が笑っている。でも止まらない

### 問題B: 秀斗が「嫉妬するいじめっ子→壊れる被害者」のテンプレに見える

**現状**: 秀斗の行動はすべて「母からの条件付き愛→嫉妬→加害→被害→崩壊」で説明できる。教育虐待の被害者がいじめっ子になるというのは、理解しやすすぎる。

**打破アイデア**:

#### B-1: 秀斗に「樹を嫌いきれない」描写を入れる

現行設計に「仕返しだと思ってた」→樹「え？何で？」という台詞がある。これを**もっと前から伏線**する。

- ACT1で、秀斗が樹をいじめた後、**家に帰って樹のことを母に話す**。「今日あいつがさ——」と楽しそうに。綾「そんな子と遊んでないで勉強しなさい」。→ 秀斗にとって樹は「嫌いな奴」ではなく「気になる奴」。いじめは歪んだ関心表現
- ACT2で、秀斗が**樹の分析ノートを読み上げた後、家に帰ってからノートの内容を思い出している**。「あいつ、俺のことこんなに観察してたのか」。怒りと、奇妙な嬉しさ。→ 誰かに「ちゃんと見られている」体験が、秀斗には家庭にないから
- ACT4で、秀斗が**樹の厳密な指導をメモしている**。つらいのに、内容は正しいから捨てられない。ベッドの横にメモが散乱している。→ 「嫌いなのにノートを取ってしまう」＝秀斗の矛盾＝キャラクターの次元

#### B-2: 秀斗の「コミュ力」をもっと具体的に描く

秀斗は「クラスメイトには優しい人気者」と設定されているが、これが描写されていない。

- ACT1で、**秀斗がクラスの女子の悩みを聞いている場面**を入れる。秀斗は共感能力が高い。他人の気持ちがわかる。だからこそ樹の「空気の読めなさ」が許せない。→ 秀斗と樹は**逆の才能を持っている**
- ACT4で、**秀斗がGoogle社内で評判がいい**描写。飲み会を企画する、後輩の面倒を見る、雑談が上手い。→ だからこそ樹の指導が「パワハラ」に見えない。秀斗が楽しそうにしているから、誰も気づかない
- 秀斗の崩壊が始まったとき、**同僚が「え、あの水無瀬さんが？」と驚く**。→ コミュ力で崩壊を隠していたことが逆説的に露呈する

#### B-3: 秀斗に「予想外の趣味/能力」を与える

- **秀斗が料理上手**。母に褒められた唯一の家事行為が料理。→ ACT4で秀斗が崩壊していく過程で、**作る料理が変化する**（凝った料理→カップ麺→何も作らない）
- **秀斗がこっそり絵を描いている**（母には見せない。見せたら「そんな暇があるなら勉強しなさい」と言われるから）。→ ACT4の部屋にスケッチブックがある。→ 秀斗のスケッチブックを樹が見つける（ACT5で）→ 中に樹の似顔絵がある、みたいな展開は可能
- **秀斗がラップが好き**。通学中にイヤホンで聴いている。歌詞を覚えるのが得意。→ 秀斗の言語能力の方向性が樹と違う（樹＝論理的精密さ、秀斗＝韻とリズム）

#### B-4: 秀斗の「自殺企図」を予想外の形にする

現行の「屋上に立つ」は定番すぎるかもしれない。

- **秀斗が部屋で普通にしている**。会社に連絡して「辞めます」と言った後、部屋を掃除し始める。綺麗にする。遺書は書かない。→ 樹が秀斗の部屋に行ったら、あの散らかっていた部屋が綺麗になっている。その清潔さに樹は恐怖を感じる。「これはあかん」
- **秀斗が突然実家（奈良）に帰っている**。「おかあさんに会いたくなった」。→ 綾と会って何かを確認して、その後——。樹は奈良まで追いかける。→ 大人になった二人が子供時代の地元を走る、という場面が生まれる
- **秀斗がSlackに「ありがとうございました」と送ってくる**。樹は最初意味がわからない。→ 同僚に聞いて「退職？」→ 電話に出ない → 走る

### 問題C: あんずが「悲劇のヒロイン」テンプレに見える

**現状**: 知的障害＋性的虐待＋純真＋自殺。「かわいそうな女の子」の要素が揃いすぎていて、読者が「はいはい、そういう役割ね」と先が読める。

**打破アイデア**:

#### C-1: あんずに「意外な強さ」を与える

- あんずは**言葉は少ないが、観察力が鋭い**。樹の分析ノートの存在に気づいている（他の誰も気づいていないのに）。でも言わない。→ あんずは「見ているけど言わない」人間。樹は「見て言語化する」人間。対照的
- あんずが**保健室で虫を殺す描写**。窓に入ってきた虫を、躊躇なく潰す。樹は「殺さなくていいのに」と言う。あんず「……だって、入ってきたから」。→ あんずには「境界を侵犯されたものへの静かな暴力性」がある。これが最後の自殺にも繋がる——「入ってくるもの」を止められないなら、自分を止める
- あんずが**樹に怒る場面を1回入れる**。例えば、樹が無神経な言葉を言ったとき、あんずが黙って立ち上がって保健室を出る。樹は「え？」となる。→ あんずは受動的なだけの存在ではない

#### C-2: あんずの「性的虐待の結果」をもっと日常の中に埋め込む

現行では「デート後に虐待再開→自殺」と大きなイベントとして描かれるが、日常レベルの描写が必要。

- あんずが**男性教師の前でだけ態度が変わる**（声が小さくなる、体が硬くなる）。女性の保健室の先生の前では比較的リラックスしている。→ 樹はこの差に気づくが、理由がわからない（ACT4で初めて意味がわかるかもしれない）
- あんずが**手を洗いすぎる**。保健室で何度も何度も手を洗っている。樹「手、赤くなってる」あんず「……うん」。→ 読者にはわかる。樹にはわからない。この情報格差

#### C-3: あんずの死を「美しく描かない」

現行の「デート→帰宅→虐待→電車飛び込み」は物語的に美しすぎる。実際の自殺はもっと雑で、唐突で、意味がないことが多い。

- あんずが死んだ日、**天気がいい**。桜が咲いている。何もかも普通の日。→ 「何もかも美しい日に人が死ぬ」ほうが、「雨の夜に人が死ぬ」より読者に刺さる
- 樹があんずの死を知る方法：**朝の学校で先生が言う。あっさりと**。「田中さんが昨日事故で——」。樹は最初理解しない。→ 「え？　昨日一緒にいたのに」

### 問題D: プロット全体が「テーマの論理的帰結」に見える

**根本的な問題**: 
> 「ASD的な主人公が論理を信じ、誤信念を抱き、それが崩壊し、受容を学ぶ」

これは**発達障害の当事者本**のあらすじであり、**小説のあらすじ**ではない。小説には「こうなるはずがないのにこうなった」という驚きが必要。

**打破アイデア**:

#### D-1: 「善意が人を殺す」のパターンを壊す3人目を入れる

現行の三重構造：
1. 樹のデート → あんずの死
2. 樹の教育 → 秀斗の崩壊
3. 綾の愛 → 秀斗の破壊

全部が「善意→加害」。パターンが見えすぎる。

**壊す方法**: **悪意が人を救うケースを1つ入れる**。

例えば：
- ACT3で、灘の友人が樹に**容赦ない批判**をする。「お前の論文、つまらん。データはあるけど魂がない」。樹は傷つく。→ しかしこの批判が樹の思考を深めた。→ 「善意が殺し、悪意が育てることもある」
- ACT4で、上司が「正しさは問題じゃない」と言うが、この上司は**別に優しい人ではない**。自分の部署の問題を処理したいだけ。→ 利己的な動機から出た言葉が、樹の世界を変える
- 秀斗が樹を**殴る**（ACT2 or ACT5）。この暴力が逆に二人の間の壁を壊す。→ 言葉ではない身体的衝突が、樹の論理を突き破る

#### D-2: 読者の予想を裏切る「あんずの真実」

現行：あんずは性的虐待を受けている「かわいそうな子」。

**裏切り案**: あんずの死の真の理由が、樹が（そして読者が）思っていたものと違ったら？

- あんずは**帰りたくなかったから死んだ**のではなく、**樹と別れたくなかったから死んだ**。帰れば虐待があるとわかっている。でも今までは「それが普通」だと思って耐えていた。樹のおかげで「普通じゃない」とわかってしまった。→ 死因は「認識」。情報が人を殺す。→ これは樹の「厳密な言語＝救済」の完全な裏返し。**知ることが人を殺す場合がある**

これは既にtheme.drawioの設計と整合する（「樹のデート→あんずが本当の優しさを知る→虐待を異常と認識→死」）。しかし現行では読者にこれが十分に伝わる設計になっていない。この「知ることが殺す」というアイロニーをもっと前面に出すべき。

#### D-3: ACT4に「樹が正しい場面」を入れる

現行ACT4は「樹の指導が暴力になる」一色。これが読者にとって見え透いている。

**打破**: **樹の指導で秀斗が実際に成長する場面を入れる**。

- 秀斗が樹のコードレビューで指摘されたことを直して、**プロジェクトで評価される**。秀斗自身も「成長した」と感じる。→ **だからこそ逃げられない**。「あいつの言うことは正しい」と秀斗が認めてしまっているから、「あれはパワハラだ」と言えない。→ 「正しいから逃げられない」のほうが「正しいのに壊れる」より一段深い
- 秀斗が**「ありがとうございます」と心から言う**場面を入れる。そしてその夜、ベッドで手が震える。→ 感謝と恐怖が共存している状態。これはテンプレでは出てこない

#### D-4: 物語の時間構造を崩す

「ACT1→2→3→4→5」という時系列順が予測可能性を強めている。

**崩す方法**:
- **ACT4から始める**。Google社。秀斗が崩壊し始める。樹は気づかない。→ 読者は「なぜこうなったのか？」を知りたくなる → ACT1〜3は回想として挿入
- **あんずの死のシーンをACT1に置く**。冒頭で少女が電車に飛び込む。読者は「誰？なぜ？」がわからない。→ ACT2で「あ、この子だったのか」とわかる → ACT4で「樹が原因だったのか」とわかる → 情報開示のタイミングが驚きを生む
- **エピローグから始める**（案3の枠構造）。カカメガの森で笑っている二人。読者は「え？なにこれ？」→ 回想が始まる

#### D-5: 「誰もが想像つく展開」を自覚的に壊す台詞を入れる

メタ的だが効果的：
- ACT5で秀斗が「お前はさ、全部わかった気でいるだろ。『かわいそうな俺を理解した』みたいな顔してんだろ。気持ち悪いんだよ」
- 樹が「……うん、そうかもしれん」
- → 読者が「こうなるだろうな」と予想していた「理解して寄り添う」を、秀斗が**拒絶する**。樹の「受容」が一度拒否される。→ その後で、何か別のもの（シュモクバエの航空券？ 図鑑？ 沈黙？）が二人を繋ぐ

### 問題E: 「予想外の展開」のための具体的シーン案

上記の構造的アイデアを組み合わせて、具体的な「こう来るとは思わなかった」シーンをいくつか。

#### E-1: 秀斗が樹に弁当を作ってくる（ACT4のどこか）

秀斗が崩壊し始める前、あるいは崩壊し始めた初期段階で。

```
昼休み。樹がいつも通りコンビニ飯を食べている。
秀斗が弁当箱を2つ持ってくる。

秀斗「はい、これ」
樹「……なに」
秀斗「弁当。昨日作りすぎた」

（秀斗は料理が趣味。母に褒められた唯一の「勉強以外のこと」）

樹、受け取って食べる。
「……美味い」
秀斗「当たり前でしょ」

→ 読者は混乱する。秀斗は樹を恨んでいるのでは？
→ 秀斗自身も混乱している。なぜ作ったのかわからない。
→ 「嫌いだと思っていた相手に弁当を作る」=秀斗のキャラの矛盾=次元
```

#### E-2: 樹が出勤中にアリの行列を見て遅刻する（ACT4）

```
朝、渋谷のスクランブル交差点の手前。
樹が突然しゃがむ。

スーツ姿の人間が周りを流れていく。
樹はアリの行列を見ている。

秀斗（後ろから来る）「何してんすか」
樹「アリ」
秀斗「見ればわかります。朝ですよ」
樹「これ多分キイロシリアゲアリ。こんな都市部にいるのは珍しい」
秀斗（呆れる）「……行きますよ」
樹「うん」（立ち上がらない）

→ 樹のASD的なこだわりが「可愛い」方向に出る唯一の場面
→ 秀斗が「呆れながらも待っている」=まだ関係が壊れていない時期
→ この場面をACT4の後半で反復：同じ場所で樹がしゃがむ。
　振り返ったら秀斗がいない。（秀斗は欠勤している）
→ 小さな反復が喪失を描く
```

#### E-3: あんずが保健室でシュモクバエの絵を描く（ACT2）

```
保健室。樹が図鑑を読んでいる。あんずが隣にいる。
沈黙。

あんず、保健室の色鉛筆で何かを描いている。
樹は気にしない。

しばらくして、あんずが紙を樹の前に滑らせる。

シュモクバエの絵。
目が左右にめちゃくちゃ離れている。
下手だけど、特徴は正確に捉えている。

樹「……よく覚えてたな」
あんず「へんな顔」

→ この絵がACTを跨ぐ小道具になる。
→ 樹はあんずの死後もこの絵を持っている。
→ ACT5の病室で、図鑑ではなくこの絵がカバンから落ちる。
→ 秀斗「何これ」→ 樹が初めてあんずのことを秀斗に話す。
```

**この案が解決する問題**:
- 小道具リレーの穴（あんずの小道具がない）
- あんずが「受動的」にしか見えない問題（自分から何かを作る行為）
- ACT5での自然な回想トリガー
- **タイトル「シュモクバエのこと、笑ってやろうぜ」がこの絵の記憶に繋がる**

#### E-4: 秀斗の母・綾が「いい母親の瞬間」を持つ（ACT1）

```
秀斗の家。深夜2時。
綾が勉強部屋にホットミルクを持ってくる。

綾「よくがんばってるね」

秀斗、ほっとする。
これだけは本当の優しさだと信じたい。

→ しかし読者には見える：
　綾は秀斗の勉強机の上のテスト結果をちらっと見てからホットミルクを出している。
　100点だったから、優しい。
→ 「条件付き愛の最も残酷な形」は愛に見えること。
```

#### E-5: 樹の母・裕子が「実は気づいていた」（ACT3 or ACT5）

```
ACT3（灘入学後）。裕子が樹の荷物を整理していて、図鑑を見つける。
シュモクバエのページに付箋が貼ってある。
あんずの絵が挟まっている。

裕子はしばらくそれを見て、そっと元に戻す。

→ 裕子は何を理解したのか、何も描かない。
→ 読者だけが「母は息子のことを、わからないなりに見ていた」と感じる。
→ 樹が信じる「母のプリント＝非効率な愛」が、実はもう少し深いものだったかもしれない
→ ACT5で「辛かったやろ」を言えたのは、父だけでなく母からも何かを受け取っていたから
```

## おわりに

ユーザーが感じている「個性のなさ」の正体は、**キャラクターが構造の関数になっている**こと。McKee理論で構造を固めた結果、人物が「テーマを証明する装置」になっている。

解決策は**構造を壊すこと**ではなく、**構造の隙間にキャラクターの不合理さを差し込むこと**。

シュモクバエはまさにその「不合理さ」の象徴として機能する。論理では説明できない執着、分類できない感情、意味のない行動——それこそがこの物語のテーマそのもの（「理解できなくても寄り添える」）であり、同時にキャラクターを生きた人間にするための鍵でもある。

「構造の正しさ」と「キャラの不合理さ」が共存したとき、この小説は本当に面白くなる。シュモクバエは、その共存の入口になりうる。
