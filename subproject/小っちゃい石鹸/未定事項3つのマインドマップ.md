# 小っちゃい石鹸 — 未定事項3つのマインドマップ

元の種：[構想.txt](構想.txt) ／ 入口：[[workspace_hub]]

構想の未定事項を「絡み・何が癒されるか」「なたねあぶらの背景」「最後の心の動き」の3つにまとめた候補集。各枝は別案で、別のマップの枝とも自由に組み合わせられる。「癒される」は、会話の中で少し緩む感覚として考える。

## 1. どんな絡みをするか・何が癒されるか

```mermaid
mindmap
  root((絡みと癒されるもの))
    敵同士のくだらない口喧嘩
      油が毎日どうでもいい宣戦布告
      石鹸は律儀に抗議してしまう
      頭が自分への攻撃から少し逸れる
    何もしない物の勤務報告
      油は黄色を保つ係
      石鹸は小皿にいる係
      何もできない日にも会話に参加できる
    二人だけの架空のお出かけ
      台所旅行を実況する油
      石鹸は洗面台の港から参加
      外へ行けない夜に一緒の思い出ができる
    弱音を商品表示にする
      石鹸は本日ひび割れ注意
      油は開封後お早めにかまってください
      人間の事情を説明せず弱音を渡せる
    油のごっこが下手になる日
      いつもの溶けちゃうに勢いがない
      石鹸が初めて敵役を買って出る
      自分も相手の夜に何か返せる
```

## 2. なたねあぶらのバックボーン

本文には背景を明示せず、投稿の癖や、ごっこを選んだ理由にだけ滲ませる案。

```mermaid
mindmap
  root((なたねあぶらの背景))
    病弱で外出が難しい
      周囲にはいつも心配される側
      ネットでは自分からちょっかいを出したい
      元気だった頃の揚げ物の匂いから油
    いじめで学校に行けない
      教室では何を言っても笑われた
      今度は自分が仕掛けた冗談で笑ってほしい
      菜の花畑に行く遠足だけ覚えている
    家庭の管理が厳しく外出できない
      本名ではいい子を続けている
      物のアカウントでは面倒な敵役になれる
      台所の油は自由に扱える数少ない物
    家族の世話で家を空けられない
      食事を作るので油が身近
      返信は家事の合間に突然途切れる
      役に立つ毎日から無意味な遊びへ逃げる
    明るい自分を続けられず不登校
      現実では場を盛り上げる役に疲れた
      油なら黙る日も固まってましたで済む
      名前は手近な瓶から適当に借りただけ
```

## 3. 最後にどういう心の動きをするか

石鹸がすり減り、自撮りから消える案を起点にした分岐。

```mermaid
mindmap
  root((石鹸が消えたあとの心))
    石鹸と自分を少し切り離せる
      空の小皿を撮って本体は撮影係でした
      石鹸の終わりのあとも自分は投稿している
    明日にもくだらない用事が残る
      油が小皿の引継ぎ式を勝手に予約
      明日の返事をぼんやり考えてしまう
    ごっこの外の言葉が一語出る
      石鹸の消失にさびしいとだけ書く
      自分の感情を相手へ渡してみたくなる
    相手の不在が気になる
      最後の自撮りより油の沈黙を気にする
      敵はどこですかと自分から呼びかける
    終わることが少し惜しくなる
      空の小皿を油が空き物件と呼ぶ
      腹が立って返信を書き始める
      まだこの馬鹿な会話をしていたい
```

気になった枝から会話を一往復書く。背景・癒され方・結末の組み合わせは、その会話が面白くなってから選べばよい。
