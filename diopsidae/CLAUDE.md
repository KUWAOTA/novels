# diopsidae — 小説プロジェクト コンテキスト

## 概要

**タイトル:** Constrain（制約）
**ジャンル:** 純文学・心理ドラマ
**主人公:** ASD傾向を持つエンジニア（名前なし）

**統制概念（テーマ命題）:**
> 「精密さで世界を守ろうとした人間が、誤解と傷で成り立つ社会を、完全な理解なしに愛せるようになる」

**価値軸:**
```
理解すれば救える → 理解しても救えない → 理解できなくても寄り添える
```

## 現在の構成方針

プロットや設定は、順番どおりに空欄を埋める設計図ではなく、執筆中に方向を確かめる羅針盤として扱う。ACTごとの本文管理は廃止し、幼少期と社会人時代を中心に、書ける場面から `本文/本文.txt` へ自由に書く。場面の採否・順序・区切りは、原稿が育ってから決める。

旧ACT構成と未執筆枠は `_内部/old/本文_ACT構成_2026-09-02/` に保存している。

## 執筆フォーマット規約

- シーン素材は `<シーン名>/vN/<シーン名>.txt` 形式
- 新しい版では直前の版を残す

## プロット更新時の手順

プロットを更新したら（`../.agent/skills/constrain-plot-sync/SKILL.md` 参照）:
1. `_内部/old/brainstorm/plot_history.md` に変更記録を追記
2. `settings/v5/plot.drawio` を配色規約に従って更新
3. `git commit -m "sync: plot YYYY-MM-DD 更新反映"`

## Antigravity スキル

## Prompt Normalization Rule

依頼が短文、抽象的、または断片的な場合は、`../.agent/skills/prompt-refinement/SKILL.md` を先に適用する。

- まず候補出しか確定更新かを判定する
- プロット（`_内部/old/brainstorm/`）に触れる恐れがある場合だけ確認する
- 致命的な不足がなければ、既存テーマに沿う候補として進める
