# 20260422提出分

## 主な観点

- 筆者の意図適合性
- 文体
- ストーリー構造
- 内容の面白さ
- レビュワーならではの視点


### 筆者の意図適合性（PROLOGUE）

1. 循環構造がこの物語において読者を引き込む形で提示されているか
2. 主人公のASD特性を明瞭化し、暗黙の問いを投げかけて読者を引き込めているか
3. この物語のテーマである、曖昧さとの対峙を読者に匂わせることができているか
4. それでいて、テーマが明示されすぎていて読者を萎えさせることがないか

### 文体

以下は、レビュー観点の例

1. 語り口の統制
例えば、3人称1視点（主人公の視点に固定した三人称）が正しく維持されているかなど

2. 文章リズムのよさ

3. 選ばれた言葉の必然性
主人公のセリフの語彙や比喩の選び方が、ASD傾向のエンジニアであるという設定と矛盾していないか、など

4. 描写性
無理に情報を詰め込んでいて、読んでいて映像の浮かばないものになっていないか、など

### ストーリー構造

以下は、レビュー観点の例

1. 構成上無理がないか

2. テーマとの一貫性
テーマに沿った内容になっているか、それをどれだけ示せているか
（あくまでプロットはプロットでしかないので、逸れていたとしてもそこに合わせて修正するのはあり）

### 内容の面白さ

自分で言っておいて観点を考えるのが難しい

### レビュワーならではの視点
ここに関しては経験の少ない僕が気づいていないであろう観点を見ていただけると助かる
正直、上記までにあげた観点は僕が知っている技巧について書いたものに過ぎない気がする。
