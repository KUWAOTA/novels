# v7 — Y・X・Wから設計する構想案

**01 → 02 → 03で目的・世界を選ぶ理由・必要な体験を確認してから、04以降の物語案を読みます。** 各シート上部に移動リンクがあります。

今回の対話で合意した起点：

- **Y（動機）**：自分の空想が形になること、その世界が誰かの楽しみにもなること自体が嬉しい。
- **X（実現したいこと）**：自分が作りたい世界を、読者が冒険して楽しめる作品にする。現時点のX′（実現すべきこと）も同じと置く。
- **W（構築したい世界）**：表面の言動だけでは見えない事情や構造があり、言葉によってそれを発見できる。見ている自分も、その構造の中にいる世界。

Y・X・Wを起点に、wとストーリーは今回の候補として置いています。作者の動機全体を解明したという扱いではありません。

今回の補足「自分の経てきた経験や、獲得した価値観だからこそ伝えたい。他のどんな空想よりも伝えたいというパッションがある」は、**このWを選ぶ動機**として配置しています。「なぜ創作するか」のYと「なぜこの作品を選ぶか」の動機が併存し、後者がX→Wの選択に働く、という整理です。両者を一つの上位目的に還元する必要はありません。経験で得た構造や感触を人物・出来事に組み直すことを設計の基準とし、出来事の変更はその視界が伝わるかで判断します。

読者に経験してほしい核は、**世界がクリアになる快感と、その世界の中で他者と自分の意味が変わる冒険**。主題の変化「他者を裁く → 自他の不完全さを受け入れる → 他者の幸福を願う」と、作者の創作動機Yを区別しています。

物語の仮配置では「空気が読めない苦しさ」と、社会人編の「論理のメガネによる本物の救い」を残しました。短い分析ノートから始め、本編は中学から時系列で進めます。論理が見通しをよくする楽しさは結末まで続きます。

父の死を全編の契機、秀斗との再会を副線との合流、欠勤と指導拒否を最終幕へ押す転換に置いています。価値軸「孤立 ⇄ 協働」と、因果形の統制概念は今回の設計仮説です。

研究開発の異動枠、移管の期限、既存・新方式、役割分担と承認手続きは仮設定です。具体業務と品質基準、代替案の制約、選ぶ代価の自然さは今後の検討点。既存本文の年表・手続きとは未同期です。樹／秀斗の性別・外見は未固定、あんずなしの配置例です。
