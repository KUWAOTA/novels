# 小説プロジェクト「diopsidae」

シュモクバエの学名（*Diopsidae*）を冠した、純文学小説のプロジェクトです。

---

## フォルダ構成

```
diopsidae/
├── 本文/         ← 番号付きシーンの原稿、旧素材、統合原稿
├── 設定資料/     ← キャラクター・プロット・テーマの設定資料
└── _内部/        ← 内部資料（作業ログ・旧バージョン等）
```

---

## 📝 本文フォルダ

原稿は `本文/番号.シーン名/vN/本文.txt` で場面ごとに管理します。場面一覧と現行版は [本文の管理](本文/README.md) を参照してください。従来の統合原稿は参照用に保存しています。

| フォルダ | 内容 |
|---------|------|
| `0.プロローグ/` | プロローグの各版とレビュー資料 |
| `1.…/`〜`10.…/` | 場面ごとの版。8〜10は未執筆 |
| `N.エピローグ/` | エピローグの各版とレビュー資料 |
| `旧素材/` | 旧構成で書かれた参考資料 |

旧ACT構成と未執筆枠は `_内部/old/本文_ACT構成_2026-09-02/` に保存しています。

### ファイルの読み方

- `vN/本文.txt` — その版のシーン本文
- `master.md` — 構造メモ（シーン設計）
- `omote.md` — スマホ向け整形版
- `kyakuhon.md` — 脚本形式の草案

---

## 📊 設定資料フォルダ

物語の設定資料です。最新版は `v5/` にあります。

| ファイル | 内容 |
|---------|------|
| `v5/characters.drawio` | キャラクター関係図（draw.io で開く） |
| `v5/plot.drawio` | プロット構造図 |
| `v5/theme.drawio` | テーマ・価値軸の図 |

ファイルは [draw.io](https://app.diagrams.net/) で開けます。

Discord に添付する高解像度 PNG は [人物関係図](設定資料/v5/discord/characters.png)、[プロット構造図](設定資料/v5/discord/plot.png)、[テーマ図](設定資料/v5/discord/theme.png) です。各 draw.io 原本から２倍の解像度で書き出しています。

本文に書かれた場面と日記の年代順は、[本文時系列.svg](設定資料/本文時系列.svg) で確認できます。SVG はブラウザや Obsidian でも表示できます。

---

## バージョン管理について

- `設定資料/` 内は `v3/`, `v4/`, `v5/` でバージョン管理されています
- 本文の修正履歴は Git（このリポジトリ）が管理しています
- **ファイルは削除しないでください**。過去のバージョンはいつでも参照できます
