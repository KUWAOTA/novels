# 小説プロジェクト「diopsidae」

シュモクバエの学名（*Diopsidae*）を冠した、純文学小説のプロジェクトです。

---

## フォルダ構成

```
diopsidae/
├── 本文/         ← 小説の本文ファイル（メインの編集場所）
├── settings/     ← キャラクター・プロット・テーマの設定資料
└── _内部/        ← 内部資料（作業ログ・旧バージョン等）
```

---

## 📝 本文フォルダ

`本文/` フォルダが執筆の中心です。

| フォルダ | 内容 |
|---------|------|
| `PROLOGUE/` | プロローグ ← ここが黒田さんへのレビュー依頼範囲 |
| `ACT1/` | 小学生時代（孤立・いじめ） |
| `ACT2/` | 中学時代（あんずとの出会い・あんずの死） |
| `ACT3/` | 灘高校〜東大 |
| `ACT4/` | 社会人（Google Japan） |
| `ACT5/` | クライマックス |
| `EPILOGUE/` | エピローグ |

各シーンフォルダの中に `本文.txt`（メインテキスト）があります。

### ファイルの読み方

- `本文.txt` — 現在の本文（主に読むファイル）
- `master.md` — 構造メモ（シーン設計）
- `omote.md` — スマホ向け整形版
- `kyakuhon.md` — 脚本形式の草案

---

## 📊 settings フォルダ

物語の設定資料です。最新版は `v5/` にあります。

| ファイル | 内容 |
|---------|------|
| `v5/characters.drawio` | キャラクター関係図（draw.io で開く） |
| `v5/plot.drawio` | プロット構造図 |
| `v5/theme.drawio` | テーマ・価値軸の図 |

ファイルは [draw.io](https://app.diagrams.net/) で開けます。

---

## バージョン管理について

- `settings/` 内は `v3/`, `v4/`, `v5/` でバージョン管理されています
- 本文の修正履歴は Git（このリポジトリ）が管理しています
- **ファイルは削除しないでください**。過去のバージョンはいつでも参照できます
