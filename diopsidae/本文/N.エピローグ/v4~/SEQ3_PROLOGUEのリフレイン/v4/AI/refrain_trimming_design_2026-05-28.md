# SEQ3_PROLOGUEリフレイン 削り方・残す描写 設計たたき台

対象: `diopsidae/本文/EPILOGUE/v4~/SEQ3_PROLOGUEのリフレイン/本文.txt`

## 結論

SEQ3は、PROLOGUEのコピーとして読ませるより、「読者にPROLOGUEを思い出させる入口」として設計した方が強いです。

つまり、日記本文を全部再掲しない。樹が日記に到達するまでの現在時制の衝動を中心に置き、最後にPROLOGUEの最初の数行だけを見せて切る。読者に「あ、ここが冒頭につながるのか」と気づかせれば十分です。

削る方向は次の通りです。

- 残す: 帰宅直後に押し入れへ向かう衝動
- 残す: ノートの束、ビニールテープ、100冊以上という物量
- 残す: 秀斗の声が残り続けること
- 残す: 解釈の余地が膨張すること
- 残す: 生活リズムや薬の通知を無視すること
- 残す: 最初の日記へたどり着く瞬間
- 削る: 押し入れの上下段など、空間説明としてだけ機能する描写
- 削る: 日記本文の長い再掲
- 削る: PROLOGUEで読者がすでに知っている情報の説明
- 追加可: 「読者が知っている冒頭」を、現在の樹が別の意味で読み直している描写

## このSEQ3の役割

SEQ3の役割は、過去を説明することではありません。

役割はこれです。

```text
SEQ2で保留した曖昧さ
  ↓
帰宅後に耐えきれなくなる
  ↓
過去ログを掘る
  ↓
最初の日記へ到達する
  ↓
物語冒頭が、最後の樹の探索結果だったとわかる
```

だから、読者に必要なのは「日記の内容」ではなく、「なぜ今それを開いたのか」です。

PROLOGUEの本文はすでに読者の記憶にあるので、SEQ3で全部繰り返すと冗長になります。むしろ、少しだけ見せて読者の記憶に接続させる方が、循環として上品です。

## 残すべき描写

### 1. 帰宅直後の異常な速度

現行:

```text
ケニアから桜新町のアパートに帰り着いたその足で、樹<いつき>は寝室の押し入れへ向かった。
```

これは残すべきです。「その足で」が強い。SEQ2の曖昧さが、休むこと・荷解き・入浴・睡眠より優先されているとわかります。

ただし、SEQ2からの接続を強めるなら、直前に一文だけ入れるとよいです。

候補:

```text
桜新町のアパートに着くまで、樹は「丸くなった」の意味を三十七通り考えた。
どれも却下した。
却下したはずなのに、言葉は消えなかった。
```

この3文があると、押し入れへ向かう行動が「急に思いついた行為」ではなく「解析不能の末の過去参照」になります。

### 2. ノートの束の物量

現行:

```text
下の段には丁寧にビニールテープで縛られて真ん中だけ食い込んだノートの束が100冊以上積み上げられていた。
中学生のころからの日記だ。
```

ここは残す価値が高いです。特に「ビニールテープで縛られて真ん中だけ食い込んだ」が良い。過去が保管されているだけでなく、圧迫され、束ねられ、封じられていた感じが出ます。

ただし、押し入れの上下段説明は短縮できます。

圧縮案:

```text
押し入れの下段には、ビニールテープで縛られ、真ん中だけ食い込んだノートの束が積み上がっていた。
中学生のころからの日記だった。
```

「100冊以上」は残してもよいですが、少し数字が説明に見える場合は後ろへ逃がせます。

```text
ほどいてもほどいても、同じサイズのノートが出てくる。百冊を超えたところで数えるのをやめた。
```

この方が、物量を行動で見せられます。

### 3. 秀斗の声と解釈の余地

現行:

```text
ずっと秀斗の声が、樹の頭の中で再生されているのだ。
何度消そうとしても、地震警報のサイレンのように耳に残り続けている。
言葉の解釈の余地が煙のようにむくむくと膨れ上がって拡散していく。
それをかき消す手がかりが欲しくて、樹は過去を遡るのをやめることができなかった。
```

ここはSEQ3の核です。残すべきです。

ただし、「地震警報のサイレン」と「煙」はどちらも強い比喩なので、両方あると少し比喩が多いかもしれません。どちらか一つを主軸にした方が締まります。

おすすめは「煙」を残すことです。理由は、「解釈の余地」が形を持たず、部屋に広がり、ノートの束を探す行為に接続しやすいからです。

圧縮案:

```text
秀斗の声は、再生を止めたはずの録音みたいに頭の奥で鳴り続けていた。
丸くなった、という言葉の解釈の余地が、煙のように部屋の中へ広がっていく。
樹はそれを薄める手がかりが欲しくて、過去を遡った。
```

「地震警報」を残したいなら、煙を削る方がよいです。

```text
秀斗の声が、地震警報のサイレンのように頭の中で鳴り続けていた。
止めるには、原因を特定するしかない。
樹はノートの束に手を突っ込んだ。
```

こちらは樹の「原因特定」衝動が強く出ます。

### 4. スマートウォッチの通知

現行:

```text
普段通りの時間に寝ろ、睡眠前に薬を飲めと、規則正しい生活をせがむスマートウォッチのスヌーズを、30回は無視していた。
```

これは残す価値が高いです。樹の現在の生活、自己管理、薬、規則性が一文で見える。しかも、その規則性を破ってまで日記を漁っているので、SEQ3の異常性が出ます。

ただし「30回は無視していた」はややコミカルなので、終盤の温度に合わせて調整できます。

現行の軽さを残すならそのままでよいです。

より切迫させるなら:

```text
スマートウォッチは、睡眠と服薬の通知を何度も震わせた。
樹はすべてスヌーズに送った。
```

より樹の自己認識に寄せるなら:

```text
睡眠と服薬の通知を無視するのは、普段の樹ならエラーだった。
そのエラーを、樹は三十分ごとに延長した。
```

この案は、SEQ2の「停止というアルゴリズム」と接続しやすいです。

### 5. 日記を開く瞬間

現行:

```text
ようやく手に取った一冊は表紙が黄ばんでいて、埃を払うとカビが放出する揮発性物質の臭いがした。
それが樹には懐かしく思えた。
書きなぐってきた分だけ分厚く膨らんでいた。
樹は表紙の日付を指でなぞって、ゆっくりとその日記の1ページめを開いた。
象形文字と見まがうような殴り書きがびっしりとページいっぱいに書き込まれていた。
```

ここも残す価値が高いです。ただし少し長いので、日記本文を削るならここを丁寧に残すのはありです。

特に「カビが放出する揮発性物質の臭い」は樹らしい。普通なら「カビ臭い」で済ませるところを物質名っぽく見るのが良いです。

圧縮案:

```text
ようやく見つけた一冊は、表紙が黄ばんでいた。
埃を払うと、カビが放出する揮発性物質の臭いがした。
懐かしい、と樹は思った。
その判断が正しいのかどうかは、わからなかった。
```

最後の一文を足すと、現在の樹が「感情を判定しようとしている」感じが出ます。

## 削るべき描写

### 1. 押し入れの上段の布団

現行:

```text
押し入れの上の段には布団がぎゅうぎゅうに詰め込まれていた。
```

これは削ってよいです。部屋の物理配置としては自然ですが、循環構造にはあまり寄与しません。

残すなら、日記が「下段に封じられている」ことを示すために一文へ圧縮します。

```text
布団の下に、ビニールテープで縛られたノートの束が沈んでいた。
```

この方が象徴的です。過去が寝具の下に沈んでいる感じも出ます。

### 2. アリクイ比喩

現行:

```text
蟻塚の穴という穴に舌を挿入しては捕食を繰り返す、アリクイのようだった。
```

これは面白いですが、終盤でかなり目立ちます。昆虫・蟻塚の連想として作品には合っていますが、「日記へ戻る」場面では比喩が強すぎて、読者の注意がアリクイに持っていかれる可能性があります。

残すなら、少しだけ弱めた方がよいです。

候補:

```text
蟻塚の穴を一つずつ探るみたいに、樹はノートの束をほどいていった。
```

これなら昆虫連想を残しつつ、グロテスクさが下がります。

削っても問題ありません。むしろ日記の物量と秀斗の声を中心にしたいなら、削った方が締まります。

### 3. 日記本文の長い引用

ここが最大の削り対象です。

現行では、PROLOGUEの内容をほぼ再掲しています。循環は伝わりますが、読者にとっては「もう読んだ情報」になる可能性が高いです。

おすすめは、日記本文を全部載せず、最初の3〜5行だけにすることです。

残す候補:

```text
2011年5月13日
ニンゲンは魔法を使うようだ。
顔を見るだけで相手の気持ちがわかるという。
優れた魔法使いに言葉は要らないようだ。
言葉というはしごを使わないといけない僕は、どうやら落ちこぼれの魔法使いらしい。
```

ここまでで十分です。

理由:

- 「ニンゲン」
- 「魔法」
- 「言葉」
- 「はしご」
- 「落ちこぼれ」

この5つが出れば、読者はPROLOGUEへ接続できます。シュモクバエの説明まで再掲しなくても、タイトルや作品全体から読者は思い出せます。

## 別視点から足すなら何がよいか

「削るだけではなく別視点の描写を足す」なら、以下の3方向が候補です。

### 案A: 現在の樹が昔の日記を読む視点

これは一番おすすめです。

PROLOGUEでは、日記の中の少年の樹が世界を見ていた。SEQ3では、大人の樹がその少年の文章を読む。つまり同じ文章でも、視点が変わる。

足すならこういう方向です。

```text
字は汚かった。
けれど、そこに書かれている怒りの形だけは、今の樹にも読めた。
読めてしまうことが、少し嫌だった。
```

この一文があると、単なる再掲ではなく「現在の樹による読み直し」になります。

### 案B: 部屋の静けさを使う

SEQ2は渋谷駅の人混みでした。SEQ3は桜新町のアパートの静けさ。対比が効きます。

足すなら:

```text
渋谷駅では、言葉は人の流れに紛れていた。
部屋に戻ると、同じ言葉だけがやけに大きかった。
```

これはかなり使いやすいです。SEQ2との接続も明確です。

### 案C: 荷物をまだ下ろしていない描写

ケニア帰りの身体性を残すなら、ザックやタモを使うのがよいです。

```text
ザックを下ろす前に押し入れを開けたせいで、金属フレームがふすまの縁に当たった。
タモの柄が畳の上を転がり、ノートの束の前で止まった。
```

これはかなり良いです。SEQ1/SEQ2のケニア帰りの物体が、SEQ3の過去ログに物理的に接触する。現在と過去が同じ部屋でぶつかる感じが出ます。

特に「タモの柄がノートの束の前で止まる」は、シュモクバエ探しと日記探索が重なります。

## 推奨構成

全体の構成は、以下くらいがよいです。

```text
1. 帰宅まで「丸くなった」が消えない
2. 荷物を下ろす前に押し入れへ向かう
3. ザックやタモが部屋に引っかかる
4. ノートの束を見つける
5. 生活通知を無視しながら探す
6. 最初の日記を見つける
7. 大人の樹が昔の字を見る
8. 日記の冒頭だけ引用する
9. 引用を途中で切る、または「そこに、始まりがあった」で終える
```

この構成なら、PROLOGUEのコピーではなく、PROLOGUEへ戻るための導線になります。

9. 日記冒頭の5行程度

## 削る描写リスト

優先度順です。

1. 日記本文の長い再掲
2. 押し入れ上段の布団説明
3. 「100冊以上」を静的に説明する一文
4. アリクイ比喩の強い版
5. 「象形文字と見まがうような殴り書き」の説明的な締め

「象形文字」は悪くありませんが、日記本文を数行だけ見せるなら、読者が字の荒さを想像できます。残すなら、現在の樹の読み直しに接続する形がよいです。

```text
象形文字みたいな字だった。
それでも、そこに書かれている怒りの向きだけは読めた。
```

## 最終提案

SEQ3は、日記の内容を再提示する場面ではなく、樹が「最初の自分」に戻ろうとする場面です。

だから削る基準は単純です。

```text
読者がすでに知っている情報は削る。
現在の樹がなぜそこへ戻るのかを示す描写は残す。
現在と過去が同じ部屋で接触する描写は足す。
```

一番足す価値があるのは、ザックやタモが部屋に引っかかる描写です。ケニア帰りの現在と、中学生の日記という過去が、物理的に同じ畳の上へ置かれるからです。

この方向で削れば、SEQ3は冗長なコピーではなく、「PROLOGUEをもう一度読ませるための最後の扉」になります。
