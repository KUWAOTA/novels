# 本文の使い方

このフォルダでは、プロットを固定された工程表ではなく、執筆の方向を確かめるための羅針盤として扱います。ACT順に空欄を埋めるのではなく、いま書ける場面を `本文.txt` に飛び飛びに書き、物語が育ってから場面の順序や区切りを決めます。

## 執筆するファイル

- `本文.txt` — 現在の原稿。プロローグとエピローグの間が自由記述領域です。
- `プロローグ/` — プロローグの過去稿とレビュー資料です。
- `エピローグ/` — エピローグの過去稿とレビュー資料です。
- `シーン素材/` — 旧ACT構成で実際に文章が書かれていた場面です。本文へ組み込むことを前提にせず、元ネタとして参照します。

## シーン素材の版管理

各シーンは `シーン素材/<シーン名>/v1`, `v2`, `v3` … の単位で保存します。既存稿を大きく書き直す場合は、直前の版を残したまま新しいバージョンフォルダを作ります。本文ファイル名にはシーン名を付けます。

現在の素材は次の5シーンです。

- `ASD傾向で孤立`
- `母とのトラブル`
- `父から仮説を学ぶ`
- `あんずの電話`
- `秀斗の二重の羨望`

旧ACT構成と未執筆のシーン枠は、削除せず `_内部/old/本文_ACT構成_2026-09-02/` に保存しています。
