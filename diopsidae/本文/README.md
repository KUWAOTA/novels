# 本文の管理

場面ごとに `番号.シーン名/v1/本文.txt`、`v2/本文.txt` … と保存します。プロローグは `0`、エピローグは `N` です。大きく書き直すときは直前の版を残し、次の番号の版を作ります。番号は現在の原稿での掲載順であり、今後の構成変更に応じて見直せます。

`シュモクバエのこと、笑ってやろうぜ.md` は、分割時点の統合原稿として残します。上記の `vN/本文.txt` は、その統合原稿の各場面を本文を変えずに切り出した版です。8〜10 は場面の枠だけ作り、執筆時に `v1/本文.txt` を追加します。

`旧素材/` は旧構成で書かれた参考資料です。現行の場面フォルダとは区別して残します。エピローグの `v4~/` は従来の検討資料を保持する場所で、現行原稿は `N.エピローグ/v4/本文.txt` です。
