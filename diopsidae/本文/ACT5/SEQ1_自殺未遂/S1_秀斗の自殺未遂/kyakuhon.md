# S1 脚本: 秀斗の自殺未遂 → 樹が走る

## 何が起きるか

- 報せを聞いて走り出す。あんずの顔が浮かぶ
- 「今度は間に合うかもしれない」
- ピュアだからわけもわからず止めようとする
- 秀斗が樹に呪い事を吐く
- 自殺自体は一瞬で、止めた後が重要

## 秀斗側（客観）

- 3つの圧力が同時に限界を超える
- ★ あんずの電車飛び込みと構造的にエコー

### たたき台の脚本

〇樹の家の前
　秀斗が玄関のベルを鳴らす。
　樹が急いでドアを開ける。
樹「今まで大丈夫だったか？」
　秀斗は包丁を手に握りしめている。
秀斗「（殺意のこもった台詞）」
　秀斗が包丁を振りかざそうとする。
　秀斗の手が震えて動かなくなる。　
　秀斗、涙を流す。　←　ありきたり？もうちょっと母さんへのコンプレックスをにおわせる感じにしたい。
秀斗「（人を殺すなんてできるわけないよな、というあきらめのこもった台詞）」
秀斗「（俺の人生さんざんだったからここで死んでやらあ　みたいな台詞）」
　自殺という言葉を聴き、あんずのトラウマを思い出し、（なんかいいアクション）する樹。

　秀斗が自分の胸に包丁を突き刺そうとする。
　樹がその腕を止めようとする。
　秀斗の方が力強いので、樹は押し負ける。
樹（このままでは死んでしまう、何か止まることを言わなくてはと焦る）
樹「死ぬくらいならケニア行こうぜ！」
　秀斗、思いもよらない台詞に、きょとんとした顔をする。
樹「ケニアに行って、シュモクバエとかいうわけのわからんハエのことを笑い飛ばして、それでも死にたいなら死んでくれ！」
　秀斗、さらにきょとんとする。
樹「やらかした、考えたことをそのまま喋ってしまった。意味わからないよな。とにかく死んじゃいけない理由としてまず説明するべきは...」
　目の前で焦る樹。
　本気で焦って、死んでほしく
秀斗「なんだよそれ」
　秀斗が包丁を放って、地面に崩れて笑い出す。
秀斗「(俺、こんなアホなやつを恨んで、こんなんになっちまったのかよ...)的なセリフ」
秀斗「だいたい、俺のこと恨んでたんだろ。死なせりゃいいじゃん」
樹「なんで恨んでいるの？僕が」
秀斗「えっ？」
秀斗「（俺だけかよ、こんなに因縁もってたの）みたいな台詞」
　泣き笑いをする秀斗。

### 問題点、相談転

感情のやり取りが台詞でしかできないがゆえに場面が長くなりそう
秀斗が、樹に学生時代のこと恨んでるんだろ、みたいなこと言って樹がきょとんとして、余計逆上するようなやりとりも、包丁を止めるまでのやり取りに入れておきたい。

樹の葛藤をどこに挟み込むかを考える必要がある。脚本はあくまで心理描写はなくそれを想起させるものであるが

同scene設計したら葛藤とかをうまく盛り込めるかを相談したい。
ちょっと、今のシーン設計だとつじつまを合わせることで手一杯で、面白味の糧となる葛藤が演出できていない。
