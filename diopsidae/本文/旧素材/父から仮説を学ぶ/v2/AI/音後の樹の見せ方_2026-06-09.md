# S4 v2 音のあとに樹をどう見せるか

対象:
`diopsidae/本文/ACT1/SEQ2_父との絆と喪失/S4_父から仮説を学ぶ/v2/本文.txt`

直前:

```text
カーテンが揺れている。
天井から吊られたレースの白が、外から入る風で、ふくらんで、戻って、また少しふくらむ。
そのわずかな隙間から、眩しい空の青が現れては消える。
その光が、白すぎる病室の壁を少しだけやわらげていた。
きい、と鳴った。
少し遅れて、床がこつ、と鳴った。
きい。
こつ。
きい。
こつ。
```

## 結論

ここからは、樹をいきなり「樹が椅子で回っていた」と説明しない方がよいです。

おすすめは、**音の正体を身体の一部から明かす**流れです。

```text
[音]
  -> [カーテン下を靴先が横切る]
  -> [もう一度横切る]
  -> [丸い椅子の座面]
  -> [樹の足が床を蹴っている]
  -> [樹の全身]
  -> [父の視線]
```

この順番なら、音から映像へ戻る感じが自然です。

## 重要な方針

### 1. 樹の名前を急いで出さない

最初から「樹が」と出すと、音の謎が一気に説明になります。

最初は、

```text
靴先
膝
ランドセルの肩紐
椅子の丸い座面
床を蹴る足
```

のように、部分で見せるとよいです。

### 2. 反復の快さを見せる

樹は落ち着きなく暴れているのではなく、反復に安心している。  
なので、動作は乱暴ではなく、一定のリズムにする。

```text
蹴る
回る
父の前を通る
また蹴る
同じ景色が戻る
```

この反復が、樹にとっての安心になる。

### 3. 父の視線は途中で入れる

樹だけを長く見せると、単なる奇行に見える危険があります。  
途中で父を入れると、「この行動が許されている場所」だとわかります。

```text
樹が回る
父の顔が見える
父は止めない
樹がまた回る
```

## 案A: 靴先から明かす

```text
[音]
  -> [レースの裾の下を靴先が横切る]
  -> [少し遅れて、もう一度横切る]
  -> [靴底が床を蹴る]
  -> [こつ]
  -> [椅子が鳴る]
  -> [きい]
```

効果:
- 音の正体に自然に近づける
- カーテン描写とつながる
- まだ全身を見せないので、カメラがきれいに引ける

文章化の方向:

```text
レースの裾の下を、靴先が横切った。
少し遅れて、同じ靴先がもう一度横切った。
```

このあとに「床を蹴る」を置くとよいです。

## 案B: 椅子の部品から明かす

```text
[音]
  -> [丸い座面の端]
  -> [金属脚]
  -> [床に触れる足]
  -> [樹の足]
```

効果:
- 音の発生源がわかりやすい
- 道具の映像が立つ
- 回転椅子の存在をスムーズに出せる

注意:
- 物から入りすぎると、樹の身体感覚が少し遅れる

文章化の方向:

```text
丸い椅子の脚が、床の上で少しだけ向きを変えた。
座面の端に、樹の指がかかっていた。
```

ただし、この案は少し説明的になりやすいです。

## 案C: 父の視線から明かす

```text
[音]
  -> [父の目が同じ場所を追う]
  -> [父の目の先を追う]
  -> [回る樹]
```

効果:
- 父の受容を早く出せる
- 読者は「父が何を見ているのか」と自然に追う
- 安心感が最初から入る

文章化の方向:

```text
ベッドの上の父は、その音の方を見ていた。
目だけが、右から左へ、ゆっくり動いた。
```

注意:
- 樹の正体を明かす前に父を出すので、少し視点が父寄りになる

## 案D: 樹の身体感覚から明かす

```text
[音]
  -> [床を蹴る足]
  -> [体が半分回る]
  -> [景色が順番に見える]
  -> [父の顔]
```

効果:
- 三人称樹視点に合う
- 樹が回転で安心している感じを出しやすい
- 発達特性を説明せずにshowできる

文章化の方向:

```text
右足で床を蹴ると、白い壁が横へずれた。
次に窓が来て、カーテンが来て、父のベッドが来た。
```

注意:
- 音の正体は早めにわかる

## 一番おすすめの組み合わせ

おすすめは、**案A → 案D → 父の視線**です。

```text
[音だけ]
  -> [靴先が横切る]
  -> [床を蹴る足]
  -> [樹が回っているとわかる]
  -> [景色の反復]
  -> [父の顔が一周ごとに戻る]
  -> [父は止めない]
```

理由:
- カーテンから靴先へつながる
- 音の正体を自然に明かせる
- 樹の身体感覚が出る
- 父の安心感も立つ

## 具体的な流れ案

本文に変換する前の映像順はこれがよいです。

```text
きい。
こつ。
きい。
こつ。

[レースの裾の下]
  -> [靴先が横切る]
  -> [同じ靴先がもう一度横切る]

[床]
  -> [右足が床を蹴る]
  -> [椅子が半回転]
  -> [きい]

[視界]
  -> [白い壁]
  -> [窓]
  -> [カーテン]
  -> [ベッド]
  -> [父の顔]

[反復]
  -> [また白い壁]
  -> [また窓]
  -> [またカーテン]
  -> [また父の顔]

[父]
  -> [何も言わない]
  -> [目だけで追う]
  -> [口元が少しゆるむ]

[樹]
  -> [それを見てまた蹴る]
```

## 「安心して回っている」をshowする方法

「安心していた」と書かずに見せるなら、以下が使えます。

```text
[父の前を通る]
  -> [父は止めない]
  -> [樹は次の一蹴りを強くする]
```

これが一番強いです。

父が怒らないから、樹の動きが増える。  
つまり、安心が行動に出る。

他にも、

```text
一周ごとに父の顔を確認する
父の顔が変わらないので回り続ける
父の前だけ少し速度が落ちる
父を見たあと、また床を蹴る
```

などが使えます。

## 避けたい見せ方

```text
樹は安心していた。
父は樹を受け入れていた。
樹は発達障害らしく回っていた。
病室は安全な場所だった。
```

これらは説明になりやすいです。

ここでは、

```text
父が止めない
樹がまた蹴る
父の顔が一周ごとに戻る
```

だけで十分です。

## 最終推奨

この直後は、こういう順序が一番きれいです。

```text
音の反復
→ カーテン下の靴先
→ 床を蹴る足
→ 回転する椅子
→ 樹の視界に父が戻る
→ 父は何も言わない
→ 樹がもう一度強く蹴る
```

これで、音から樹の存在へ気づかせつつ、父の安心感まで自然に入ります。
