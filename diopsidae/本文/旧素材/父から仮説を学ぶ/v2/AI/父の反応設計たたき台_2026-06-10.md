# S4 v2 転倒後の父の反応設計たたき台

対象:
`diopsidae/本文/ACT1/SEQ2_父との絆と喪失/S4_父から仮説を学ぶ/v2/本文.txt`

現在の接続元:

```text
床は、さっきと同じところに来なかった。
つま先が少し先へ出た。
椅子はまだ回っていた。
背中のランドセルが、一拍遅れて横に振れた。
樹の体が、椅子の外へ落ちた。
```

## 結論

父・孝則の反応は、**安全確認はするが、事故を大事件にしない**方向がよいです。

裕子との差はここで立ちます。

```text
[裕子]
  -> 大きい声
  -> すぐ止める
  -> 心配が樹への制御になる
  -> 樹の行動を問題化する

[孝則]
  -> 声を大きくしない
  -> まず怪我だけ見る
  -> 樹が自分で起きる余白を残す
  -> こぼれたものを責めない
```

父は「心配していない」のではなく、**心配を樹にぶつけない**人として描くのがよいです。

## 父の反応の役割

転倒後の父の反応には、三つの役割があります。

```text
1. 樹が安全であることを確認する
2. 樹を恥ずかしがらせない
3. こぼれたプリントへ自然に視線を移す
```

ここで「大丈夫か！」と強くやると、裕子と同じく、樹の行動を外から制御する大人になります。  
一方、完全に無反応だと冷たく見える。

なので、父は以下の順番がよいです。

```text
[小さい反応]
  -> [安全確認]
  -> [樹が起きるのを待つ]
  -> [床のものを見る]
  -> [プリントに気づく]
  -> [責めずに聞く]
```

## 反応設計の基本順

### 1. 父の身体が少しだけ動く

父は病気で自由に動けない。  
だから、駆け寄れない。

この制約が、逆に樹への安全な距離になります。

見せるもの:

```text
背中を起こしかける
手がシーツを押す
ベッド柵に指がかかる
でも床までは届かない
```

機能:

- 心配していないわけではない
- でも大騒ぎしない
- 父の身体制約も自然に出る

### 2. 声は短く、小さく

父の第一声は、長い説明ではなく短い安全確認がよいです。

方向:

```text
怪我の確認
痛みの確認
起きられるかの確認
```

避けたい方向:

```text
危ないやろ
何してるんや
ほら言わんこっちゃない
だからやめとけって
```

父は、転倒を叱責に変えない。

### 3. 樹が自分で起きるのを待つ

ここが大事です。

父がすぐ「助ける」方向に行きすぎると、心配性に見えます。  
父はまず、樹がどう動くかを見る。

見せるもの:

```text
樹が手をつく
膝を立てる
父は急かさない
父は声を重ねない
```

機能:

- 樹のペースを守る
- 転倒を失敗として騒がない
- 安心感が出る

### 4. こぼれたものを見る順番

父は、転倒後すぐにプリントへ食いつかない方がよいです。

順番:

```text
樹
  -> 膝/手/顔色
  -> ランドセル
  -> 教科書
  -> 赤フィルム
  -> 破れたプリント
```

この順番で見ると、父が「プリントという証拠」を追及する人ではなく、自然に状況を見ている人になります。

## 父の「心配性に見えない」条件

### 条件1: 声を重ねない

裕子は、おそらく同じ場面なら言葉を重ねます。

```text
大丈夫？
痛くない？
だから言ったやろ？
もうやめなさい。
```

父は一つだけ聞く。  
答えを待つ。  
それ以上詰めない。

### 条件2: 樹の行動を禁止しない

父は「もう回るな」と言わない。

ここで禁止すると、裕子と同じ構造になります。

父がするのは、

```text
怪我の確認
状況の観察
プリントへの穏やかな問い
```

だけ。

### 条件3: 転倒を感情化しない

父は「びっくりした」「心臓止まるかと思った」など、自分の感情を樹に渡さない。

樹にとって安心な大人は、自分の不安を子どもに背負わせない大人です。

### 条件4: 失敗を笑いすぎない

軽く笑うのはありですが、笑いすぎると転倒が茶化されます。  
父の笑いは、緊張を下げるための小さなものに留める。

## 父の反応パターン

### パターンA: 安全確認最小版

構造:

```text
樹が落ちる
-> 父が少し身を起こす
-> 短く確認
-> 樹が起きる
-> 父はそれ以上言わない
-> 床のものを見る
```

効果:
- 心配性に見えない
- 父の受容が出る
- プリントへの接続が自然

向いている場合:
- テンポよくプリントへ入りたい
- 父の穏やかさを出したい

### パターンB: 父の身体制約を活かす版

構造:

```text
樹が落ちる
-> 父の手がベッド柵にかかる
-> でも届かない
-> 声だけが届く
-> 樹が自分で起きる
```

効果:
- 父が動けないことが出る
- でも冷たくない
- 「声だけで安全を作る父」になる

向いている場合:
- 父の病状を自然に滲ませたい
- S5の喪失への下準備をしたい

### パターンC: 樹のペースを守る版

構造:

```text
樹が落ちる
-> 父は一度だけ聞く
-> 樹が散らばったものを見始める
-> 父は拾う順番を変えない
-> プリントに気づく
```

効果:
- 父が樹の秩序を尊重する
- 裕子との差が強い
- プリントが自然に出る

向いている場合:
- こぼれたものから母の話へ入りたい

### パターンD: 少しユーモアを入れる版

構造:

```text
樹が落ちる
-> 父が安全確認
-> 樹が平気そう
-> 父が小さく場をゆるめる
-> プリントを見る
```

効果:
- 父の柔らかさが出る
- 転倒が怖い場面になりすぎない

注意:
- 茶化しすぎない
- プリントの母の痛みを軽くしない

## 一番おすすめ

おすすめは、**B + C** です。

```text
[樹が落ちる]
  -> [父の手が少し動く]
  -> [でも床までは届かない]
  -> [声だけで短く安全確認]
  -> [樹が自分で起きる]
  -> [父はそれ以上騒がない]
  -> [床のものを見る]
  -> [破れたプリントへ気づく]
```

理由:

- 父の身体制約が自然に出る
- 心配性に見えない
- 冷たくも見えない
- 樹のペースが守られる
- プリントへの接続が自然

## プリントへの入り方

安全確認の後、父がプリントに言及するまでの流れは、以下がよいです。

```text
[樹が起きる]
  -> [ランドセルが開いている]
  -> [教科書が出ている]
  -> [赤フィルムが見える]
  -> [破れたプリントが見える]
  -> [父の視線が少し止まる]
  -> [でも指差さない]
  -> [樹が自分で拾う]
  -> [父が短く聞く]
```

父は、プリントを「事件の証拠」として扱わない。  
あくまで、床にこぼれたものの一つとして見つける。

## 父の第一声の方向

第一声は、次の条件を満たすとよいです。

```text
短い
声が大きくない
叱責ではない
樹の身体だけを確認する
答えを急かさない
```

機能としては、

```text
怪我の確認
```

だけでよいです。

そのあとプリントへ入るときも、

```text
何があったかを責める
```

ではなく、

```text
それがここにある理由を聞く
```

程度がよいです。

## 避けたい父の反応

### 1. 過剰に心配する

```text
大丈夫か、大丈夫か
痛くないか
頭打ってないか
看護師さん呼ぼうか
```

これは父が心配性に見えます。  
裕子との差も弱まります。

### 2. すぐ禁止する

```text
もう回ったらあかん
危ないからやめとき
```

これは母に近くなります。

### 3. すぐプリントを問い詰める

```text
それ何や
どうしたんや
お母さんに何かされたんか
```

これは尋問に見えます。  
まず安全確認、次に自然な観察です。

### 4. 父が完全に無反応

これだと受容ではなく無関心に見える可能性があります。

小さく反応する。  
でも騒がない。  
このバランスが必要です。

## 父の反応の芯

この場面で父が見せるべきなのは、

```text
樹が転んでも、世界は壊れない。
大人が大声を出さない。
失敗しても、次の言葉が罰にならない。
```

ということです。

だから、父の反応は派手に優しい必要はありません。

むしろ、

```text
少し動く
短く聞く
待つ
見つける
責めずに聞く
```

だけで十分です。

## 次の会話への橋

プリントへ入るときの理想の流れ:

```text
父: 怪我だけ確認
樹: 起きる / 拾う
父: 床のプリントを見る
父: その紙について軽く聞く
樹: 正解したのに破られた話を始める
父: 途中で止めない
```

これで、父の「受け止め」の土台ができます。

父が「辛かったなあ」と言う前に、すでに父は、

```text
転倒を責めない
散乱を責めない
説明を急がせない
```

という形で受け止めを実践していることになります。
