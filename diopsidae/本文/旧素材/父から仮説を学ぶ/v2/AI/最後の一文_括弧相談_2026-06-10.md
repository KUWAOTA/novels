# S4 v2 最後の一文の括弧相談

対象:
`diopsidae/本文/ACT1/SEQ2_父との絆と喪失/S4_父から仮説を学ぶ/v2/本文.txt`

該当箇所:

```text
樹は、早く回すことに夢中になっていた。
より強い風を感じることに夢中になっていた。（これ、同じ動詞を避けたうえで、もうちょっとshowよりにしたい）
```

## 結論

括弧の違和感は正しいです。  
ここは「夢中になっていた」を言い換えるより、**樹の動作が一段強くなる**方向に変えるとよいです。

現状は、

```text
夢中になっていた
夢中になっていた
```

で内面を説明しています。

ここで欲しいのは説明ではなく、

```text
足の動きが速くなる
蹴る間隔が詰まる
肩紐や前髪が揺れる
風が頬や耳に当たる
それでも止めない
```

です。

## 今の文の機能

### 1文目

```text
樹は、早く回すことに夢中になっていた。
```

機能:

- 樹が椅子の回転に集中していることを示す
- ここで内面に入る

これは残してもよいです。  
ただし、次の文も「夢中」だと説明が重なります。

### 2文目

```text
より強い風を感じることに夢中になっていた。
```

機能:

- 回転が速くなる理由を身体感覚へ寄せる
- 「気持ちよさ」を出そうとしている

ただ、これもまだ説明です。  
「風を感じることに夢中」と言うより、風を受けている身体を見せたい。

## 方向性

### 方向A: 1文目を残し、2文目をshowにする

この場合、1文目で内面を一度だけ許し、2文目で身体へ戻します。

狙い:

```text
[夢中]
  -> [足の動作]
  -> [風の身体感覚]
```

近い方向の例:

```text
樹は、早く回すことに夢中になっていた。
頬に当たる風が弱くなる前に、右足が次の床を探した。
```

これは「夢中」の重複を避けつつ、風をshowできます。

### 方向B: 両方ともshowに寄せる

「夢中」を消す方向です。

狙い:

```text
[足が動く]
  -> [音の間隔が詰まる]
  -> [風が強くなる]
```

近い方向の例:

```text
樹の右足は、椅子が止まりきる前にまた床を押した。
頬の横を通る風が、少しずつ強くなった。
```

これだと内面説明はほぼ消えます。  
樹の行動だけで「夢中」がわかります。

### 方向C: 音でshowする

直前から `きい / こつ` の音を使っているので、音の間隔で夢中を見せる方向です。

狙い:

```text
[きい]
  -> [こつ]
  -> [間隔が短くなる]
  -> [止まらない]
```

近い方向の例:

```text
きい、とこつの間が、少しずつ短くなった。
```

かなりシンプルです。  
「夢中」を言わずに、回転が加速していることがわかります。

### 方向D: ランドセルへの伏線を入れる

この後こけてランドセルが開くなら、ここでランドセルの動きを入れると強いです。

狙い:

```text
[回転が速くなる]
  -> [ランドセルが遅れて揺れる]
  -> [転倒の準備]
```

近い方向の例:

```text
背中のランドセルだけが、樹の体より少し遅れて揺れた。
```

これは次の転倒へかなり自然につながります。  
風の快さより、物理の危うさを出す方向です。

## おすすめ

一番おすすめは、**方向B + D** です。

理由:

- 「夢中」を説明せずに出せる
- 同じ動詞問題が消える
- 樹らしく、人間ではなく身体と物理に寄る
- 次の転倒へつながる

構造としてはこうです。

```text
樹の足が止まらない
→ 風が強くなる
→ ランドセルが遅れて揺れる
→ こける準備ができる
```

## 採用候補の方向

### 候補1: 風のshow重視

```text
椅子が止まりきる前に、樹の右足はまた床を押した。
頬の横を通る風が、さっきより強くなった。
```

向いている場合:
- 「気持ちよさ」を残したい
- 回転の快感を中心にしたい

### 候補2: 音のshow重視

```text
きい、とこつの間が、少しずつ短くなった。
```

向いている場合:
- 文を削りたい
- 音の導入を活かしたい
- 樹の反復行動をコンパクトに見せたい

### 候補3: 転倒への伏線重視

```text
背中のランドセルだけが、樹の体より少し遅れて揺れた。
```

向いている場合:
- すぐこのあとこけるなら強い
- プリントがこぼれる流れへ自然につなぎたい

### 候補4: 風と転倒の両方

```text
頬に当たる風が強くなるたび、背中のランドセルが少し遅れてついてきた。
```

向いている場合:
- 風の快さと危うさを同時に出したい
- 次の転倒まで滑らかにつなげたい

ただし少し整いすぎているので、自分の文体に崩してよいです。

## 最終判断

今の括弧は、以下のどれかに変えるのがよいです。

```text
樹の右足が止まらない
音の間隔が詰まる
風が強くなる
ランドセルが遅れて揺れる
```

「夢中」を言いたいなら一回だけで十分です。  
その直後は、内面ではなく動作に戻すと、show寄りになり、次の転倒にもつながります。
