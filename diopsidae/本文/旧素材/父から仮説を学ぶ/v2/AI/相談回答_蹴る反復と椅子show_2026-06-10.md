# S4 v2 相談①②への回答: 「蹴る」の反復と回しやすい椅子のshow

対象:
`diopsidae/本文/ACT1/SEQ2_父との絆と喪失/S4_父から仮説を学ぶ/v2/本文.txt`

該当箇所:

```text
孝則は樹に対して何も言わなかった。
「じっとしなさい」が口癖の裕子とは対照的に。
だから、樹は何度も何度も床を蹴った（相談①　同じ動詞を使うのを避けたい）。
（相談②なんかいい感じの表現にしたいけど、円が上にのっているだけの簡易な椅子は回しやすくて気持ちよかった　これをshowする）
```

## 結論

相談①は、「蹴る」を別語に置き換えるより、**動作を段階に分ける**と自然です。

```text
足を引く
つま先を床に置く
床を押す
椅子が回る
足が浮く
また床を探す
```

相談②は、「回しやすくて気持ちよかった」と書かず、**椅子が軽く反応すること**を見せるとよいです。

```text
少し押しただけで座面が動く
軸が細い
背もたれがない
体の向きだけがすぐ変わる
足が床に触れるたびに半回転する
```

## 相談①: 「蹴る」の反復を避ける方法

### 方針A: 動詞を変えるのではなく、動作を細分化する

「蹴る」を避けるために、

```text
押す
払う
すべらせる
突く
弾く
踏む
こする
```

を無理に並べると、逆に人工的になります。

樹らしくするなら、同じ行為を「足の位置」「床との接触」「椅子の反応」に分解する方が自然です。

機能:

```text
[足]
  -> [床]
  -> [椅子]
  -> [視界]
```

### 使える動作単位

```text
右足を引く
つま先を床に置く
床を押す
靴底がすべる
足が少し浮く
椅子の向きが変わる
もう一度、床を探す
```

これなら「蹴る」を一回だけ使っても、周囲の動作が変わるため単調になりません。

### 方向サンプル

```text
だから、樹は右足を引いて、つま先で床を押した。
椅子は軽く半分回った。
足が床から離れると、すぐまた次の床が来た。
```

この方向だと、「蹴る」を避けつつ、回転の反復が出ます。

### もう少し樹らしい方向

```text
だから、樹は右足を床に置いた。
少し押すだけで、椅子の向きが変わった。
戻ってきた床を、また右足で押した。
```

これは、樹が人間ではなく仕組みを見ている感じが出ます。

## 相談②: 簡易な丸椅子が回しやすくて気持ちいいことをshowする

### 見せるべき要素

「気持ちよかった」を直接言わず、以下を見せると伝わります。

```text
[椅子の構造]
  - 背もたれがない
  - 丸い座面だけ
  - 軸が細い
  - 足を押すとすぐ向きが変わる

[樹の反応]
  - すぐもう一度足を置く
  - 回転を止めずに続ける
  - 音の間隔が揃う
  - 見えるものの順番を覚える
```

### 椅子側のshow

```text
少し押すだけで、丸い座面が逃げる。
背もたれがないので、体ごとすぐ横を向く。
足元の金属だけが、床の上で小さく鳴る。
```

機能:
- 簡易な椅子の軽さが出る
- 回しやすさが物理でわかる
- 「気持ちいい」を説明しない

### 樹側のshow

```text
一度回ると、樹はすぐ次の床を探す。
足が触れたところを押す。
同じ音が返ってくる。
```

機能:
- 樹がその反応を気に入っていることがわかる
- 反復行動として自然
- ASD的な「同じ入力・同じ反応」の快さが出る

## 相談①②を同時に満たす構造

本文では、以下の順にするとよいです。

```text
[孝則は止めない]
  -> [樹が右足を引く]
  -> [つま先で床を押す]
  -> [丸い座面がすぐ向きを変える]
  -> [音が返る]
  -> [樹がまた床を探す]
  -> [同じ反応が返る]
```

これで、

- 「蹴る」の反復を避ける
- 椅子の回しやすさを見せる
- 樹がそれを気に入っていることを行動で示す

が同時にできます。

## 具体方向候補

### 候補A: 物理寄り

```text
だから、樹は右足を引いて、つま先で床を押した。
丸い座面は、押した分より少し多く回った。
足が離れると、次の床がすぐ横から来た。
```

強み:
- 樹の認知っぽい
- 回しやすさが出る
- 人間の感情に寄らない

### 候補B: 音の反復寄り

```text
だから、樹はつま先を床に置いた。
押すと、きい、と返った。
足を戻すと、こつ、と返った。
```

強み:
- 直前の音の導入とつながる
- 樹が音の反応を楽しんでいる感じが出る
- 「蹴る」を避けられる

### 候補C: 椅子の簡易さ寄り

```text
背もたれのない丸い座面は、体重を少し傾けるだけで向きを変えた。
樹が足を置くたび、椅子は待っていたみたいに回った。
```

強み:
- 椅子の形状がわかる
- 回しやすさが出る

注意:
- 「待っていたみたい」は少し擬人化なので、好みによって削る

### 候補D: 樹の反復行動寄り

```text
右足を置く。
押す。
半分回る。
また右足を置く。
```

強み:
- 樹らしい
- 説明が少ない
- 反復の快さが行動で出る

注意:
- 文体が硬くなりやすいので、周囲とのなじませが必要

## 一番おすすめ

この場面では、候補AとBの混合がよいです。

```text
だから、樹は右足を引いて、つま先で床を押した。
丸い座面は、押した分より少し多く回った。
足を戻すと、こつ、と返った。
```

理由:

- 孝則が止めない結果として自然につながる
- 「蹴る」を繰り返さない
- 椅子の軽さが出る
- 音の反復に戻れる
- 樹が人間ではなく、入力と反応を見ている感じになる

## 注意点

「円が上にのっているだけの簡易な椅子」を説明しすぎると、家具説明になります。

必要なのは構造説明ではなく、

```text
押すとすぐ回る
背もたれが邪魔しない
音が返る
足がまた床を探す
```

です。

つまり「どんな椅子か」より、**樹が触ったときにどう反応する椅子か**を書くとよいです。
