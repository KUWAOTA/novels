# S4 映像相談ポイント案

対象:
`diopsidae/本文/ACT1/SEQ2_父との絆と喪失/S4_父から仮説を学ぶ/v1/本文.txt`

目的:
本文の書きぶりに引っ張られないよう、相談ポイント1・2に関する **show用の客観描写素材** を複数案で整理する。

## 前提の映像ライン

```text
[病室カーテン]
  -> [揺れ]
  -> [回転椅子の音]
  -> [樹が足で床を蹴って回る]
  -> [父が見ている]
  -> [父は止めない]
  -> [樹が安心して回り続ける]
  -> [こける]
  -> [ランドセルが開く]
  -> [教科書の山]
  -> [くしゃくしゃのプリント]
  -> [父がプリントを見る]
  -> [父が樹を脅かさずに聞く]
```

ここで大事なのは、父が「すぐ助ける善人」ではなく、**樹のペースを壊さない人**として見えること。  
また、樹は「母の気持ちを無視している悪い子」ではなく、**物理・順序・正誤だけが見えていて、感情の面が視界に入っていない子**として見せる。

# 相談ポイント1

## 父がプリントに言及するとき、安心感を持たせる動き

### 案1: 先に樹の身体、次にプリントを見る

```text
[転倒]
  -> [父の視線: 樹の膝]
  -> [父の視線: 樹の手]
  -> [父の視線: 顔色]
  -> [樹が自分で起き上がれる]
  -> [父の視線: 床のプリント]
```

意味:
父はプリントより先に樹の無事を見る。  
ただし、母のように大きく心配して騒がない。  
「安全確認はするが、樹を事件化しない」動きになる。

使える細部:
- 父が体を起こしかけるが、樹が起き上がるのを見て止まる
- 声を張らず、視線だけ先に動く
- 樹が膝を払うまで待つ
- 樹が泣いていないのを見てから床を見る

### 案2: 父は届かない距離から、拾う順番を樹に任せる

```text
[床に散らばる]
  -> [父の手: ベッド柵の上]
  -> [床まで届かない]
  -> [樹が拾う]
  -> [父は拾い方を指示しない]
  -> [最後にプリントへ視線]
```

意味:
父は介入しすぎない。  
床のものを全部片づけてあげるのではなく、樹が自分の順番で拾う余白を残す。  
樹の世界の秩序を尊重している感じが出る。

使える細部:
- 父の指が少し動くが、すぐ戻る
- ベッドから床までの距離がある
- 樹が消しゴム、ケース、教科書、プリントの順に拾う
- 父はその順番を変えない

### 案3: プリントを指差さず、視線だけで気づく

```text
[父の視線]
  -> [教科書]
  -> [赤フィルム]
  -> [破れた紙]
  -> [緑マーカー]
  -> [樹]
```

意味:
指差しは少し詰問に見える。  
視線だけで「見つけた」と示すと、圧が弱い。  
父の観察力も出る。

使える細部:
- 父は紙を指ささない
- 目だけが一度止まる
- すぐ樹に戻る
- 樹が父の視線に気づいて、自分から破片を見る

### 案4: プリントを「証拠品」にしない

```text
[破れたプリント]
  -> [父は拾わせて見せろと言わない]
  -> [床にあるまま見る]
  -> [樹の手元の作業を待つ]
```

意味:
母なら「それ何」「見せなさい」になりそうなところを、父は証拠品として扱わない。  
床にあるものとして自然に扱うことで、樹が責められている感じを持たない。

使える細部:
- プリントはしばらく床に置かれたまま
- 父は紙を取り上げない
- 樹が自分で膝の上に集めるまで待つ
- 父は紙よりも樹の手つきを見る

### 案5: 父がまず椅子を止める

```text
[樹がこける]
  -> [椅子だけ回り続ける]
  -> [父の視線: 椅子]
  -> [樹が手で椅子を止める]
  -> [病室が静かになる]
  -> [父がプリントを見る]
```

意味:
転倒直後は椅子がまだ回っている。  
それが止まってからプリントの話に入ると、場面の温度が整う。  
父が急がない感じも出る。

使える細部:
- 回転音が残る
- 樹が自分で椅子の座面を押さえる
- 父はその間、何も言わない
- 音が消えてから、父の目が床へ移る

### 案6: 父が冗談の入口を作り、すぐやわらかく戻す

```text
[教科書とプリントの山]
  -> [父が少しだけ笑う]
  -> [樹が反応しない]
  -> [父の笑みが弱まる]
  -> [父が静かに聞く姿勢へ]
```

意味:
父が場を怖くしないために、最初だけ軽く受ける。  
しかし、樹がそれを笑いごとにできていないと見て、すぐ真面目に戻る。  
「相手の反応に合わせる父」が立つ。

使える細部:
- 父の口元だけ少し動く
- 樹が紙片を見たまま
- 父が笑うのをやめる
- 病室の空気が静かに落ちる

### 案7: 父は母の名前をすぐ出さない

```text
[破れたプリント]
  -> [父は紙を見る]
  -> [赤フィルムを見る]
  -> [緑線を見る]
  -> [樹を見る]
  -> [母という語をまだ出さない]
```

意味:
母の話に直行すると、樹にとってはまた裁判が始まる。  
父がまず「何が起きた物か」を見ると、安心感がある。

使える細部:
- 父は「お母さん」と言う前に、紙の状態を見る
- 赤フィルムと緑線で、家庭学習の痕跡を読む
- すぐ結論にしない

### 案8: 父の身体制約を安心感に転じる

```text
[父]
  -> [動けない]
  -> [近づけない]
  -> [取り上げられない]
  -> [声だけで関わる]
  -> [樹の領域が守られる]
```

意味:
父が動けないことは弱さだが、この場面では「樹のものを奪わない距離」になる。  
母はプリントを握り、破る。  
父は届かない。  
この対比が強い。

使える細部:
- ベッドから床への距離
- 父の手が柵を越えない
- 樹の膝の上にプリントが残る
- 父は視線と声だけで関わる

# 相談ポイント2

## 樹が母のことを本当にわかってなさそうに見える客観描写

### 案1: 母の感情ではなく、問題の正誤だけを再現する

```text
[樹の説明]
  -> [743年]
  -> [墾田永年私財法]
  -> [一回目も正解]
  -> [二回目も正解]
  -> [三回目も同じ答え]
  -> [なのに終わらない]
```

見えること:
樹にとって事件の中心は「正解したのに終わらなかったこと」。  
母がなぜ終われなかったのかは視界にない。

客観描写の方向:
- 指を折って回数を数える
- 同じ答えを何度も言ったことを強調する
- 母の表情ではなく、問題文を再現する
- 「五時に起きた」など母の努力には反応が薄い

### 案2: 母の顔ではなく、赤フィルムのずれを話す

```text
[母の怒り]
  -> [樹の記憶では]
       |
       +-- [赤フィルムがずれた]
       +-- [赤字が半分見えた]
       +-- [緑線が曲がった]
       +-- [答えが隠れなかった]
```

見えること:
母が傷ついた瞬間ではなく、教材の状態変化だけを見ている。  
感情の場面を、物の事故として記憶している。

客観描写の方向:
- 樹が赤フィルムの端を指で直す
- 破片に赤フィルムを重ね直す
- 父に話しながら、母の声色ではなく教材のズレを再現する

### 案3: プリントを「まだ使えたもの」として扱う

```text
[破られたプリント]
  -> [母が怒ったもの]
  -> [樹には]
       |
       +-- [まだ使えるもの]
       +-- [順番があれば戻せるもの]
       +-- [破ったら効率が悪いもの]
```

見えること:
樹は母の悲しみより、プリントの機能停止を問題視している。  
ここに「見えてへん感」が出る。

客観描写の方向:
- 破片をサイズ順に並べる
- 文字がつながるか確認する
- 赤フィルムを重ねて、答えが隠れるか試す
- 使える/使えないの判定をしている

### 案4: 母の台詞を意味ではなく音・語尾として記憶する

```text
[母の言葉]
  -> [内容]
       |
       +-- [五時に起きた]
       +-- [作った]
       +-- [いらんのか]
  -> [樹の受け取り]
       |
       +-- [声が大きくなった]
       +-- [語尾が伸びた]
       +-- [同じ言葉が戻ってきた]
```

見えること:
母が何を訴えていたかではなく、音量や反復として受け取っている。  
感情の意味内容が抜ける。

客観描写の方向:
- 樹が母の台詞を平板に再現する
- 怒りの意味を説明しない
- 声が大きかった、近かった、手が紙を握ったなど感覚情報に寄る

### 案5: 「お母さんはなぜ破ったか」ではなく「破ると何が困るか」を話す

```text
[父の問い]
  -> [それ、どうしたん]
  -> [樹の答え]
       |
       +-- [破られた]
       +-- [順番がわからない]
       +-- [赤フィルムが使えない]
       +-- [答え合わせできない]
```

見えること:
父が出来事を聞いているのに、樹は物の不具合報告をする。  
母の内面が抜け落ちている。

客観描写の方向:
- 樹が破片をつまみながら話す
- 母の顔を思い出す描写がない
- 父を見るより、紙片を見る
- 破片を合わせる作業が説明と同期する

### 案6: 自分の正当性を主張している自覚がない

```text
[樹]
  -> [怒っているように見えない]
  -> [泣いているように見えない]
  -> [ただ手順を報告する]
  -> [正しい順に並べようとする]
```

見えること:
樹は「母はおかしい」と訴えているのではなく、「発生した矛盾」を報告している。  
その無自覚さが、わかってなさを強める。

客観描写の方向:
- 感情的な語彙を避ける
- 淡々と数・順序・物の状態を出す
- なのに内容は母を傷つける方向に読める

### 案7: 母の努力を、作業量としてだけ理解する

```text
[母: 五時に起きて作った]
  -> [樹の理解]
       |
       +-- [早い時間]
       +-- [手書き]
       +-- [緑マーカー]
       +-- [赤フィルム]
       +-- [教科書を写した]
```

見えること:
母の努力を「愛情」や「不安」ではなく、作業工程として理解している。  
だから「教科書写しただけ」に見える。

客観描写の方向:
- 緑線の引き方を観察する
- 手書きの字の揺れを見る
- 作業工程を分解する
- 作った人の気持ちには触れない

### 案8: 「私」の破片へのこだわり

```text
[ごみ箱の縁]
  -> [「私」だけ残る]
  -> [樹が拾う]
  -> [病室の床]
  -> [樹が最後に置く]
```

見えること:
母との衝突全体より、欠けた一文字のほうに注意が向いている。  
象徴的にも、樹の「私」だけが残っていて、母の「私」は見えていない。

客観描写の方向:
- 破片を並べるとき「私」だけ別に持つ
- その破片を最後に置く
- 父の視線もそこに止まる
- 樹はその重要性を説明せず、ただなくなると困るものとして扱う

# 組み合わせ推奨

## 最も自然な組み合わせ

```text
[こける]
  -> [父は先に樹の身体を見る]
  -> [椅子の回転音が止まる]
  -> [父は床のプリントを指差さず視線で見る]
  -> [樹が自分の順番で拾う]
  -> [樹がプリントを機能停止した教材として説明する]
  -> [父は途中で止めない]
  -> [父が「辛かった」に到達する]
```

効果:
- 父の安心感が出る
- 母との差が出る
- 樹の狭い視界が出る
- 父の「受け止め」が自然に入る

## 父の安心感を強めたい場合

```text
[父は動けない]
  -> [取り上げられない]
  -> [指差さない]
  -> [拾う順番を変えない]
  -> [樹が話し終わるまで待つ]
```

効果:
父の身体制約が、樹にとっての安全な距離に変わる。

## 樹のわかってなさを強めたい場合

```text
[母の怒り]
  -> [樹の説明では]
       |
       +-- [問題回数]
       +-- [正答]
       +-- [赤フィルム]
       +-- [破片の順番]
       +-- [再利用不能]
       +-- [「私」]
```

効果:
母の感情が一切説明されないことで、読者には逆に「この子には見えていない」とわかる。

# この場面の映像上の芯

```text
[母]
  -> [樹の動きを止める]
  -> [プリントを握る]
  -> [破る]

[父]
  -> [樹の動きを止めない]
  -> [プリントを取り上げない]
  -> [破片の前で待つ]
```

S4冒頭は、この対比が見えればかなり強いです。

父は、樹を正しい形に戻す人ではない。  
樹が回って、転んで、こぼしたものを、こぼれた場所から一緒に見る人。
