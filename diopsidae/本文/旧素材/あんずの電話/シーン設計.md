# S4: あんずの電話

## 脚本（マスター）

```yaml
id: ACT2-SEQ2-S4
value_change:
  axis: なし（意図的）
  from: デートの当日夜（デートの余韻）
  to: 変化なし — 樹は何も知らないまま勉強に戻る
  cause: あんずからの電話。読者だけが不穏さを感じる
time: デートの当日夜
space: 樹の自室
表視点: 僕（樹）
→ 直後に FB2（あんずの最後の夜）が入る
```

### 何が起きるか

- デートの当日夜、あんずから電話がかかってくる
- あんず「がんばれって言ってほしいだけやねん」
- 樹「がんばれ」（文字通りに受け取る）
- あんず「うちと、仲良うしてくれたん、樹くんだけやったんよ」
- あんず「今までありがとう、じゃあね！」→ 電話が切れる
- 樹は「ありがとう」「じゃあね」を文字通りに受け取る
- 樹、そのまま勉強に戻る

### 演出

- シーン全体を通して樹は何も変わらない（意図的なvalue_change不在）
- 読者だけが不穏さを感じる構造
- 「勉強に戻る」で終わる恐ろしさ
- 読者と樹の温度差がACT2クライマックスの核心

### 【穴】

- 「勇気」「覚悟」の直球さ → 樹が止めない不自然さの回避策
- あんずの声色の設計（読者に微かな違和感を与えつつ、樹には気づかせない匙加減）
