# S3: 母とのトラブル

## 脚本（マスター）

```yaml
id: ACT1-SEQ2-S3
value_change:
  axis: 家庭内の混乱⇔父への接続
  from: 母の怒りと涙の理由がわからず、家の中で孤立している
  to: くしゃくしゃのプリントを父の病室へ持っていく動機が生まれる
  cause: 母の手作りプリントをめぐる衝突
time: 小6
space: 自宅リビング
表視点: 僕（樹）
```

### 何が起きるか

- 母・裕子が社会の手書き穴埋めプリントを作る
- 樹は勉強に集中できず、消しゴムを投げる／欄外に書く／問題の非効率さを指摘する
- 母が「朝から一生懸命つくったのに」と泣く
- 樹には、母がなぜ泣くのかわからない
- くしゃくしゃになったプリントを、樹が捨てずに鞄へ入れる

### 伏線

- 母のプリント: ACT1-S4で父が母の行動原理を翻訳する材料になる
- 母の涙: 秀斗母の「お母さんのためにがんばって」と鏡像になる
- 樹の混乱: 「なぜ人が怒るのか／泣くのか」を論理で知りたい動機になる
