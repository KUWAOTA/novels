# 「アルコールの芳香臭すら落ち着く」をshowする案

対象:
`diopsidae/本文/ACT1/SEQ2_父との絆と喪失/S4_父から仮説を学ぶ/v2/本文.txt`

## 結論

「部屋に染み付いたアルコールの芳香臭すら、落ち着きを感じさせた」は、匂いを説明するより、**樹の身体がその匂いで面会の場所に来たと認識する**動きにするとshowになります。

つまり、匂いそのものを描くのではなく、

```text
[匂いがする]
  -> [樹の身体がゆるむ]
  -> [ここは父の病室だとわかる]
  -> [回転椅子に安心して向かう]
```

という流れで見せるのがよいです。

## アクション案

### 案1: 息を吸う

```text
[病室に入る]
  -> [樹が一度、鼻から息を吸う]
  -> [肩が少し下がる]
  -> [ランドセルの肩紐を握る手がゆるむ]
```

効果:
匂いで安心していることが身体に出る。  
「落ち着いた」と書かずに、緊張が抜けたことを見せられる。

### 案2: 廊下から病室へ入った瞬間の変化

```text
[廊下]
  -> [足音が速い]
  -> [病室]
  -> [アルコールの匂い]
  -> [足音が遅くなる]
  -> [椅子へ向かう]
```

効果:
場所が変わったことで樹のテンポが変わる。  
病室の匂いが「父に会える場所」の合図になる。

### 案3: 鼻をしかめない

```text
[アルコール臭]
  -> [普通なら嫌な匂い]
  -> [樹は顔をしかめない]
  -> [むしろ少し長く吸う]
  -> [椅子の背に手を置く]
```

効果:
「嫌な匂いなのに嫌ではない」が出る。  
ただし、露骨に「深呼吸」させると説明的なので、軽くでよい。

### 案4: 匂いと父の存在を結びつける

```text
[アルコール臭]
  -> [白いシーツ]
  -> [父のベッド]
  -> [父の顔]
  -> [樹が椅子に座る]
```

効果:
匂い単体ではなく、父の病室全体の記憶として安心が出る。  
「この匂い = 父のいる場所」という条件づけになる。

### 案5: ランドセルを下ろす

```text
[病室に入る]
  -> [匂い]
  -> [樹がランドセルを背負い直さない]
  -> [片方の肩から自然に落とす]
  -> [椅子に向かう]
```

効果:
防御がゆるむ。  
母との場面ではランドセルの奥にプリントを隠していたが、父の部屋では少し開く方向に動く。

### 案6: 匂いの中で音が聞こえる

```text
[アルコール臭]
  -> [白い壁]
  -> [静けさ]
  -> [樹の呼吸]
  -> [きい、という椅子の音]
```

効果:
相談2の音への接続にも使える。  
匂いで場が静まってから、椅子の音だけが立つ。

## 使いやすい組み合わせ

一番自然なのは、案1 + 案6です。

```text
[レース越しの日差し]
  -> [白い壁]
  -> [アルコールの匂い]
  -> [樹が息を吸う]
  -> [肩紐を握る手がゆるむ]
  -> [静けさ]
  -> [きい、という音]
```

これなら「落ち着きを感じさせた」と書かずに、落ち着いたことが見えます。

## 避けたい見せ方

```text
樹が安心した
落ち着いた
懐かしかった
父の匂いがした
病院の匂いが好きだった
```

これらは説明になりやすいです。

特に「病院の匂いが好き」は少し特殊性が強く出すぎるので、樹のキャラを狙いすぎた感じになります。  
それより、身体の力が抜けるくらいに留める方が自然です。

## 最終推奨アクション

```text
アルコールの匂いがする。
樹が一度だけ鼻から息を吸う。
ランドセルの肩紐を握っていた指がゆるむ。
そのあと、椅子の音が聞こえる。
```

この流れが、匂いの安心感と音への接続を同時に処理できます。
