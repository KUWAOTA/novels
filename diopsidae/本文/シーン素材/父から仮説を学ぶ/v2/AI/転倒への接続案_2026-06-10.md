# S4 v2 最後の行から樹をこかす接続案

対象:
`diopsidae/本文/ACT1/SEQ2_父との絆と喪失/S4_父から仮説を学ぶ/v2/本文.txt`

現在の最後の行:

```text
頬に当たる風が弱くなる前に、右足が次の床を探した。
```

## 結論

この行はかなり良いです。  
ここから転倒させるなら、**「次の床を探した」→「床の位置が予想とずれる」→「足が空振る」→「ランドセルの重さで崩れる」** が最も自然です。

ポイントは、転倒を「樹が不注意でこけた」にしないこと。  
樹は回転の周期を続けようとしている。  
でも、回転速度が上がり、椅子と体とランドセルのタイミングがずれる。  
その結果、足が想定した床に届かない。

つまり転倒は、

```text
楽しい
  -> もっと回す
  -> 足が次の床を探す
  -> 床の位置がずれる
  -> ランドセルが遅れる
  -> こける
```

でつなぐとよいです。

## 今の行の強み

```text
頬に当たる風が弱くなる前に、右足が次の床を探した。
```

この行には、すでに次の転倒の種があります。

```text
[風が弱くなる前に]
  -> 急いでいる

[右足が]
  -> 身体の一部に焦点

[次の床を探した]
  -> 床がいつもあるとは限らない
  -> 探す対象になっている
```

なので、次に必要なのは、「探した床が、予想した位置になかった」ことです。

## 接続の基本構造

### 1. 足が床を探す

現在の行で完了しています。

### 2. 床が遅れる/ずれる

ここで、回転が速すぎて位置感覚がずれる。

見せるもの:

```text
靴底
床
椅子の回転
体の向き
```

### 3. ランドセルが遅れる

転倒に説得力を出すなら、ランドセルを使うのが強いです。

見せるもの:

```text
肩紐
背中の重さ
ランドセルが横へ振れる
体だけ先に回る
```

### 4. 手が出る/椅子が回る

こける瞬間に、椅子だけがまだ回っていると映像が残ります。

見せるもの:

```text
手が椅子の縁をつかもうとする
椅子は逃げる
座面が少し回る
床に尻もち
```

## 方向性案

### 案A: 床の空振りでこける

構造:

```text
右足が次の床を探す
-> つま先が床に届かない
-> 体が傾く
-> 尻もち
```

向いている場合:
- 樹の身体感覚を中心にしたい
- 短く転倒させたい
- 比喩を避けたい

必要な描写:

```text
つま先
床までの距離
体の傾き
椅子の残る回転
```

### 案B: ランドセルの遅れでこける

構造:

```text
右足が次の床を探す
-> 体は回る
-> ランドセルが一拍遅れて振れる
-> 肩を引っ張られる
-> 尻もち
```

向いている場合:
- その後ランドセルからプリントをこぼしたい
- 転倒とプリント流出を一続きにしたい
- 物理の説得力を上げたい

必要な描写:

```text
肩紐
ランドセルの重さ
横に振れる
金具
ふた
```

### 案C: 椅子が軽すぎて逃げる

構造:

```text
右足が次の床を探す
-> 手か腰で椅子を支えようとする
-> 椅子が軽く回る
-> 支えにならない
-> こける
```

向いている場合:
- 「よく回る椅子」の性質を転倒にも使いたい
- 椅子の軽さを強調したい

必要な描写:

```text
丸い座面
手を置く
座面が逃げる
軸だけが回る
```

### 案D: 音の間隔が崩れてこける

構造:

```text
きい/こつの間隔がそろう
-> 速くなる
-> こつが遅れる
-> 足が床を外す
-> 転倒
```

向いている場合:
- 冒頭からの音の反復を活かしたい
- 読者に音で異変を感じさせたい

必要な描写:

```text
きい
こつ
間隔
一拍抜ける
床
```

## 一番おすすめ

おすすめは、**案A + 案B** です。

```text
右足が次の床を探す
-> 床が予想より遠い
-> ランドセルが背中で遅れて揺れる
-> 肩が引かれる
-> 尻もち
```

理由:

- 今の最後の行と直結する
- 樹の認知が「床を探す」にあるので自然
- ランドセルが開いてプリントがこぼれる流れへ直結する
- 人間への情緒ではなく、身体と物理で進む

## 避けたい方向

### 1. 「目が回ったからこけた」

わかりやすいですが、少し普通です。  
今の流れだと、目が回るより「次の床の探索失敗」の方が樹らしいです。

### 2. 「楽しくなりすぎてこけた」

内面説明になります。  
行動で十分見えています。

### 3. 「父を見ていてこけた」

これは避けた方がよいです。  
樹が人間に興味を持ちすぎる感じになり、前の違和感に戻ります。

## 使いやすい接続パターン

```text
右足が次の床を探した。
けれど、つま先は床より少し先に出た。
```

機能:
- 空振りが出る
- すぐ転倒へ行ける

### パターン2: 物理強め

```text
右足が次の床を探した。

背中のランドセルだけが、一拍遅れて横に振れた。
```

機能:
- なぜこけるかがわかる
- ランドセル散乱へ接続できる

### パターン3: 音を活かす

```text
右足が次の床を探した。
こつ、が一拍遅れた。
```

機能:
- 冒頭の音が崩れる
- 異変がスマートに出る

### パターン4: 樹の認知寄り

```text
右足が次の床を探した。
床は、さっきと同じところに来なかった。
```

機能:
- 樹の認知に近い
- 比喩が少ない
- 「同じ反応を期待したのに違った」が出る


```text
樹が床に落ちる

```

へ行けば自然です。

## 最終方針

「次の床を探した」は強いフックです。  
次は、床が期待通りに来ないことを書けばよいです。

転倒は、

```text
足の空振り
椅子の残る回転
ランドセルの遅れ
```

の三つで作ると、樹らしく、かつ次のプリント流出にもつながります。
