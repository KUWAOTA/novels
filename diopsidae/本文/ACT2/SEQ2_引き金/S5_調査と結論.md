# S5: 調査と結論

## 脚本（マスター）

```yaml
id: ACT2-SEQ2-S5
value_change:
  axis: 理解⇔誤解
  from: 「がんばれ」が何を後押ししたのかわからない混乱
  to: 「周りが彼女の特性を理解してやれなかったから死んだ」→ 精密な言語への執着が確立
  cause: 聞き取り調査とあんず母との対面で「理解されなかった」と結論
time: 中3卒業前の春
space: 富雄南中学校 / あんずの家
表視点: 僕（樹）
```

### 何が起きるか

- 樹「何がダメだったんだ…僕は何を後押ししてしまったんだ」
- 「仲良うしてくれたん、樹くんだけやったんよ」が反芻される
- 繰り返してはならない → 原因調査を決意
- クラスメイトに聞き取り調査 → 空気が読めないと煙たがられる
- 女子生徒の盗み聞き「全然空気読めへん子やから、死んでせいせいしたわ」
  - ★ あんずと樹の二重の排斥：同じ特性を持つ二人、片方は死に、片方は生き残って「なぜ」を追う
- あんずの家に押しかける
  - あんず母は**普通の悲しむ母を演じている** → 樹は違和感を持つが言語化できない
- 樹、自力で結論に至る：「周りが彼女の特性を理解してやれなかったからだ」
  - → 「もっと精密な言葉があれば、理解を伝えられた」→ 言語への執着が確立

### 演出

- 樹の「聞き取り調査」はASD的な直球さで周囲を不快にさせる
- あんず母のファサードと樹の違和感（読者はFB2で真実を知る）
- 誤信念の確立は樹の分析的内語で描写（分析ログ形式）

### 【穴】

- 聞き取り調査の具体的なやりとり
- あんず母との会話の詳細（ファサードの描写）
- 因果鎖の補完：嘔吐→反芻→「わからない」が耐えられない→「知れば防げる」→調査（のちに埋める予定）
