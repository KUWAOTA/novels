# S4b: 取調室（ACT2クライマックス）

## 脚本（マスター）

```yaml
id: ACT2-SEQ2-S4b
value_change:
  axis: 理解⇔誤解
  from: 何も知らない日常
  to: 「がんばれ」が何を後押ししたのかわからない衝撃
  cause: 刑事の反応で「がんばれ」の意味が反転
time: あんずの死の数日後
space: 警察署・取調室 → トイレ
表視点: 僕（樹）
note: FB2の後に配置。読者はあんずの真実を知った状態でこのシーンを読む
```

### 何が起きるか

- あんずの最後の通話相手として警察から呼び出し
- 樹、淡々と事実を述べる
- 刑事「最後の会話の内容を教えてくれるかな」
- 樹「がんばれと言いました」
- 刑事の表情が変わる → 樹はなぜ変わったかわからない
- 胃の奥が重くなる（身体が先に反応）
- トイレに駆け込み嘔吐
- 感情に名前がない。論理が追いつかない。身体だけが何かを知っている

### 演出

- ★ ドラマティック・アイロニー：読者はFB2であんずが「がんばれ＝死ぬ勇気」として受け取ったことを知っている。樹が「がんばれと言いました」と無邪気に報告する瞬間、読者は刑事と同じ顔をする
- 感情の遅延：事実→分析→身体反応（嘔吐）。感情は言語化されない
- 鏡に映る自分の顔 — 泣いていない。表情がない

### 【穴】

- 取調室の具体的なやりとり（刑事の質問の流れ）
- 保護者同伴の描写（中学生の事情聴取）
- 嘔吐後の帰宅シーンの有無
- 「がんばれ」の反転認識 — この時点では完全には理解していない。完全な認識はS5で
