# 「ムキになりながら」描写案

対象: `diopsidae/本文/EPILOGUE/v4~/SEQ1_ケニアにてシュモクバエを捜索する/v5/本文_描写増量版.txt`

該当箇所:

```text
「嘘は一番のアンチパターンだからね。つきたくないし、嘘にはしたくない」
ムキになりながら(これを描写的な言い方に変えて)樹が答える。息を切らしながら。
```

## 方針

ここでの「ムキ」は、怒鳴る感じよりも、疲労で身体は限界なのに「嘘にしたくない」という理屈だけで踏ん張っている感じが合いそうです。

樹は感情的に反論しているというより、「自分の行動の整合性」を守ろうとしている。その必死さが、息切れ・足元・タモ・ザック・声の硬さに出るとよいです。

## 差し替え案

### 案1: 声だけ硬くなる

```text
樹は息を切らしながら答えた。声だけが、妙に硬かった。
```

一番シンプルです。「ムキ」を直接言わず、声の質で出せます。

### 案2: 疲れているのに即答する

```text
樹は膝に手をつきかけた姿勢のまま、そこだけは即答した。
```

「そこだけは」が効きます。疲労よりも信条が勝っている感じ。

### 案3: 論理にしがみつく

```text
息は乱れていたが、言葉だけは足場を探すみたいにまっすぐだった。
```

少し文学寄り。ジャングルの足場と、論理の足場が重なります。

### 案4: 反論というより訂正

```text
樹は乱れた息の隙間に、訂正だけを差し込むみたいに言った。
```

樹らしいです。怒りではなく、間違いを見逃せない感じが出ます。

### 案5: 身体は負けているが言葉は負けない

```text
肩で息をしながら、それでも樹はその部分だけ譲らなかった。
```

かなり使いやすいです。「ムキ」の機能が素直に出ます。

### 案6: タモを握る手に出す

```text
樹はタモの柄を握り直した。息は切れていたが、その理屈だけは手放す気がなさそうだった。
```

物に出せるので描写寄りです。タモが後半まで効くなら相性が良いです。

### 案7: 目だけ前に行く

```text
足は藪に取られていたのに、樹の目だけは先へ行こうとしていた。
```

「ムキ」を行動意志として見せる案。直前の藪草描写とつながります。

### 案8: 秀斗への反発を少し入れる

```text
樹は秀斗のぼやきを拾い損ねないように、息の上がった声を少しだけ強くした。
```

会話の応酬感が出ます。やや説明寄りですが自然。

### 案9: 疲労と正しさのアンバランス

```text
声はへばっていたが、そこに含まれた正しさだけはやけに元気だった。
```

少しユーモラス。秀斗との軽口の温度に合います。

### 案10: 自分に言い聞かせる

```text
樹は秀斗に返したというより、自分の疲労に言い聞かせるみたいに言った。
```

この旅を本当にやる意味を、樹自身が再確認している感じが出ます。

### 案11: アンチパターンの言葉を支えにする

```text
アンチパターン、という言葉に体重を預けるみたいに、樹は息の荒い声で続けた。
```

樹のエンジニアっぽい言葉遣いを活かす案です。やや癖が強いですが面白い。

### 案12: 呼吸の隙間で論理が走る

```text
呼吸は追いついていなかったが、論理だけが先に走っていた。
```

短くて使いやすいです。樹の頭と身体のズレが出ます。
