# エピローグ — カカメガの森

**形式:** シーン描写。行動と感覚のみ。内的独白は最小限。
**時間:** ACT5の数ヶ月後
**場所:** ケニア・カカメガの森
**視点:** 僕（樹）
**役割:** 物語の余韻。タイトル回収。未来に向かって開いて終わる。

## 価値変化

```yaml
value_change:
  axis: 理解⇔受容
  from: ACT5で選択した「理解できなくても寄り添う」
  to: 「理解できなくても笑い合える」（受容の完成形）
  cause: シュモクバエを実際に見つけたことで、ACT5の航空券の約束が果たされる
```

## 構造上の機能

- **タイトル回収**: 「シュモクバエのこと、笑ってやろうぜ」がここで体現される
- **中核イメージの結晶**: 図鑑の知識だったシュモクバエが、目の前の実物になる
- **不可逆な変化の確認**: Googleをクビになった（社会的代価）→ それでも笑っている
- **プロローグとの対句**: 一人の独白 → 二人で笑う。内面 → 外の世界

## 内容のイメージ

- カカメガの森。湿度が高い。虫の音がうるさい
- ガイドの研究員が「この辺にいる」と指差す
- 秀斗が葉の裏を覗き込む
- 1センチもないシュモクバエを見つける
- 「こんなんのためにGoogleクビになったぞ」「あほやな」
- 笑い声が森に響く
- シュモクバエは気にせず、目を離したまま飛んでいる

## 注意点

- **内的独白を入れない**（それはプロローグの仕事）
- **テーマを説明しない**。笑い声と虫と森の空気だけで伝える
- **短く書く**。400字以内。余白が余韻になる

## エピローグ
「ほんまに取りに行くとか聞いてへんで」
草木をかき分けながら、泥まみれになった秀斗がぼやく。
「見つけないと帰れないからね」
飛行機16時間、現地の謎バスで10時間、さらにはジャングルの中を3時間。
意地になっていることぐらい自覚している。
存外、ここが涼しい事だけが救いだった。
「Shhhh!」
突然ガイドが黙るように僕らに促す。
目を凝らした後、ゆっくりと葉の裏を指差す。
そろりそろりと近寄ってみると、そこには1センチにも満たない小さなシュモクバエがいた。
「こんなんのためにケニアまで来たんかよ」
乾いた声で笑った秀斗につられて笑ってしまう。
「全然目と目の距離離れてないじゃんか」
シュモクバエは驚いたわけでもなく、自分の用事を思い出したかのように秀斗のそばをすり抜けて飛んで行った。
あっけなく。
現実のシュモクバエは、僕らニンゲンに興味すらなかったみたいだ。
