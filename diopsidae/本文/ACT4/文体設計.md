# ACT4 文体設計（28歳・Google Japan）

## 語り手
樹（28歳・社会人）

## 文体方針

### 樹視点
- **語彙レベル:** 最も高い。ビジネス用語・技術用語が自然に混在。「フィードバック」「最適化」「リソース」を人間関係にも適用
- **文の長さ:** 長く整然。報告書のような精度。しかし読者には「人間味のなさ」として感じられる
- **感覚描写:** ほぼ消滅。オフィスの空間すら抽象的に処理される
- **感情表現:** 「善意」を客観的事実として記述する。「彼のために最善を尽くしている」→ 暴力性への無自覚が文体に滲む
- **対人描写:** 秀斗を「成長すべき対象」として描写。秀斗の苦痛は樹の文体では見えない → FB3で補完
- **特徴的ルール:** 樹が「正しいこと」を語るほど、読者には暴力的に感じられる文体の逆転効果

### 秀斗（間接描写 → FB3で直接描写）
- 樹の目を通して：「改善すべき点がある同僚」「期待に応えられていない」
- FB3（秀斗視点）：FB_フラッシュバック/文体設計.md参照

### SEQ別の変化
| シーン | 文体の状態 |
|--------|-----------|
| SEQ1-S1（Google入社と昇進） | 文体が最も「完成」した状態。読者が最も信頼し、同時に最も不安になる瞬間 |
| SEQ1-S2（正しいのに人が壊れた） | 「正しいことを言っているのに、なぜ」という困惑が、文の構造自体を微かに不安定にする。接続詞が増え、文が長くなりすぎる |
| FB3（秀斗の全貌） | 視点交代 → FB文体設計参照 |
| SEQ2-S3（鏡像認識）★ | 文体の崩壊が始まる。精密だった文が途中で止まる。初めて「わからない」が逃げではなく本心として出現。電車の窓に映る自分の顔と秀斗が重なる瞬間、文の主語が混乱する |

### 導入理由
- ACT3で確立された精密文体を、読者が「暴力」として体験する構造（タカヤさん指摘：「物語上は善意でも、文体上は暴力」の実装）
- 鏡像認識で文体が壊れ始めることが、ACT5への橋渡し
- 秀斗への描写の「見えなさ」自体が、樹の盲点を文体で表現している
