# カーテン描写3文の映像順序

対象:
`diopsidae/本文/ACT1/SEQ2_父との絆と喪失/S4_父から仮説を学ぶ/v2/本文.txt`

検討文:

```text
①天井から吊られたレースの白が、外から入る風で、ふくらんで、戻って、また少しふくらむ。
②そのわずかな隙間から、空の青が現れては消える。
③レースを通った日差しが、白すぎる壁を少しだけやわらげていた。
```

## 結論

おすすめは **① → ② → ③** のままでよいです。

理由は、視線の流れが自然だからです。

```text
[カーテン全体の動き]
  -> [布の隙間に視線が寄る]
  -> [その光が壁へ届く]
```

つまり、まずカーテンを見る。  
次に、カーテンの隙間から外を見る。  
最後に、その外光が室内の壁にどう作用しているかを見る。

この順番が一番カメラの動きとして素直です。

## ただし、③の位置は少し調整できる

現状の③は「日差しが壁をやわらげる」なので、②の「空の青」とやや競合します。

②は窓の外。  
③は室内の壁。  
この切り替えが少しだけ急に感じる場合があります。

その場合は、③に「室内へ戻る」感じを足すとよいです。

```text
その光が、白すぎる壁を少しだけやわらげていた。
```

こうすると、

```text
①レースが動く
②隙間から青が見える
③その光が壁へ届く
```

になり、②と③がつながります。

## 別順序案

### 案A: ① → ③ → ②

```text
①レースがふくらむ
③日差しが壁をやわらげる
②隙間から空の青が見える
```

効果:
室内の安らぎを先に固めてから、最後に青を差し色として出せる。

弱点:
③で光を見たあとに②で空へ戻るため、視線が少し往復する。

使うなら、青を強い印象として最後に残したい場合。

### 案B: ③ → ① → ②

```text
③壁がやわらいでいる
①原因としてレースが揺れている
②隙間から青が見える
```

効果:
最初に病室の空気感が出る。

弱点:
原因と結果の順が逆なので、少し説明的に見える。  
冒頭の映像としては、①から入るほうが強い。

### 案C: ① → ②のみ、③を削る

```text
①レースがふくらむ
②隙間から青が見える
```

効果:
かなり静かで簡潔。  
そのあとすぐ音へ行ける。

弱点:
病室の「白すぎる壁がやわらぐ」感じは薄くなる。

## 最終推奨形

順序は **① → ② → ③**。

ただし、③の主語を「レースを通った日差し」ではなく、②を受ける「その光」にすると、かなり滑らかになります。

```text
天井から吊られたレースの白が、外から入る風で、ふくらんで、戻って、また少しふくらむ。
そのわずかな隙間から、空の青が現れては消える。
その光が、白すぎる壁を少しだけやわらげていた。
```

さらに落ち着かせるなら、「空の青」より「窓の青」のほうが病室内の視点に留まります。

```text
天井から吊られたレースの白が、外から入る風で、ふくらんで、戻って、また少しふくらむ。
そのわずかな隙間から、窓の青が現れては消える。
その光が、白すぎる壁を少しだけやわらげていた。
```
