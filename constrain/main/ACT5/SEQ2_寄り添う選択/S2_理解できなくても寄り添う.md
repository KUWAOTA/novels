# S2: 「理解できなくても寄り添う」選択（Story Climax）

## 脚本（マスター）

```yaml
id: ACT5-SEQ2-S2
value_change:
  axis: 理解⇔受容
  from: 「理解できなければ救えない」
  to: 「理解できなくても寄り添える」
  cause: あんずのフラッシュバック → 父の①を初めて使う
time: 28歳（自殺未遂の後）
space: 病院・病室

```

### 何が起きるか

- 何を言えばいいかわからない（初めて「正解の言葉がない」状況）
- スマホでナイロビ行きを検索。震える手で
- 「シュモクバエ、見に行かん？」「俺もわからん」
  → 初めて「わからない」と言う＝樹の変容の核心
  → ケニア行き航空券を買う＝論理では説明できない行動
- 秀斗「お前……頭おかしいんか」→ 力が抜ける
- 沈黙
- あんずのフラッシュバック：沈黙の共有、「…優しいね」、デートの夕方
  → あんずが教えてくれたことに気づく
- 父の①を初めて使う：「辛かったやろ」（関西弁＝論理の鎧が外れる）
- いじめられた時に泣くことはないのに、元いじめっ子を止めれたときにほっとして涙が出る
- 正しい事だけを言ってくる冷淡な樹が泣いている → 秀斗が驚く
- 秀斗が樹をハグする。樹わけがわからなくなる
- 「仕返しだと思ってた」→樹「え？何で？」

### テーマ

- ★ あんずはACT2で既にACT5の答えを体現していた（「ただそこにいる」ことが十分だった）
- 統制概念の証明：理解できなくても寄り添える

- ✅ 具体的台詞 → 「シュモクバエ、見に行かん？」＋「辛かったやろ」
