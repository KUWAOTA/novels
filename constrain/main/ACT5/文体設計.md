# ACT5 文体設計（28歳・数時間〜数日）

## 語り手
樹（28歳・崩壊と再生の只中）

## 文体方針

### 樹視点
- **語彙レベル:** 急速に簡素化。学術語・ビジネス語が脱落していく。残るのは身体感覚の言葉
- **文の長さ:** 断片化。完成した文が書けなくなる。「〜して、」で途切れる。思考が追いつかない
- **感覚描写:** 爆発的に回帰。ACT1以来消えていた色・匂い・温度が戻ってくる → 精密さの鎧が剥がれ、世界が再び感覚として入ってくる
- **感情表現:** 初めて感情を直接語ろうとする。しかし語彙がない → 「なんか」「よくわからないけど」のような不正確な言葉が初出
- **特徴的ルール:** 論理的接続詞（「したがって」「つまり」）が消え、「でも」「けど」に置き換わる

### SEQ別の変化
| シーン | 文体の状態 |
|--------|-----------|
| SEQ1-S1（秀斗の自殺未遂） | 文体の最大の断裂。身体が先に動く場面 → 思考の文ではなく、身体動作の羅列になる。「走った。掴んだ。引いた。」主語すら消える |
| SEQ2-S2（理解できなくても寄り添う）★ | 新しい文体の誕生。精密でも断片でもない、「不完全だが温かい」文。あんずの名前が出るが、今度は文が乱れない → 修復ではなく受容 |

### 導入理由
- ACT1〜4で積み上げた精密文体が物理的に崩壊する過程を読者に体感させる
- 「身体が先に動く」シーンでは思考の文体自体が不可能になる → 文体の不在が最大のドラマ
- SEQ2で生まれる「不完全な温かさ」の文体が、EPILOGUEへの橋渡しになる
- 「しんどかったな」（感情を精密に分析せず、ただ認める言葉）が文体的クライマックス
