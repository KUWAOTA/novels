# ACT2 文体設計（中1〜中2夏）

## 語り手
樹（中学生） / FB2のみ あんず視点

## 文体方針

### 樹視点
- **語彙レベル:** 中学生。理科用語に加え、社会的な語彙が増え始める（「係」「責任」「対処」）
- **文の長さ:** ACT1よりやや長くなる。あんずとの会話シーンで初めて複文が出現
- **感覚描写:** あんずに関する描写だけ質感が変わる → 色・匂い・温度が入り始める
- **感情表現:** まだ直接名指ししないが、身体感覚として漏れ始める（「胸の辺りが詰まる」「手が冷たい」）
- **対人描写:** あんずに対してだけ、行動の「理由」を推測しようとする → 樹にとって初めての他者理解の試み

### あんず視点（FB2: あんずの最後の夜）
- **語彙レベル:** 中学生だが、語彙が極端に少ない。同じ言葉の反復
- **文の長さ:** 極端に短い断片と、止まらない一文が交互に来る
- **感覚描写:** 身体の痛みと、小さな美しいものへの逃避が交互（叔父の暴力 → 窓の外の月）
- **感情表現:** 言葉にならない。「〜たかった」「〜したい」が途中で途切れる
- **特徴的ルール:** 助けを求める言葉を構成しようとして、毎回失敗する → 文が物理的に完成しない
- **リズム:** 息が浅い。過呼吸のようなリズム

### SEQ別の変化
| シーン | 文体の状態 |
|--------|-----------|
| SEQ1-S1（あんず係に任命） | ACT1の延長だが、あんずの描写だけ微かに精度が変わる |
| SEQ1-S2（論理でいじめをかわす） | 樹の得意領域。文体が最も安定・自信に満ちる |
| SEQ1-S3（あんずとのデート）★ | 文体の転換点。初めて「美しい」に類する語が出る。文のリズムがゆっくりになる |
| SEQ2-S4（あんずの電話） | 文が再び短くなる。「何を言えばいいかわからない」が文体に表れる |
| FB2（あんずの最後の夜） | 視点交代。上記あんず文体。読者への衝撃 |
| SEQ2-S4b（取調室）★ | 樹の文体が初めて「壊れかける」。しかし壊れきらず、論理で立て直す |
| SEQ2-S5（調査と結論） | 再び平坦に戻る。しかし今度は防衛的な平坦さ。「精密な言葉があれば救えた」という結論で文体が硬化 |

### 導入理由
- あんずとの交流で文体が揺れる ＝ 感情が芽生えている証拠（物語上は明示しない）
- あんず視点の文体を極端に変えることで、樹の「精密な言葉で救えた」という結論の誤りを文体レベルで証明する（あんずの問題は言語化不可能だった）
- 取調室での文体の揺れと回復が、ACT3以降の「誤った確信の硬化」を準備する
