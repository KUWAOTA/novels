# ACT 2 — 中学時代（〜13歳・夏）

**場所:** 富雄南中学校 / 石切公園 / 大和西大寺駅
**時間幅:** 中1〜中2夏
**幕の役割:** 物語の最大の引き金が発射される幕。あんずの自殺によって樹の誤信念が確立し、以後の全行動の根拠になる。

## 価値変化（Act Level）

```yaml
value_change:
  axis: つながり⇔孤立
  from: あんずとの沈黙の共有（微かなつながり回復）
  to: あんずの死による二度目の喪失 → 誤信念の確立
  cause: あんずの自殺
```

## クライマックス

あんずの自殺。樹は電話で「がんばれ」と言った直後にあんずが死んだことで、自分の言葉が何を後押ししたのかわからない罪悪感を背負う。調査の末、「精密な言語があれば理解を伝えられた」という誤信念が確立する。
