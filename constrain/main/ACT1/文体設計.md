# ACT1 文体設計（小6春〜中1直後）

## 語り手
樹（小学6年生）

## 文体方針

### 樹視点
- **語彙レベル:** 小学生相応。ただし父から学んだ理科・論理用語だけが不自然に高い（「仮説」「検証」「因果関係」）
- **文の長さ:** 短文主体。「〜した。〜だった。」の羅列
- **感覚描写:** カタログ的。教室の配置、人の位置関係を空間的に記述する（人間を「物体」のように配置する視点）
- **感情表現:** ほぼ不在。出来事を事実として並べるだけ。孤立を「誰もいない」ではなく「机の周囲半径1mに人がいない」のように描写
- **対人描写:** クラスメイトの行動を観察記録のように書く。動機の推測がない
- **父との会話:** 唯一リズムが変わる場面。文が少し長くなり、問いと応答の往復が生まれる → 樹にとって唯一の「対話」

### 秀斗（間接描写・樹の目を通して）
- 樹からは「なぜか自分を見ている子」としか認識されない
- 秀斗の嫉妬・羨望は樹の視点では描写不可能 → FB1で補完

### SEQ別の変化
| シーン | 文体の状態 |
|--------|-----------|
| SEQ1（孤立と嫉妬） | 最も平坦。感情語ゼロに近い。世界を計測するだけの視点 |
| SEQ2-S4（父から仮説を学ぶ） | わずかに温度が上がる。「面白い」「もっと知りたい」が初出 |
| SEQ2-S5（父の死） | 平坦さが壊れない → 壊れないこと自体が異常として機能する。読者は「なぜ泣かないのか」と感じる |

### 導入理由
- 文体の平坦さ＝ASD傾向の体感的表現（説明ではなく体験させる）
- 父の死で文体が変わらないことが、この語り手の本質的な断絶を示す
- 「精密さで世界を記述する」という樹の基本姿勢を文体レベルで確立する
