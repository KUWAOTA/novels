# ACT 1 — 小学生（1997年生・6年春〜）

**場所:** 三碓小学校 / 京大病院
**時間幅:** 小6春〜中1直後
**幕の役割:** 樹の弱点・信念・喪失の起源を描く。「なぜこの人物がこうなったか」を読者が体感する幕。秀斗の嫉妬の種もここで撒かれる。

## 価値変化（Act Level）

```yaml
value_change:
  axis: つながり⇔孤立
  from: 孤立しているが父がいる（不完全なつながり）
  to: 唯一の理解者を失い完全な孤立へ
  cause: 父・孝則の死
```

## クライマックス

父の死。唯一の理解者の喪失により、樹の孤立が不可逆になる。
