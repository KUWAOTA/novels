# プロローグ — 幼少期の日記

**形式:** 大人の樹が幼少期の日記を読み返す。シュモクバエと自分についての内的独白。
**時間:** ACT1以前（幼少期の記述）を、物語の「現在」の樹が読み返している
**視点:** 僕（樹）
**役割:** 樹の「声」と中核イメージ（シュモクバエ）を冒頭で確立。読者に問いを与える。

## 価値変化

```yaml
value_change:
  axis: 分類⇔受容
  from: なし（物語開始前のスナップショット）
  to: なし（問いの提示のみ）
  cause: 日記を読み返す行為自体が、物語全体のフレームを開く
```

## 構造上の機能

- **好奇心駆動**: 読者は「シュモクバエって何？」「なぜこの日記を読み返している？」と問いを持つ
- **声の確立**: 樹の一人称の文体・語彙・リズムが冒頭で定まる
- **中核イメージの配置**: シュモクバエが最初の1ページ目から登場
- **エピローグとの対句**: プロローグ＝一人の内的独白 → エピローグ＝二人で笑い合う

## 内容のイメージ

- 幼少期の樹がシュモクバエについて書いた日記（図鑑を読んだ感想）
- 目の離れ具合でモテるかどうかが決まる → 「ばかみたいだ」
- 自分の孤立も、自然界の恣意的なルールと同じかもしれない → 少し楽になった
- 枠を選びなおせば何の問題もないのでは、という原初の直感
- 大人の樹がこの日記を読み返している → なぜ今読んでいるのかは書かない

## エピローグとの対応

| | プロローグ | エピローグ |
|---|---|---|
| 時間 | 幼少期（回想） | 物語の後（未来） |
| 場所 | 日本（内面世界） | カカメガの森（外の世界） |
| 人数 | 樹一人 | 樹＋秀斗 |
| 行為 | 内的独白（考える） | 笑い合う（感じる） |
| シュモクバエ | 図鑑の中の知識 | 目の前にいる実物 |
| テーマ | 「枠を選びなおせば…」（仮説） | 「あほやな」（受容） |

## 表視点（僕・樹）

実家の本棚から一冊の日記を見つけた。
「
ニンゲンは魔法を使うようだ。
顔を見るだけで相手の気持ちがわかるという。
優れた魔法使い〈ニンゲン〉に言葉は要らないようだ。
言葉というはしごを使わないといけない僕は、どうやら落ちこぼれの魔法使いらしい。
はしごを与えてくれないニンゲン社会に僕の居場所はない。
だから、ニンゲンと話すより、昆虫とか葉っぱとか見つめている方が楽しい。
そんな僕に、父さんは昆虫図鑑を買い与えてくれた。
表紙に、シュモクバエという虫の写真が載っていた。
目が頭の両端についている、へんな顔のハエだ。
その目の離れ具合で、オスとしての魅力が決まるという。
アホくさい話だと思った。
でもシュモクバエからしたら、僕の方がよっぽどアホくさい存在かもしれない。
こんなことで悩んでいるのだから。
いっそ、昆虫や葉っぱにでもなりたかった。
その視点でニンゲン社会を眺めれたら、どれだけ楽だったろう。
図鑑を眺めながらずっとそんなことばかり考えている。
友達のいない昼休みに。
」
と、書いてある。

## claudeのレビュー（rev.3）

### 前回からの修正 → すべて良い方向

- 「母さん」→「父さん」 → ◎ 父・孝則が樹の興味を受容する設定と完全整合。図鑑が**父の遺品**としての意味も自然に生まれる
- ❾を2文に分割 → ◎ 「へんな顔のハエだ」が子供の声として完璧。ACT2であんず「…へんなの」とのエコー
- ⓮「昆虫や葉っぱにでも」 → ◎ ❼「昆虫とか葉っぱとか見つめている」との語のエコー。見つめる対象に自分がなりたい、という反転
- ❶が「じ」になっている → **タイポ？** 要確認

### 一文ずつ（変更箇所のみ）

| # | 文 | 判定 | コメント |
|---|---|---|---|
| ❶ | じ | **要確認** | 「古い日記が出てきた。」の残骸？ 新しいフレーム文？ |
| ❽ | そんな僕に、父さんは昆虫図鑑を買い与えてくれた。 | **Excellent（昇格）** | 父の①受容の体現。父が死んだ後も持ち続ける理由が自然に生まれた |
| ❾+❾' | 表紙に〜 / 目が頭の〜へんな顔のハエだ。 | **Excellent** | 「へんな顔」が子供の語彙として完璧 |
| ⓮ | いっそ、昆虫や葉っぱにでもなりたかった。 | OK（改善） | ❼との語のエコーが生まれた |
| ⓯ | その視点でニンゲン社会を眺めれたら、どれだけ楽だったろう。 | OK（軽度warning） | ⓮とまだやや重複するが、リズム（短→長）は悪くない。許容範囲 |
| ⓰ | 図鑑を眺めながらずっとそんなことばかり考えている。 | **warning** | 「友達のいない昼休み」が消え孤独の具体性が減った。最終行候補→「友達のいない昼休みに、僕はいつも図鑑を眺めている。」or「今日も昼休みに、図鑑を眺めている。」 |

### 残る作業（2つだけ）

**1. ❶のフレーム文を確定する。**

**2. ⓰の最終行を微調整する。** 「友達のいない」を戻すと、エピローグ（二人で笑う）との対句「一人で図鑑を眺めている」↔「二人でシュモクバエを見ている」が最も鮮明になる。
