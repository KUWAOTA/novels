# PROLOGUE 文体設計

## 語り手
樹（大人の樹が過去を振り返る形式）

## 文体方針

### 樹視点
- **語彙レベル:** 大人の樹が幼少期を回想するため、子供の感覚と大人の言葉が混在する
- **文の長さ:** やや長め。回想特有のゆったりとした呼吸
- **感覚描写:** 視覚・触覚が中心。昆虫図鑑の表紙など、非人間的な対象への鮮明な描写
- **感情表現:** 直接的に感情を名指ししない。「魔法が使えない劣等な魔法使い」のような比喩で間接的に示す
- **特徴的ルール:** 人間関係の描写は曖昧・短いが、物や自然の描写だけ異様に精密 → ASD傾向を文体で暗示
- **リズム:** 静謐。句読点多め、余白を残す

### 導入理由
- 読者に「この語り手は世界の見え方が独特だ」と直感させる
- 物語全体の文体的基調（精密さと感情の断絶）を最初に提示する
- 回想形式により、読者は「この人物に何があったのか」という問いを持って読み進める
