# プロローグ — 幼少期の日記

**形式:** 大人の樹が幼少期の日記を読み返す。シュモクバエと自分についての内的独白。
**時間:** ACT1以前（幼少期の記述）を、物語の「現在」の樹が読み返している
**視点:** 僕（樹）
**役割:** 樹の「声」と中核イメージ（シュモクバエ）を冒頭で確立。読者に問いを与える。

## 価値変化

```yaml
value_change:
  axis: 分類⇔受容
  from: なし（物語開始前のスナップショット）
  to: なし（問いの提示のみ）
  cause: 日記を読み返す行為自体が、物語全体のフレームを開く
```

## 構造上の機能

- **好奇心駆動**: 読者は「シュモクバエって何？」「なぜこの日記を読み返している？」と問いを持つ
- **声の確立**: 樹の一人称の文体・語彙・リズムが冒頭で定まる
- **中核イメージの配置**: シュモクバエが最初の1ページ目から登場
- **エピローグとの対句**: プロローグ＝一人の内的独白 → エピローグ＝二人で笑い合う

## 内容のイメージ

- 幼少期の樹がシュモクバエについて書いた日記（図鑑を読んだ感想）
- 目の離れ具合でモテるかどうかが決まる → 「ばかみたいだ」
- 自分の孤立も、自然界の恣意的なルールと同じかもしれない → 少し楽になった
- 枠を選びなおせば何の問題もないのでは、という原初の直感
- 大人の樹がこの日記を読み返している → なぜ今読んでいるのかは書かない

## エピローグとの対応

| | プロローグ | エピローグ |
|---|---|---|
| 時間 | 幼少期（回想） | 物語の後（未来） |
| 場所 | 日本（内面世界） | カカメガの森（外の世界） |
| 人数 | 樹一人 | 樹＋秀斗 |
| 行為 | 内的独白（考える） | 笑い合う（感じる） |
| シュモクバエ | 図鑑の中の知識 | 目の前にいる実物 |
| テーマ | 「枠を選びなおせば…」（仮説） | 「あほやな」（受容） |

```プロンプト
元ネタはchildhood.mdの冒頭部分と、シュモクバエのアイデアのミックスでいいと思います。

これを叩き台にして、ストーリーコンパイラ（日記は内的独白なので脚本的にかけないことに留意）をかけて
一文一文精査して、
それへのFBをもとに
文章を推敲していきたいです。
```

「
ニンゲンは『魔法』を使うそうだ。だから、顔を見るだけで相手の気持ちがわかるらしい。
優れた魔法使い〈ニンゲン〉に言葉は要らない。魔法で十分だから、落ちこぼれには説明すら与えないのだ。

⇔　（ここをいい感じに接続したい。）

ニンゲンと話すより、昆虫とか葉っぱとか見つめている方が好きだった。
図鑑に載ってるシュモクバエが目の位置の離れ具合でモテるかどうか決まるってのを知った。
馬鹿みたいだと思った。
僕が今集団から孤立していることや女子から寒い目を向けられている理由が、そんなくだらない理由なのかもしれないと思うと安心した。

私は人間という枠・指標にとらわれているからダメなだけで、

」

### claudeのレビュー

#### 0. 前提：日記はプロローグである

この日記は「ACT1のシーン」ではなく、**物語全体のフレームを開くプロローグ**。
したがって評価基準は通常のシーンと異なる：
- シーン遷移（`13_scene-transition`）のルールではなく、好奇心駆動（`12_exposition`）が最優先
- 価値変化は不要。「問いの提示」が仕事
- 脚本的なアクション描写は求めない（日記なので）

ただし、以下は通常通り適用する：
- `24_discernment`（陳腐さ・テンプレ検出）
- `17_symbolism`（中核イメージの自然な導入）
- `16_choice-and-expression`（声の固有性）

---

#### 1. 一文ずつの検証

**❶「ニンゲンは『魔法』を使うそうだ。だから、顔を見るだけで相手の気持ちがわかるらしい。」**

判定: **OK → 据え置き推奨**

childhood.mdのStory Compilerレビューで既に精査済み（1-3として仮採用）。プロローグとしても機能する。「魔法」の比喩は樹の声として固有性がある。

ただしchildhood.mdで指摘されていた問題は残っている：
- 「らしい」「そうだ」の伝聞語尾が「安全な場所からの観察」に見える
- Layer 2（人格・傷）がやや薄い

→ **プロローグという位置なら許容範囲**。日記なので「観察者の距離感」は自然。ACT1のシーンで3文目（ノートを破かれる）が来るので、ここでは傷を前面に出さなくていい。

**❷「優れた魔法使い〈ニンゲン〉に言葉は要らない。魔法で十分だから、落ちこぼれには説明すら与えないのだ。」**

判定: **OK**

同じくchildhood.mdで精査済み。テーマ（言葉 vs 非言語）の軸を早期に提示する機能文。

1点だけ：プロローグとして使う場合、「落ちこぼれ」が少し自己憐憫的に聞こえる。日記なので自己憐憫は自然だが、**幼少期の樹はまだ「傷ついている自覚」がない**はず（ASD傾向ゆえに「なぜ自分が排除されるかわからない」のが本質）。「落ちこぼれ」は自分の位置を理解している言葉。

→ 推敲候補：「落ちこぼれ」を「僕みたいなの」に変える等で、自己認識のなさを出す手もあるが、現状でも日記として成立する。

**❸「⇔（ここをいい感じに接続したい。）」**

**接続案を3つ提案する。**

前半（魔法の話）は「人間社会のルールがわからない」。後半（シュモクバエの話）は「自然界にも恣意的ルールがある → 安心」。接続に必要なのは**「人間社会から自然界に目が向く転換点」**。

```
案A（対比型・シンプル）：
「だから僕は、魔法が使えないなりに、別のものを見ることにした。」

案B（行動型・具体的）：
「教室にいるのが嫌になると、僕は図書室の隅で図鑑を開いた。」

案C（認知型・樹らしい）：
「でも、魔法のルールは図鑑に載っていなかった。代わりに載っていたのは、もっと馬鹿みたいなルールだった。」
```

**推奨は案C**。理由：
- 「図鑑」が自然に導入される（後半の昆虫図鑑に繋がる）
- 「魔法のルールは図鑑に載っていなかった」→ 樹が「理解可能なルール」を求めている（＝統制概念の萌芽）
- 「もっと馬鹿みたいなルール」→ シュモクバエへの自然な接続
- 樹のASD的な「分類・体系化」志向が出る

**❹「ニンゲンと話すより、昆虫とか葉っぱとか見つめている方が好きだった。」**

判定: **OK**

シンプルで機能的。ただし「好きだった」の過去形が少し気になる。日記なら「好きだ」（現在形）のほうが自然では？ 日記は「今の自分」が書くものなので。

→ ただし「大人の樹が読み返している」というフレームがある場合、過去形は「日記に書いてある文を読んでいる」感が出て逆に良い。**現状維持で可**。

**❺「図鑑に載ってるシュモクバエが目の位置の離れ具合でモテるかどうか決まるってのを知った。」**

判定: **warning — 文が長すぎる**

一文に情報が3つ入っている：
1. 図鑑に載っている
2. シュモクバエの目の位置
3. モテるかどうかが決まる

プロローグの核心情報（シュモクバエの初登場）なので、ここは**もっとゆっくり書いていい**。

→ 推敲案：
```
図鑑でシュモクバエのことを知った。
目が頭の端っこについていて、その離れ具合でモテるかどうかが決まるらしい。
```
2文に分けることで「シュモクバエ」という名前が独立して立つ。読者の目がここで止まる。

**❻「馬鹿みたいだと思った。」**

判定: **Excellent**

短い。断定。余計なものがない。樹の声がここで最も純粋に出ている。この一文は絶対に変えない。

**❼「僕が今集団から孤立していることや女子から寒い目を向けられている理由が、そんなくだらない理由なのかもしれないと思うと安心した。」**

判定: **warning — 説明的すぎる**

「集団から孤立」「女子から寒い目」「くだらない理由」「安心した」——認知の各ステップが全部言語化されている。これは**日記というより分析メモ**に見える。

問題：樹はASD傾向なので分析的に書くのは自然だが、プロローグとしては**読者に考えさせる余白**がほしい。「馬鹿みたいだと思った。」の余韻を、次の文が説明で潰している。

→ 推敲案：
```
馬鹿みたいだと思った。
でも、少し安心した。
```
「なぜ安心したか」を書かない。読者は❻❼の間で自分で考える。これが`12_exposition`の「好奇心駆動」。

あるいは：
```
馬鹿みたいだと思った。
僕が教室で浮いているのも、たぶん同じようなものだ。
```
「孤立」「女子」「寒い目」等の説明を省き、「同じようなもの」の一言に圧縮する。

**❽「私がいじめを受けているのはこの狭い日本の人間世界のローカルなルールに馴染めなかったに過ぎなくて、」**

判定: **compile_error — 人称の不一致**

「僕」→「私」に変わっている。日記の中で人称が揺れるのは意図的でない限りエラー。

また、この文は**論文のような口調**になっている。「この狭い日本の人間世界のローカルなルール」は大人の語彙。幼少期の日記としては不自然。

→ 推敲案（人称統一＋語彙調整）：
```
僕がハブられてるのは、この学校のルールに合わなかっただけで、
```

**❾「そんなルールなんてあほくさいくらい自然は多様的で、それぞれの生物がそれぞれのどうでもいいことを気にしてて、それぞれのコードで生きてた。」**

判定: **warning — 一文が長い＋語彙の混在**

良い点：「それぞれのコードで生きてた」は樹らしい言い方で固有性がある。
問題点：
- 「多様的」は日本語として不自然（「多様」で十分）
- 「あほくさい」は関西弁。樹は標準語話者だが、関西出身なので日記では出てもいい → **むしろ伏線として有効**（ACT5で「辛かったやろ」と関西弁に戻る伏線が、ここに「あほくさい」として既に埋まっている）
- 一文に詰め込みすぎ

→ 推敲案：
```
自然はもっとあほくさい。
それぞれの生き物が、それぞれのどうでもいいことを気にして、それぞれのコードで生きてる。
```
「あほくさい」を独立させることで、この言葉が印象に残る。ACT5の「辛かったやろ」（関西弁）との無意識のエコーになる。

**❿「それを俯瞰するのが好きだった。」**

判定: **OK**

「俯瞰」は幼少期の語彙としてはやや硬いが、樹のキャラクターなら許容範囲。ただし❹「見つめている方が好きだった」と意味が重複する。どちらか一方でいい。

→ カットするか、❹と統合する。

**⓫「私は人間という枠・指標にとらわれているからダメなだけで、」**

判定: **compile_error — 人称不一致（再）＋説明的**

再び「私」になっている。また「枠・指標」は完全に大人の分析言語。幼少期の日記としては不自然。

→ この内容自体は重要（エピローグの「枠を選びなおす」と対になる）だが、もっと子供の言葉で書く必要がある。

**⓬「その枠や指標を自分で選びなおしたら、そんな場所に旅をして移れたら何の問題もないのではと思えた。」**

判定: **warning — 結論が早すぎる＋希望的すぎる**

プロローグの最後がこの文で終わると、「この子は大丈夫だ」と読者が安心してしまう。物語の冒頭に安心は要らない。「問い」で終わるべき。

また「旅をして移れたら」は、エピローグ（ケニア旅行）の**先取りになりすぎている**。象徴としての接続は良いが、ここでこんなに明確に書くと`forced_symbolism`に近づく。

→ 推敲案：
```
僕がいる場所を変えたら、何か変わるのかな。
```
「枠」「指標」を使わず、子供の言葉で同じ直感を書く。「変わるのかな」と疑問形で終わることで、プロローグが「問い」で閉じる。

| 項目 | 判定 | 備考 |
|------|------|------|
| 中核イメージ導入 | ◎ | シュモクバエが自然に登場する |

#### 3. 接続部（⇔）の推奨案

前述の案Cを改良：

```
でも、魔法のルールは図鑑のどこにも載っていなかった。
代わりに見つけたのは、もっと馬鹿みたいなルールだった。
```

→ 「魔法のルール」＝人間社会の暗黙知。「図鑑に載っていない」＝樹の世界（言語化・体系化された知識）には存在しない。この2行で「人間社会の不可解さ」→「自然界の恣意性」への橋が架かる。

---

#### 4. 推敲の方向性まとめ

1. **人称を「僕」に統一**する
2. **大人の分析語彙**（枠・指標・多様的・俯瞰・ローカルなルール）を**子供の言葉**に置き換える
3. **❻「馬鹿みたいだと思った。」の後の説明を削る**。余白を残す
4. **最後を「問い」で終わらせる**。答えを出さない
5. **「あほくさい」は残す**（関西弁の伏線として機能する）
6. **接続部に「図鑑」を入れる**（案C）。小道具リレーの起点
7. **一文を短くする**。❺❼❾⓫⓬は分割 or 圧縮
