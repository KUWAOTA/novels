# あんずキャラクター再設計 — マインドマップ

## 設計方針

**変更しない核（既存設計の維持）:**
- 性加害を受けていても言い出せない
- 自己肯定感が低い
- クラスに馴染めていない
- 樹の言葉を「優しさ」として受け取る特性
- 「がんばれ」の電話 → 自死 の流れ
- 樹との交流が「初めて受容された体験」になること

**変更する核:**
- 知的障害 → 別の理由で孤立・言語化困難・周囲から疎まれる設定へ

## 最推奨案：E1（ADHD＋新興宗教家庭）の詳細設計スケッチ

```mermaid
mindmap
  root((E1: あんず詳細))
    ADHD面
      不注意優勢型
      忘れ物・提出物で常に叱られる
      授業中ぼーっとして怒られる
      「やればできるのに」が一番つらい言葉
      未診断（親が宗教的理由で医療拒否）
      衝動的に本音を言って後悔するパターン
    宗教面
      母親が熱心な信者
      父親は離婚済み or 無関心
      叔父は教団の幹部的立場
        →性加害が「教えの一部」として正当化
        →あんずは「これは罰なんだ」と思い込む
      学校では「〇〇教の子」として避けられる
      勧誘チラシ事件でクラスから完全孤立
      教義：苦しみは試練、耐えることが美徳
        →性被害を誰にも言えない構造
        →自己犠牲の美化→低自己肯定感
    樹との関係
      樹は宗教に全く興味がない
      「ふーん、で？」が逆に救い
      ADHDの散漫さを樹は気にしない
        樹自身が空気を読まないから
      お互いの「普通じゃなさ」が心地よい
      樹は「あんず係」を義務として淡々とこなす
        あんずにとっては初めての安定した関係
    デートシーンへの影響
      「セックスしたい？」
        →叔父の加害＋教義の歪みから出る台詞
        →「優しくしてくれる人には身体で返す」
      「帰りたくない」
        →家＝叔父の加害＋宗教的抑圧の場
        →二重の意味が載る台詞になる
      たい焼きの思い出
        →入信前の家族の記憶（まだ普通だった頃）
    自死の文脈
      樹の「優しさに見返りは要らない」
        →教義の「対価としての苦行」の否定
        →初めて無条件の肯定を受けた
      「がんばれ」の電話
        →教義では「頑張る＝耐える」
        →樹の「がんばれ」は違う意味だと分かっている
        →でも帰った先にあるのは叔父と宗教
      幸福死の構造
        →「試練の外」に出られた瞬間に死を選ぶ
        →苦しみからの解放としての自死
```

      樹は言葉が少なくても気にしない

        →声に出して言えたこと自体が悲痛
      電話で「がんばれって言って」
        →電話なら声が出る（対面でないから）
        →でも最後の電話は涙声で

## 補足：知的障害からの移行で調整が必要な箇所

| 既存要素 | 知的障害前提の設計 | 変更後の対応 |
|---|---|---|
| 「あんず係」の任命 | 特別支援的な配慮 | ADHD→忘れ物フォロー係 / 緘黙→連絡係 / 宗教→孤立児のケア係 |
| 言語化の困難 | 知的な制約 | ADHD→思考が散る / 緘黙→声が出ない / 愛着障害→感情の言語化ができない |
| 樹の暴言を受容 | 意味を完全には理解しない | ADHD→聞き流す / 緘黙→言い返せない / 宗教→「試練」として受容 |
| 「がんばれ」の意味の多層性 | シンプルな解釈 | 各案で固有の意味が付与される（上記参照） |
